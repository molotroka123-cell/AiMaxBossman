- Memory can be configured (root folder) through the product API.

## ACTUAL

1. Memory config: POST /api/memory/config {"root": "...\\audit-memory"} -> 200,
   backend_class=SQLiteMemoryBackend, configured=true. PASS.
2. Memory search INDEXING works: after any write, /api/memory/stats shows
   files=1 chunks=2 terms=16; /api/memory/search returns scored hits for terms that
   exist in indexed files ("memory", "note", "bossman", "created" all hit with score).
   PASS (search engine itself functions).
3. Memory FACT WRITE FAILS: FactIn-compliant payload
   {subject:"CP02 audit marker", predicate:"identifies",
   statement:"CP02-MARKER-KOBALT-91 is the unique marker...", object, source_kind,
   source_note, confidence} -> HTTP 409 with EMPTY body. Retry -> same 409.
   /api/memory/facts GET -> {"items":[],"total":0}. The fact is NOT persisted.
   No error text anywhere to explain the conflict. -> P1 (see blocker).
4. Malformed payload accepted silently: earlier write with wrong keys
   (scope/key/value/note) returned 200 and created a note file whose body is EMPTY
   (only frontmatter). Data silently dropped. -> P2.
5. File intelligence: analyze/extract on a real file -> HTTP 200 with
   {"ok":false,"refused":"FEATURE_DISABLED","detail":"file_intelligence_v1 is off;
   the owner enables it explicitly (BCC_FILE_INTELLIGENCE=1)"}. Honest fail-closed,
   default off. NOT a fake success. Live extraction -> OWNER_REQUIRED (env flag +
   restart is a production config change; auditor does not flip it).
6. /api/health -> HTTP 503 with EMPTY body even with valid token, while UI home
   page reports "СИСТЕМА В СТРОЮ". Opaque, inconsistent with UI status. -> P2.
7. Advertised endpoints /api/memory/facts/history and /api/memory/facts/as-of
   return 405 on POST; /api/memory/expand returns 404 on POST although advertised
   in /openapi.json. -> P2 (API surface mismatch).
8. Systemic: 4xx/5xx responses across memory API have EMPTY bodies (401/409/422/503/405),
   and /api/memory/write declares no requestBody schema while accepting arbitrary
   JSON. -> P2 (diagnosability).

## RESULT

canonical memory write path unusable via HTTP API in this build)
