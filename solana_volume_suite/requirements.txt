# Версии ЗАКРЕПЛЕНЫ точно (==), а не «не ниже» (>=).
#
# Почему именно здесь это важнее, чем где-либо ещё в репозитории: этот
# подпроект держит приватные ключи и подписывает транзакции mainnet. Плавающая
# версия означает, что состав кода, который увидит ключ, определяется не нами,
# а тем, кто последним опубликовал релиз.
#
# Это не гипотеза. Ноябрь 2018, event-stream: в цепочку зависимостей
# биткоин-кошелька Copay попал вредоносный релиз транзитивного пакета, и он
# выгружал приватные ключи. Никто из пользователей не менял свои зависимости —
# менялся мир вокруг незакреплённого `>=`.
#
# Версии сняты с PyPI 2026-09-11 (`https://pypi.org/pypi/<пакет>/json`,
# поле `info.version`), а не выбраны по памяти.
#
# Как обновлять: поднимать версию осознанно, одним изменением, с прочитанным
# списком изменений. Снять `==` обратно — значит вернуть ровно ту дыру, ради
# которой этот комментарий написан.
#
# Чего здесь ПОКА нет: хешей (`--require-hashes`). Это следующий шаг, и он
# закрывает подмену уже опубликованного артефакта; закрепление версии от такой
# подмены не защищает. Не сделано в этом прогоне — не выдаётся за сделанное.
