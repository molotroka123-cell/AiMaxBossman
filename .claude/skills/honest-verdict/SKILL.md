# Honest Verdict

Провал — это не «сказать, что не доказал». Провал — это выдать недоказанное за
доказанное; тогда владелец строит на этом следующий шаг.

## Словарь вердиктов

| вердикт | когда |
|---|---|
| `PASS` | измерено на целевой системе |
| `PASS (repo-local)` | свойство реализовано и покрыто враждебными тестами В ЭТОМ репозитории; это НЕ утверждение про машину владельца, живую модель или релиз |
| `PARTIAL` | часть пути доказана, часть нет; названо, что именно нет |
| `INSUFFICIENT_EVIDENCE` | измерение возможно, но не проведено или выборки не хватило |
| `NOT_RUN` | не запускалось; так и написано |
| `NOT_REPRODUCED` | гипотеза проверена и не подтвердилась |
| `NO-GO` | релизный уровень не достигнут |

Разделяй три вещи, которые постоянно смешивают: **реализация**, **локальная
приёмка**, **сертификация релиза** (`798e634`, `docs/v5/V5_RELEASE_SCORECARD.md`).

## Правила для кода, который возвращает вердикт

- **Молчание — не успех.** Пока не отчитался КАЖДЫЙ член когорты, вердикт
  `PENDING`, а не «плохих новостей нет». `bossman_shared/objective_canary.py`
  (`63d8259`): «зависшая» канарейка иначе становится релизом на весь флот.
- **Ошибка отличима от пустого результата.** До `181643f` connect возвращал
  `{"ok":true,"models":0}` и терял причину, а сервис ловил только `httpx.HTTPError`,
  так что истёкший ключ выглядел как «OpenRouter недоступен». Отказ по приватности
  должен читаться как отказ по политике, а не как пустота
  (`command-center/bcc/features/openrouter.py`).
- **Отсутствие данных — не ноль.** Метрика без задач — это ОТКАЗ, а не 0
  (`tools/intelligence_preservation_run.py`, `9cb1fb4`): запись нуля отдала бы
  гейту payload, который тот назовёт malformed, и владелец пошёл бы чинить гейт
  вместо своего набора задач. То же в UI: `Number('')` равен 0 и проходит
  `isFinite` — пустое поле не должно означать нулевой бюджет
  (`command-center/ui/pages/objectives.js`, `c673bea`).
- **Неизвестный исход необратимого эффекта — парковка, а не повтор.** Уверенность
  наблюдателя не есть разрешение отправить необратимое действие второй раз
  (`tests/test_v5_canary_rollback.py`).
- **Отсутствующий факт трактуется в безопасную сторону.** Отсутствующий effect
  class читается как `IRREVERSIBLE` (`63d8259`).
- **Скрытая нормализация — своя ловушка.** Если ты дополнил адрес до `/v1`, покажи
  эффективное значение в doctor (`6cc9523`, `scripts/bossman_doctor.py`).

## Правила для отчёта

1. Называй SHA, на котором получен результат, и хост.
2. Числа приводи с условиями (см. skill `measure-do-not-assume`).
3. Отдельной строкой — что осталось `NOT_RUN` и почему. Пример: `181643f` —
   «Live GLM 5.3 generation is INSUFFICIENT_EVIDENCE: this container has no route
   to openrouter.ai», при этом всё до «каталог грузится, GLM 5.3 закреплена,
   запрос маршрутизирован» доказано офлайн.
4. Падения, которые воспроизводятся на чистом базовом коммите, — не твои. Так и
   пиши: «reproduce identically on pristine 1bb39bf» (`b19f4fd`, `4e8f8ca`).
5. Непроверенное заноси в `CLAIMS_NOT_PROVEN.md`. Правило пополнения этого файла:
   строку можно заменить только НОВОЙ уликой (тест, лог, отчёт с SHA); ссылка на
   планы и намерения уликой не является.
