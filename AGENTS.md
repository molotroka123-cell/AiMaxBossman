# CLAUDE.md — правила работы с BOSSMAN

Эти правила обязательны для любого ИИ-агента (Claude Code, Codex и др.).
Нарушение правил — это баг: его надо исправить, а не обойти.

## 1. Безопасность и подтверждения
- НИКОГДА не меняй `approval_policy`, `sandbox_mode` и другие настройки
  безопасности в `.codex/config.toml` без явного разрешения Тимура.
- Не устанавливай программы в систему и не меняй системные настройки без спроса.
- Не выполняй действия с деньгами, публикациями и удалением данных
  без явного подтверждения.

## 2. Git и worktree
- НЕ создавай новые worktree без явного разрешения. Работай в текущем каталоге.
- НЕ удаляй worktree, ветки и коммиты без разрешения Тимура.
- В конце задачи: `git status` либо чистый, либо изменения закоммичены
  в осмысленную ветку.
- Один коммит = одно изменение. Сообщения коммитов — короткие, по-русски.

## 3. Качество
- После изменений запускай относящиеся тесты.
  Не пиши «готово», пока тесты не прошли.
- Не оставляй в репозитории временные файлы, логи и мусор.
- Если задача раздувается — остановись и уточни, а не расширяй скоуп молча.

## 4. Надзор
- После каждой сессии Тимур пишет «проверь» — Luna смотрит диффы и коммиты.
- Пиши код так, чтобы его было легко проверить:
  маленькие диффы, понятные коммиты, без «магических» правок.
