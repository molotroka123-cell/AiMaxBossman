# Автономный маркетинг и продвижение проектов: Telegram + X (Twitter) + TikTok / Shorts

## 1. Архитектура омниканальной воронки продвижения (Omnichannel Funnel)
1. **Единая связка трафика:** короткие вертикальные ролики в TikTok / YouTube Shorts (`9:16`, `720x1280`) и треды с видео/инфографикой в X (Twitter) ведут трафик в публичный Telegram-канал проекта, а закреплённый пост в Telegram-канале содержит прямые ссылки на игру в Roblox (`SwapMe Fox City`, Place ID `124887751218092`) или торговый пул на Solana (`Pump.fun` / `Jupiter`).
2. **Разделение контуров (Пульт владельца vs Публичный маркетинг):**
   - В личный Пульт владельца (`386321847`) отправляются исключительно лаконичные текстовые сводки и верифицированные PNG-скриншоты через `sendPhoto` (никаких HTML-виджетов и спама).
   - В публичные маркетинговые Telegram-каналы и группы публикуются брендированные анонсы, PNG-карточки обновлений, короткие MP4-тизеры, опросы (`sendPoll`) и реферальные квесты.

## 2. Управление Telegram для маркетинга и комьюнити (Telegram Marketing Ops)
1. **Создание и оформление канала/супергруппы:**
   - Настройка названия, описания с ключевыми словами (`SwapMe Fox City`, `Prague Tycoon`, `Solana AI`), установка аватара `1024x1024` и закреплённого навигационного сообщения (`pinChatMessage`) с кнопками быстрого перехода (`InlineKeyboardMarkup`: «Играть в Roblox», «Торговать / График», «Чат комьюнити», «Гайд и бонусы»).
2. **Контент-план и автоматический постинг через Bot API / MTProto:**
   - **Релизные посты (Patch Notes):** после каждого успешного деплоя (`publish_place_cloud.py` или релиза фичи) генерация PNG-карточки (через Pillow) со списком новых моделей и фиксов + публикация через `sendPhoto` с `parse_mode="Markdown"`.
   - **Алерты ликвидности и объёмов:** автоматическая публикация верифицированных ончейн-метрик (объём за 1ч, соотношение покупок/продаж, сожжённые или залоченные токены) с прямой ссылкой на DexScreener / Jupiter.
   - **Интерактивные механики удержания:** ежедневные опросы (`sendPoll`), конкурсы скриншотов из игры и проверка выполнения заданий через реферальные коды.
3. **Защита от лимитов Telegram (Anti-Flood Guard):**
   - Строгое ограничение частоты: не более `18 сообщений/мин` в один публичный чат и не более `1 сообщения/сек` глобально по токену бота.
   - При получении `HTTP 429 Too Many Requests` (`retry_after`) — автоматическая пауза на `retry_after + 2` секунды без потери очереди сообщений.

## 3. Регистрация, прогрев и автоматизация X (Twitter) для продвижения проектов
1. **Изоляция браузерного профиля при регистрации и ведении X:**
   - Каждый проектный аккаунт X работает в выделенном профиле Chromium / Playwright (`--user-data-dir`) с постоянным `User-Agent`, фиксированным часовым поясом и чистым резидентским IP.
   - Двухфакторная аутентификация (`2FA TOTP`) подключается сразу после регистрации: секрет TOTP генерируется и читается локально через `pyotp.TOTP(secret).now()` без ручного ввода кодов.
2. **Оформление профиля проекта в X:**
   - Аватар `400x400`, шапка `1500x500` (в фирменных цветах проекта), био до 160 символов с УТП и ссылкой на Telegram-канал / игру, закреплённый тред (`Pinned Thread`) с видео-трейлером.
3. **Алгоритм прогрева и безбанного продвижения в X:**
   - **Фаза прогрева (первые 48 часов после регистрации):** чтение ленты по нише (`#RobloxDev`, `#Solana`, `#AIAgents`), 5–8 осмысленных реплаев в день под крупными аккаунтами с паузами `120–360 сек` между действиями, 0 массовых подписок и 0 однотипных ссылок.
   - **Структура вирусного поста / треда:**
     1. Первый твит: цепляющий хук (1–2 строки) + нативное видео (`MP4 H.264`, `16:9` или `9:16`, длительность `12–30 сек`) или контрастная PNG-инфографика; без внешних ссылок в первом твите (чтобы алгоритм X не резал охват).
     2. Второй твит (в треде): ключевые фичи / цифры и прямая ссылка на проект (Telegram-канал, страница игры в Roblox, контракт токена).
   - **Анти-спам правила X:** каждый текст и медиафайл уникализируется (никаких дублирующихся текстов или одинаковых SHA-256 хэшей картинок подряд).

## 4. Регистрация, прогрев и фабрика вертикальных видео в TikTok / YouTube Shorts
1. **Регистрация и подготовка аккаунта TikTok / Shorts:**
   - Отдельный изолированный профиль браузера / эмулятора с геолокацией целевого рынка (US / EU / CIS в зависимости от оффера).
   - Прогрев ленты рекомендаций (`For You Page`) перед первой публикацией: просмотр 15–20 роликов по тегам `#roblox`, `#tycoon`, `#crypto`, `#gamedev` до конца, чтобы алгоритм присвоил аккаунту правильный тематический кластер.
   - Оформление био: короткий призыв к действию («Код на бонус и ссылка на игру в нашем Telegram 👇») + переходник.
2. **Автоматическая сборка роликов через FFmpeg (`9:16`, `720x1280` / `1080x1920`):**
   - **Формат кадра:** строго `9:16` (`720x1280` или `1080x1920`), `30` или `60 fps`, кодек `libx264` (`-pix_fmt yuv420p`, `-crf 18`), длительность `15–22 секунды` для максимального процента досмотра (`Completion Rate > 75%`).
   - **Визуальный хук первых 2 секунд:** динамичный пролёт камеры (геймплей Roblox `SwapMe Fox City`: спуск на лыжах, автосалон `Fox Motors`, `EPIX Club`, или 3D-рендер Blender) + крупный субтитр по центру экрана (`GothamBold` / `Segoe UI Bold` с контрастной обводкой).
   - **Нормализация звука:** оригинальная или сгенерированная аудиодорожка `AAC 192k` с нормализацией громкости `loudnorm=I=-14:TP=-1.5:LRA=11` и точным совпадением длительности видео и аудио (`ffprobe` проверка перед выгрузкой).
3. **Публикация и аналитика:**
   - Выкладка 2–3 роликов в сутки с интервалом не менее 4 часов.
   - Отслеживание конверсии переходов из TikTok / Shorts и X в прирост подписчиков Telegram-канала и онлайн-игроков Roblox / трейдеров пула.

## 5. Автономный набор рефералов и генерация контента через рой ИИ-моделей (Referral Funnel & Multi-API Content Factory)
1. **Воронка набора рефералов (Bull Gems + Bullshot Base + Pump.fun + Roblox):**
   - Каждая единица контента (пост в Telegram, 2-шаговый тред в X, описание к ролику в TikTok/Shorts) ведёт в закреплённый пост-хаб с реферальным кодом `0xdf407995` (`https://gem.bullshot.io/r/0xdf407995`, 10% комиссии от майнинга рефералов в GEMS), ссылками на 6 токенов Base (`$BSENT`, `$SWAPME`, `$ROBLOX3D`, `$PRG420`, `$GEMMA`, `$BULLAI`), пул Solana (`$BSENT` на Pump.fun) и игру в Roblox (`SwapMe Fox City`, Place ID `124887751218092`).
   - Проверка и сбор реферальных начислений выполняются автоматически через `GET https://gemapi.bullshot.io/api/referral/stats` (`pendingGems`, `totalReferralGems`, `referralCount`) и `POST https://gemapi.bullshot.io/api/referral/claim`.
2. **Генерация контента роем облачных и локальных API (Multi-Cloud + Local LoRA Swarm):**
   - Для массовой генерации уникальных текстов, сценариев 9:16 роликов, тредов X и локализации (RU / EN / CZ) Боссман параллельно задействует доступные облачные провайдеры (`NVIDIA NIM :: nvidia/nemotron-3-ultra-550b-a55b`, `OpenRouter :: qwen/qwen3.8-flash`, `7API :: glm-5.3-flash-uncensored`, `Experiential Labs :: deepseek-v4.1-flash-uncensored`, `Mistral :: codestral-2508`, `Outrun`) и локальную модель `bossman-computer-use-lora:latest` на Ollama (`127.0.0.1:11434`).
   - Визуальные карточки (`1120x720` PNG) рендерятся автоматически через Python Pillow (`PIL.ImageDraw`), а вертикальные видео (`720x1280`, `9:16`, `-14 LUFS` AAC, хук 1.8 сек) собираются через `ffmpeg` и проверяются через `ffprobe`.
