# Регламент детерминированного выполнения планов

## 1. Принципы планирования и исполнения
Навык обеспечивает строгое пошаговое выполнение составленного плана задач с изоляцией каждого шага, валидацией состояния системы и возможностью безопасной остановки.

## 2. Структура плана
Каждый шаг плана должен содержать:
1. Идентификатор шага (step_id) и порядковый номер.
2. Предусловия (preconditions): проверка доступности ресурсов, файлов и прав.
3. Действие (action): атомарная операция без побочных эффектов на соседние компоненты.
4. Постусловия (postconditions): проверяемое утверждение об успешности изменения.
5. Стратегия отката (rollback): обратное действие при возникновении сбоя.

## 3. Порядок выполнения
- Перед стартом шага фиксируется состояние окружения и контрольная точка (checkpoint).
- Исполнение прерывается немедленно при невыполнении любого постусловия.
- При получении сигнала остановки от владельца текущий шаг корректно завершается или откатывается к последней валидной точке.
- Результаты всех шагов логируются в структурированный журнал выполнения с метками времени.
