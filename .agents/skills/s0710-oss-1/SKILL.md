# Регламент эволюционной оптимизации промптов (gepa)

## 1. Концепция оптимизации промптов
Навык реализует итеративное улучшение системных инструкций и промптов агентов на основе генетических операторов (мутация, скрещивание, селекция) по измеряемой скалярной метрике качества.

## 2. Пайплайн эволюции
1. Определение целевого корпуса: фиксация набора задач с детерминированными валидаторами успеха.
2. Базовое измерение: оценка исходного поколения промптов и фиксация baseline score.
3. Генерация мутаций: создание вариаций формулировок с сохранением ограничений безопасности.
4. Отбор лучших кандидатов: сохранение только тех промптов, которые показывают строго монотонный прирост метрики без деградации побочных задач.

## 3. Критерии остановки и защита
- Остановка по достижению порога качества или исчерпанию лимита поколений.
- Запрет на использование формулировок, ослабляющих политики безопасности системы.
