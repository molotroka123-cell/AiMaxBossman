# Регламент взаимодействия с браузером через Chrome DevTools Protocol (CDP)

## 1. Контур изоляции браузера
Навык регулирует прямое подключение к инстансу Chromium/Chrome через локальный WebSocket CDP на localhost (127.0.0.1) с обязательным использованием изолированного каталога пользовательских данных (--user-data-dir).

## 2. Операции через CDP
1. Навигация: использование Page.navigate с ожиданием события Page.loadEventFired или сетевого затишья.
2. Чтение DOM: использование DOM.getDocument и DOM.querySelector для безопасного извлечения структуры страницы.
3. Снятие скриншотов: Page.captureScreenshot в буфер памяти с сохранением в локальное хранилище доказательств.
4. Инспекция сети: Network.enable для мониторинга кодов ответов HTTP без перехвата приватных заголовков авторизации.

## 3. Ограничения безопасности
- Запрещено выполнять произвольные строковые eval-команды на страницах внешних доменов.
- Запрещена передача cookies сессий и локальных токенов авторизации наружу.
- При падении вкладки или тайм-ауте сессия CDP закрывается штатно.
