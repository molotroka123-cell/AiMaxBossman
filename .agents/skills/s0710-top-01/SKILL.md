# Регламент управления окнами Windows по точному handle (HWND)

## 1. Область применения
Навык регламентирует поиск, переключение, изменение геометрии и закрытие окон графического интерфейса Windows исключительно по прямому целочисленному дескриптору HWND.

## 2. Правила поиска и идентификации
1. Поиск окна выполняется через Win32 API (EnumWindows, FindWindowEx) с обязательной верификацией PID процесса-владельца.
2. Запрещается отправлять сообщения или клики по окну, если HWND изменился или окно сменило заголовок между кадрами.
3. Перед взаимодействием проверяется:
   - Окно видимо: `IsWindowVisible(hwnd) == True`.
   - Окно не свернуто и включено: `IsWindowEnabled(hwnd) == True`.

## 3. Безопасное взаимодействие
- Активация окна выполняется вызовом `SetForegroundWindow` с последующим подтверждением фокуса через `GetForegroundWindow`.
- Изменение координат и размеров выполняется через `SetWindowPos` с флагами SWP_NOZORDER.
- Закрытие инициируется отправкой `WM_CLOSE`, ожиданием корректного завершения и проверкой через `IsWindow`.
