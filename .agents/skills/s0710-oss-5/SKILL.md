# Регламент интеграции агентного SDK OpenHands на платформе Windows

## 1. Область применения
Навык стандартизирует подключение и оркестрацию компонентов фреймворка OpenHands для решения комплексных задач программирования и анализа кода на платформе Windows.

## 2. Конфигурация рантайма
1. Изоляция рабочего пространства: работа агента настраивается в выделенной директории с отслеживанием файловых мутаций.
2. Взаимодействие с API Bossman: обращение к локальным моделям через эндпоинты Control API (:8801) с авторизацией по токену X-BCC-Token.
3. Обработка событий: преобразование потока действий и наблюдений (Action/Observation) агента в события шины EventBus Bossman.

## 3. Контроль выполнения
- Ограничение максимального количества шагов агента (max_iterations) для предотвращения зацикливания.
- Сохранение итогового диффа изменений в виде единого patch-файла для ревью владельцем.
