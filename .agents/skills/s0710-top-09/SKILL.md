# Регламент защиты от платформенных ловушек Windows

## 1. Кодировки текста и UTF-8
1. Весь ввод-вывод в консоли и файлах должен принудительно использовать UTF-8:
   - Установка `PYTHONIOENCODING=utf-8`.
   - Явное указание `encoding="utf-8"` при открытии любых текстовых файлов.
2. Обработка cp1251: перехват вывода системных утилит Windows (chcp 65001 или декодирование с cp1251 при ошибках UnicodeDecodeError).
3. Защита от BOM: чтение через utf-8-sig для предотвращения попадания символа U+FEFF в начало JSON или YAML.

## 2. Окончания строк (Line Endings)
- Нормализация окончаний строк: автоматическая замена CRLF (`
`) на LF (`
`) перед синтаксическим анализом.
- Git-конфигурация: сохранение единообразия репозитория без мусорных дифов окончаний строк.

## 3. Пути к файлам (File Paths)
- Использование библиотеки `pathlib.Path` вместо ручной склейки строк с обратными слэшами.
- Поддержка префикса `\\?\` для путей длиннее 260 символов (MAX_PATH).
