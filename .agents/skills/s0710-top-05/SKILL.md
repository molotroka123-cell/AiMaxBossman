# Регламент остановки процессов по PID с предварительным бэкапом

## 1. Цели безопасности
Исключение случайного завершения системных процессов Windows, процессов других пользователей или фоновых служб ядра при обслуживании и перезапуске компонентов.

## 2. Этапы выполнения процедуры
1. Идентификация процесса:
   - Определение точного числового PID через надежный системный запрос (Get-Process / tasklist).
   - Верификация имени исполняемого файла и командной строки процесса.
2. Сохранение состояния (бэкап):
   - Сохранение несохранённых данных и конфигурационных файлов процесса в резервный каталог.
   - Фиксация открытых дескрипторов и сетевых соединений.
3. Завершение процесса:
   - Сначала отправка мягкого сигнала завершения (WM_CLOSE / SIGTERM).
   - Ожидание грациозного завершения в течение тайм-аута (5 секунд).
   - Принудительное завершение через TerminateProcess только при зависании.
4. Пост-проверка: подтверждение отсутствия PID в таблице процессов.
