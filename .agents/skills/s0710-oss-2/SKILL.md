# Регламент регрессионного тестирования навыков и промптов

## 1. Задачи регрессионного контроля
Гарантия того, что добавление нового навыка или обновление системного промпта не ухудшает ранее достигнутые показатели решения прикладных задач.

## 2. Структура эталонного корпуса
- Эталонный корпус включает задачи категорий: рассуждение, генерация кода, извлечение фактов, обработка ошибок.
- Для каждого примера задано однозначное условие проверки (assert / equals / contains).

## 3. Процедура приёмки
1. Прогон эталонного набора тестов на неизменяемом фиксированном коммите.
2. Сравнение доли успешно решённых задач с baseline.
3. При обнаружении любого падения хотя бы на одной критической задаче релиз изменения блокируется.
4. Формирование дифференциального отчёта с детализацией упавших тест-кейсов.
