# Регламент фиксации парных скриншотов «до» и «после»

## 1. Назначение
Навык предназначен для сбора наглядной доказательной базы при выполнении UI-операций, рефакторинге стилей, тестировании графического интерфейса и аудите рабочих процессов.

## 2. Стандарт фиксации
1. Снимок «ДО»:
   - Снимается непосредственно перед отправкой управляющего действия в приложение.
   - Имя файла: `<timestamp>_<action_id>_before.png`.
2. Снимок «ПОСЛЕ»:
   - Снимается после стабилизации интерфейса (завершение анимаций, сетевых запросов).
   - Имя файла: `<timestamp>_<action_id>_after.png`.

## 3. Вычисление диффа
- Формирование маски изменений (pixel diff) с выделением изменившихся областей прямоугольными рамками.
- Сохранение метаданных: разрешение экрана, DPI масштабирование, активный HWND, хеш SHA-256 каждого изображения.
- Запись ссылок на изображения в локальную квитанцию отчёта.
