# Получение имени хоста компьютера

## Когда применять
Когда необходимо определить имя компьютера в локальной среде

## Шаги
1. Попытаться выполнить команду 'hostname' в терминале
2. Если не удалось, попытаться выполнить команду 'echo %COMPUTERNAME%' в терминале с mode=project_host
3. Если вышеуказанные методы не работают, проанализировать системную информацию и пути файлов для определения имени компьютера
4. В данном случае имя компьютера определяется из пути C:\Users\asd\Bossman
