# Регламент минимального терминального агента (mini-swe-agent)

## 1. Назначение и ограничения
Навык описывает лёгкий шаблон агента для выполнения атомарных терминальных команд (сборка, запуск тестов, проверка статуса репозитория) в изолированной среде воркера.

## 2. Правила работы с терминалом
1. Каждая команда выполняется с явным таймаутом и буферизацией вывода.
2. Проверка кода возврата: ненулевой код завершения трактуется как сбой операции с разбором stderr.
3. Ограничение области видимости: команды исполняются только внутри назначенного рабочего каталога проекта.

## 3. Защита от опасных команд
- Блокировка команд модификации системных разделов и небезопасного скачивания файлов из сети.
- Запрет работы в интерактивном режиме ожидания ввода пользователя без поддержки TTY.
