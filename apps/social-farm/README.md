# BOSSMAN Social Farm (APP #4)

Управление подключёнными аккаунтами социальных сетей **в границах их настоящих
возможностей**. Instagram — первая площадка; официальный API — основной путь,
браузерный резерв — отдельный изолированный адаптер, включаемый явно.

Приложение самостоятельное: оно ничего не импортирует из BOSSMAN, а BOSSMAN
ничего не импортирует из него. Связь только по HTTP через узкий мост.

## Главное правило

**Единого флага «полный контроль» не существует.**

Для каждого подключённого аккаунта строится матрица настоящих возможностей —
девять состояний, от `SUPPORTED_OFFICIAL` до `REQUIRES_APP_REVIEW`. Действие
показывается рабочим только тогда, когда возможность его подтверждает. Кнопка,
которую нельзя нажать, честнее ошибки после нажатия.

Из этого следует порядок, который проходит любое изменение внешнего мира:

```
ВОЗМОЖНОСТЬ → ПОЛИТИКА → ОДОБРЕНИЕ (если ASK) → ДОЛГОВЕЧНАЯ РАБОТА
→ АДАПТЕР → ВНЕШНИЙ ЭФФЕКТ → СВЕРКА → АУДИТ
```

Возможность и политика — разные барьеры, и путать их нельзя. Политика решает,
спрашивать ли человека. Возможность решает, существует ли действие вообще.
Разрешение не создаёт возможности.

## Что не будет сделано ни при каких настройках

Обход капчи. Антидетект и подмена отпечатка браузера. Обход ограничений
частоты. Создание фальшивых аккаунтов. Перебор учётных данных. Массовая
незапрошенная рассылка в личные сообщения и комментарии.

Это не значения политики — для них нет кода, и статический скан в тестах
следит, чтобы он не появился (`tests/unit/test_independence.py`).

Браузерный резерв — это адаптер совместимости, разрешённый владельцем аккаунта,
а не средство обхода защиты.

## Если неизвестно, дошла ли публикация

Не повторять. Неизвестное внешнее состояние идёт в сверку, а не в ретрай:
публикация, ушедшая дважды, не чинится откатом. Если сверка не смогла ничего
доказать, работа останавливается и ждёт человека.

## Установка и запуск

```bash
cd apps/social-farm
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env          # затем править; секреты — только из окружения

social-farm check             # напечатать возможности и выйти
social-farm serve             # поднять HTTP-сервис (по умолчанию 127.0.0.1:8895)
python -m pytest -q           # тесты приложения
```

Порт 8895 разведён с ядром (8800) и другими приложениями (8870, 8890).

## Секреты

Секрет живёт только в окружении или во внешнем хранилище. Он не передаётся
аргументом команды, не пишется в лог и не попадает в аудит — туда идёт ссылка
на секрет, а не значение. Пароли и cookie браузера в доменной базе не хранятся.
