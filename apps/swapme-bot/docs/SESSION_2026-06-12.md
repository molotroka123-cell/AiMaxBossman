### Как запустить 24/7 без компа (Railway):
1. Зайти на railway.app → Login with GitHub.
2. New Project → Deploy from GitHub repo → `swapme-bot` (Dockerfile подхватится сам).
3. В сервисе: вкладка Volumes → Add Volume → mount path `/data`.
4. Вкладка Variables: `BOT_TOKEN=<токен от BotFather>`, `DB_PATH=/data/swapme.db`, опционально `ADMIN_IDS`, `CHANNEL_ID`, `XE_API_ID`, `XE_API_KEY`.
5. Загрузить текущую `swapme.db` на volume (через railway CLI: `railway volume` или временный endpoint).
6. Deploy. Бот работает постоянно; локального бота при этом ВЫКЛЮЧИТЬ (двойной polling = конфликт).
Альтернативы: Render (background worker), VPS (Hetzner ~5€), fly.io.
