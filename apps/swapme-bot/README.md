## Незакоммиченные правки `bot.py` (после 22.08, в swapme-bot/main их НЕТ, на Railway НЕ задеплоены)

- Предупреждение об устаревших курсах (`STALE_RATE_HOURS = 12`, `_warn_if_stale`) — бэклог п.1.
- Ручные курсы применяются сразу (кэш не перекрывает manual-пары).
- Ретрай критичных источников курсов (EUR/USDT и др.).
- `add_liquidity` и смежное: ledger + liquidity_sources в одной транзакции.
- Правка даты сделки синхронизирует ledger.
- После коммита ордера сбой reconcile/чека не выглядит как ошибка сохранения (нет дублей при «Повторить»).
- Объём фиат↔фиат — по курсу дня сделки.

Чтобы выкатить: проверить, перенести в `swapme-bot` → push в main → Railway передеплоит.

## Чего здесь НЕТ (намеренно)

Репозиторий AiMaxBossman **публичный**, а правило Bossman — данные сделок SwapMe в облако не выносить.
Поэтому НЕ перенесены: `swapme.db` и бэкапы, Telegram-экспорты/фото, PDF/XLSX/DOCX-отчёты,
логи, разовые скрипты импорта/отчётов (в них вшиты сделки, расходы и токен бота).
Они остаются на основном ПК в `C:\swapme_bot`. Боевая БД — на Railway volume
(свежая копия: команда `/backup` у бота или ночной автобэкап 23:55).

## Запуск (только для разработки)

```bash
pip install -r requirements.txt
cp .env.example .env   # BOT_TOKEN, ADMIN_IDS, DB_PATH
python -X utf8 bot.py
```

⚠️ **Не запускать с боевым токеном, пока работает Railway** — конфликт `getUpdates` (409).
Для тестов — отдельный бот от @BotFather и копия БД.
Поэтому здесь нет `app.manifest.yaml`: пульт Bossman не должен уметь запускать этого бота.
