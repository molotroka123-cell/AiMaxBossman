# Poker Train — мини-приложение Telegram для всех, хост на ПК владельца (14.10.2026)

Любой человек открывает бота **Jeff** → кнопка меню **«🃏 Покер»** → играет в покер-тренажёр (IceCrown Poker
Club, репозиторий `molotroka123-cell/pokertrain`, доработанная ветка `mp/b-poker-20261011`) прямо в Telegram.
Владелец видит ту же кнопку в своём пульте и управляет хостом командой `/poker_app`.

## Как устроено

| Часть | Где | Что делает |
|---|---|---|
| Игра | браузер игрока | вся логика, раздачи и ИИ-соперники считаются у игрока; профиль и история — в его браузере |
| Хост `pokerhost` | ПК владельца, `127.0.0.1:8810`, отдельный процесс | отдаёт собранную игру и таблицу лидеров; больше ничего |
| Туннель | `cloudflared` quick tunnel (бесплатно, без аккаунта) | публичный HTTPS-адрес `*.trycloudflare.com`; порты роутера не открываются |
| Кнопки | Telegram `setChatMenuButton` | Jeff — для всех; пульт — только чат владельца; при остановке снимаются |

## Границы (проверено тестами на атаках)

- Хост не имеет доступа к Bossman, ключам, файлам вне сборки игры: выход из папки → 400/404.
- Запись в таблицу лидеров — только с подписью Telegram (`initData`, HMAC токеном Jeff или пульта, не старше
  суток); имя берётся из Telegram, а не из запроса; 1 запись в 10 с на игрока; числа обрезаются, NaN/мусор
  выбрасываются; сырой Telegram id не публикуется.
- **Очки считает браузер игрока** — подпись Telegram подтверждает, КТО прислал, но не честность очков. Таблица
  лидеров учебная, призов и денег нет.
- `/api/claude` (платный бот режима HARDCORE) на хосте выключен (503): игра сама переходит на локальный ИИ.
- CSP: скрипты только свои и `telegram.org`, сеть только к себе, встраивание только в Telegram; лимит 60 запросов
  за 10 с с одного IP, тело запроса ≤ 8 КБ.

## Управление

- Пульт (только владелец): `/poker_app` — статус, `/poker_app вкл`, `/poker_app выкл`.
- Вручную: `cd apps/poker-train-host && python -m pokerhost run|stop|status`.
- Сборка игры: в `pokertrain` `npm run build` → скопировать `dist` в `%LOCALAPPDATA%\Bossman\poker-host\dist`.
- Данные: `%LOCALAPPDATA%\Bossman\poker-host\` (`state.json`, `leaderboard.sqlite3`, `host.log`).
- `cloudflared` 2026.10.0: `C:\Users\asd\Bossman\apps-local\cloudflared\cloudflared.exe`
  (SHA256 `86aee4017b26625cee8484c113558f48effa4cd47f7aa05fcf425604e5d2b23c`), переопределяется `BOSSMAN_CLOUDFLARED`.

## Ограничения

- Адрес quick tunnel меняется при каждом запуске (кнопки обновляются автоматически). Постоянный адрес — именованный
  туннель Cloudflare (нужен аккаунт и домен) — по решению владельца.
- Хост работает, пока включён ПК; автозапуска нет.
- Игра одиночная (игрок против ИИ). Игра людей друг с другом за одним столом — отдельная большая работа.
