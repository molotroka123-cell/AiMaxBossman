# Poker-LoRA — отчёт

Ветка `poker-lora/hu-nlhe-20261006`. Область: **heads-up no-limit hold'em, только river, диапазоны заданы, ставки из малой абстракции** (check / bet50 / bet100 / pot-raise / all-in при малом SPR). Другие форматы не затрагивались.

## Результаты на отложенных бордах (72 борда, 4 518 примеров; профиль — 40 спотов × 2 места)
| политика | валидных | потеря EV, % банка (CI 95 % по спотам) | совпадение с самым частым действием решателя | эксплуатируемость, % банка | EV против station / nit / maniac, % банка | p50, мс |
|---|---|---|---|---|---|---|
| random_legal | 1.000 | 11.40 [10.75; 12.11] | 0.41 | 49.9 | −0.3 / 0.9 / −27.8 | 0.002 |
| always_check_call | 1.000 | 9.90 [9.08; 10.76] | 0.42 | 39.9 | 0.0 / −7.9 / −0.0 | 0.002 |
| equity_rule (эвристика коуча на заданном диапазоне) | 1.000 | **0.89** [0.75; 1.03] | 0.74 | 15.6 | 8.7 / −2.2 / 32.9 | 0.8 |
| imitation_mlp (numpy, обучен на 18 553 train-примерах) | 1.000 | 1.61 [1.46; 1.79] | **0.84** | **8.5** | 7.9 / 3.3 / 12.6 | 0.04 |

**Вывод реестра: кандидат `imitation_mlp` отклонён.** Парный CI разности потерь EV (baseline − кандидат) = [−0.93; −0.54] % банка по 72 спотам: улучшение по EV не подтверждено, наоборот хуже. Метрики расходятся (лучше по совпадению с решателем и эксплуатируемости, хуже по потере EV и против station/maniac), поэтому «улучшения» нет. Активной осталась `v0_equity_rule`; откат проверен тестом.

Важное:
* **imitation_mlp — заглушка конвейера, не LoRA.** Она доказывает, что цепочка «данные → обучение → отложенный тест → сравнение с базой → решение реестра → откат» работает и умеет отклонять. Про дообучение языковой модели она ничего не говорит.
* Эталон — равновесие **абстрактной игры** (малый набор размеров, один рейз), а не полного NLHE; «потеря EV» и «эксплуатируемость» точны только внутри этой абстракции. Эксплуатируемость полной игры не вычислялась (невычислима).
* EV против фиксированных соперников точный (дерево целиком) и относится к реке с заданными диапазонами; это не прогноз выигрыша в реальной игре.
* Тестовых бордов 72: доверительные интервалы это отражают; победа в нескольких раздачах доказательством не считается.

## NOT_RUN / UNVERIFIED
* Обучение LoRA, выбор и сравнение базовых моделей, сравнение базы и адаптера: нет torch/peft/GPU/весов, Hugging Face недоступен. Готово: экспорт SFT, `lora_train.py --dry-run` (проверен тестом), `env_check.py` (в контейнере даёт `NOT_READY`), клиент `OpenAICompatPolicy` (loopback, проверен на поддельном сервере: корректный ответ, мусор, попытка изменить сумму).
* Windows/AMD: возможность файнтюна **не проверена**; наличие инференса её не доказывает. Нужен запуск `train/env_check.py`, затем smoke train (20 шагов) на вашем ПК.
* Живой Poker Train: маршрут к модели **неприменим по умолчанию** — модель heads-up river, а зрение пока не доказывает число соперников, позицию и историю улицы; диапазоны не наблюдаются и подставляются вручную (помечены «предположены»). Поэтому в живом тренажёре остаётся эвристика, пока не будет heads-up формата и чтения позиции/истории.
* Другие форматы (префлоп, флоп/тёрн, мультивей): не затрагивались.
