# Макеты владельца vs текущий терминал (17.10.2026)

Числа в макетах вымышлены (130 конфликтов, $2.72T, котировки, бюджеты). Терминал показывает только то, что приходит из источников.

| Блок макета | Сейчас в терминале | Источник / что нужно |
|-------------|--------------------|----------------------|
| Карта мира с горячими точками | Карта стран Natural Earth (177 стран), закраска по погибшим UCDP 2024 и по открытым тендерам; зум и клик по стране (делается) | Natural Earth (public domain), UCDP GED 25.1. Онлайн-подложка: MapLibre + OpenFreeMap (без ключа) |
| Слой «Conflict Intensity» | Есть: 58 стран, 28 816 событий 2024 года | UCDP — данные годовые; свежие события требуют ACLED (ключ + лицензия) |
| Слой «Procurement Activity» | Есть: тендеры по странам (97 стран с данными) | TED, ISVZ (Чехия), World Bank |
| Слои Defense Spending / Sanctions / Supply Routes | Нет | SIPRI (бюджеты, файл без API), санкции по странам — EU sanctions map; маршруты поставок — нет открытого источника |
| Панель страны (Ukraine: интенсивность, длительность, погибшие, беженцы) | Погибшие/события/конфликты UCDP, тендеры страны | Беженцы — UNHCR API (без ключа, не подключён) |
| Таблица активных закупок Easy/Medium/Hard | Есть: реальные тендеры, классы, fit, фильтры | — |
| AI Opportunity Analysis (85%, рекомендации) | Есть ИИ-подсказка (облачная бесплатная модель) + детерминированные проверки; без «процента выигрыша» — это запрещено ТЗ | Локальная модель Боссмана — по выбору владельца |
| Companies in this sector (котировки) | Нет | Рыночные данные (платные или ограниченные API) — решение владельца |
| Defense Budgets (Top 5) | Нет | SIPRI Military Expenditure Database (годовой файл) |
| Recent Contract Awards | Частично: USAspending (США) | TED contract award notices, World Bank awards — можно добавить |
| Таймлайн Oct 2023 – Oct 2026 | Нет | Нужны многолетние ряды (UCDP по годам — есть в GED) |
| Поиск, уведомления, профиль | Поиск по тендерам есть; уведомления — нет | Пульт Боссмана |

Военные контракты из макета (артиллерия, ПВО, HIMARS) в терминале помечаются флагом лицензии и не поддерживаются для подачи: первая вертикаль — топливо, продукты, логистика.
