# Чек-лист владельца (Windows) и откат

1. Запуск: `scripts\Start-WarTerminal.ps1` (DEMO) или `-Live` (читает публичные источники). Откройте `http://127.0.0.1:8830/`.
2. Токены: `%USERPROFILE%\.war-terminal\tokens.json`. Вводите `owner` только вы; Боссману нужен только `analyst` (он читает файл сам).
3. Проверьте водяной знак: «DEMO / NOT LIVE» должен исчезнуть только после первой успешной загрузки реального источника.
4. Профиль компании: заполните (страна CZ, `registered`, CPV-возможности, лимит капитала) -> запрос одобрения -> одобрите в разделе «Одобрения».
5. Курсы валют вносит человек (раздел Finance/FX): приложение не подставляет курс само.
6. Санкции: загрузите EU/OFAC список (раздел Compliance, `/sanctions/import`) с версией и датой; без него проверка контрагентов = REVIEW_REQUIRED.
7. Ничего не отправляйте заказчикам и поставщикам: приложение этого не умеет, а юридическая проверка и ваше решение обязательны.

## Откат
- Остановить: закрыть процесс `python -m warterminal` (или кнопка остановки сервиса в Боссмане).
- Вернуть состояние: данные лежат в одной папке (`%USERPROFILE%\.war-terminal`): переименуйте её — приложение создаст чистую БД. Бэкап = копия `war.db`.
- Отключить Боссман-прокси: удалить `command-center/bcc/features/war_terminal.py` или не запускать приложение — прокси вернёт 503 `WT_SERVICE_DOWN`.
- Ветка `feat/war-procurement-terminal-v1` не влита в `main`; откат слияния = revert merge-коммита.
