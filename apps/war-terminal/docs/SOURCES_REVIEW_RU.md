# Источники для обзора (проверка 17.10.2026) и обучение моделей

Проверка достижимости: HTTP-запрос к главной странице и API каждого источника с этой машины. Код 200 = страница существует; это НЕ проверка
условий использования, лицензии и пригодности данных — они отдельный шаг при подключении.

## Обучение моделей Боссмана
- Решения владельца (`go/no_go/watch` с причинами) и реальные исходы (won/lost/margin) пишутся в `decisions/outcomes`; DEMO не принимается.
- `GET /learning/dataset` (owner) отдаёт JSONL без персональных данных для оценки и дообучения локальных моделей Боссмана.
- Калибровка честно пишет «данных недостаточно» при n<20 на класс; предложение весов требует n>=30 и одобрения владельца; сами гейты не обучаются.
- ИИ-подсказка (`use_ai`) — только аналитика и черновик; расхождение с детерминированным классом помечается `ai_disagreement`.
