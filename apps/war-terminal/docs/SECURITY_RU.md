# Безопасность War Terminal: модель угроз и меры

| Угроза | Мера | Проверка |
|--------|------|----------|
| Подача заявки/контакт/закупка без юриста и владельца | не реализованы; `/actions/*` -> 403 и запись в аудит | `test_bid_contact_and_purchase_actions_are_never_available` |
| Подмена записи аудита | хеш-цепочка SHA-256, `/audit/verify`, индикатор в `/health` | `test_audit_chain_detects_tampering` |
| Повышение прав | токены ролей, сравнение constant-time, 401/403 | `test_roles_are_enforced` |
| Изменение профиля/весов без владельца | журнал одобрений, решает только owner | `test_profile_change_waits_for_owner_approval...` |
| DEMO принят за реальное | `demo=true`, водяной знак, не идёт в обучение | `test_demo_data_is_always_marked...`, `DEMO_NOT_LEARNABLE` |
| Утечка секретов в промпт/логи | модель получает только публичные факты тендера, редактирование email/телефона/IBAN; ключи только в env | `test_ai_adapter_is_advisory...` |
| Подлог/сокрытие конечного пользователя | жёсткие проверки + ссылка на юридическое заключение для военной номенклатуры | `test_controlled_goods_never_pass...` |
| SSRF/произвольные URL | коннекторы ходят только на фиксированные официальные URL; пользовательских URL нет | код `connectors/*` |
| Обход санкций | seed-эмбарго = BLOCKED, санкционный список = BLOCKED при точном совпадении, возможное совпадение = ручная проверка | `test_sanction_exact_match_blocks...` |
| Внешний доступ | сервис слушает только 127.0.0.1; внешний доступ — только после OIDC | `cli.py` |
| Вредоносные строки из интернета в интерфейсе | экранирование в UI (textContent) | проверка при ревью UI |
| Тактическое использование геоданных | карта — регионы и новости для коммерческого контекста; целеуказание и движение сил не поддерживаются | текст `safety` в `/conflicts` |

## Остаточные риски (не закрыты)
- Seed-списки юрисдикций не верифицированы юристом (`SEED_VERIFIED_AT=None`); санкционные списки не загружены по умолчанию.
- Вложения тендеров не анализируются: проверка «документы» всегда на человеке.
- Нет шифрования БД на диске и теста восстановления бэкапа; нет сканирования зависимостей/SBOM в CI.
- Токены лежат в файле пользователя; для production нужен менеджер секретов и OIDC.
