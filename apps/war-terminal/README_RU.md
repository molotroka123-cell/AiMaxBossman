# Bossman War & Procurement Terminal (v0.1)

Отдельное приложение внутри монорепозитория Bossman: терминал госзакупок, контекста конфликтов и оценки реализуемости для будущей
компании владельца. Первая вертикаль — **невооружённые, неконтролируемые товары**: топливо/энергия, продукты, логистика; старт из Чехии.
Контролируемая номенклатура — только исследование и юридическая проверка.

## Что это и чем управляется Боссманом

- Своё приложение: свой процесс (порт 8830, только loopback), своя БД SQLite, свой токен-файл, свой интерфейс `/ui/`.
- Боссман влияет через версионированный API `/api/v1` с ролью **analyst**: анализ тендера (dry-run), проверки, расчёт cashflow, черновик
  чек-листа, новости. Решения (одобрения, профиль компании, подписи проверок, обучение) остаются у человека с токеном owner.
- Для моделей Боссмана зарегистрированы 5 read-only инструментов `war_terminal.*` (см. `command-center/bcc/features/war_terminal.py`).

## Запуск (Windows, владелец)

```powershell
cd <репозиторий>\apps\war-terminal
python -m pip install -e .[tls]            # fastapi, uvicorn, httpx, truststore
python -m warterminal --port 8830          # DEMO-режим, внешние источники ВЫКЛЮЧЕНЫ
python -m warterminal --port 8830 --live   # включает чтение публичных источников (TED и др.)
```
Токены ролей создаются при первом старте в `%USERPROFILE%\.war-terminal\tokens.json` (viewer, analyst, compliance, owner). Откройте
`http://127.0.0.1:8830/`, введите токен роли. Ключ SAM.gov — переменная `SAM_API_KEY` (бесплатный, личный).
Локальная модель: `WAR_TERMINAL_AI_URL` (например `http://127.0.0.1:11435/v1`) и `WAR_TERMINAL_AI_MODEL`; без них ИИ-подсказка честно пишет NOT_CONNECTED.

## Принципы, закреплённые в коде и тестах

1. DEMO никогда не выдаётся за реальное: все синтетические записи `demo=true`, на экране водяной знак, в обучение они не принимаются.
2. Неизвестное критичное = `REVIEW_REQUIRED`, не `PASS`. Оценка fit — внутренняя эвристика, а не вероятность победы.
3. Жёсткие проверки (санкции, контролируемые товары, срок, допуск, документы, контрагенты) детерминированы; модель их не меняет.
4. Любая запись про риск проходит журнал одобрений и хеш-цепочку аудита; подача заявок, контакт с контрагентами и закупка контролируемых
   товаров НЕ реализованы (`/actions/*` всегда 403).
5. Правило владельца по капиталу: до 50 000 USD; выше — только состыкованная сделка (подтверждённый заказ + подписанный контракт с поставщиком
   + чистая санкционная проверка) и одобрение владельца.
