# Slicer integration

ELEGOO provides Neptune 3 Plus support in ELEGOO Cura.

Do not ship a fabricated vendor definition. On the target machine locate the
actual installed ELEGOO Cura/Cura resources, record version/checksum and use
that definition with CuraEngine.

3MF should come from a real supported slicer/export path rather than a fake
conversion.

Future OrcaSlicer/PrusaSlicer adapters should not alter the CAD core.
