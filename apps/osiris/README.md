# OSIRIS

Локальная OSINT-панель для публичных сведений об организациях и графа связей.

Не часть `bossman-core`. Импортов BOSSMAN нет. Слушает только `127.0.0.1`.

## Жёсткие границы

- только открытые источники и только разрешённым источником способом
- уровень 0 закрыт наглухо (слитые базы, чужие сессии, обход капчи/paywall/anti-bot, биометрия, слежка за частным лицом, закрытые профили)
- уровень 1 — именной грант: дата, срок, источник/субъект, причина, журнал, автоистечение
- факт без паспорта не сохраняется

## Запуск

```bash
cd apps/osiris
python -m venv .venv
# activate
pip install -e ".[dev]"
osiris
```

По умолчанию: `http://127.0.0.1:8920`

Данные: `%USERPROFILE%\.bossman-apps\osiris\` или `OSIRIS_DATA`.

## Тесты
