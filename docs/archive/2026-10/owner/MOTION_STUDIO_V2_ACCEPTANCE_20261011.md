# Motion Studio V2: матрица приёмки (11.10.2026)

Задача владельца 11.10: «V2 в редакторе не подтверждена… доводим до V2 Motion Studio». Источник состава: раздел 5 мастер-промпта:
импорт разрешённых материалов -> сегменты и маски -> предпросмотр -> покадровый контроль -> чистые варианты -> эффекты ->
рендер и экспорт -> manifest и восстановление после сбоя.

Что считается «редактором V2» (сверено с кодом, а не с названиями):

| Часть | Код | Роль |
|---|---|---|
| Genjutsu-панель (страница «Прямой генератор») | `command-center/ui/pages/genjutsu.js`, `genjutsu_core.js`, `bcc/direct_gen/genjutsu.py` | импорт кадра/видео, покадровый переход, маски зон, перекраска, до/после, чистые варианты, manifest, датасет |
| Motion Studio (страница) | `ui/pages/motion_studio.js`, `bcc/features/motion_studio.py`, `tools/motion_studio/make_video.py` | сценарий -> предпросмотр -> полный рендер -> проверка файла -> manifest |
| Гейт титров | `tools/trend_edit/title_guard.py` | геометрическая проверка «титр не над лицом» |
| Video Studio (отдельная страница) | `ui/pages/video_studio.js`, `bcc/video_studio/*` | монтаж, разрезание по кадру; в прогон V2 не входила |

Правило статусов: WORKS только при прогоне с rc 0 и сохранённым артефактом; PARTIAL / MISSING с точной причиной.
V2 «подтверждена» только если каждая строка WORKS или явно отложена владельцем.

## Как прогонять

Один процесс, без `-n`, GPU только на один кадр масок:

```
python tools/studio_v2_e2e.py --evidence C:\Users\asd\Bossman\evidence\studio-v2-20261011 --json docs/owner/runs/STUDIO_V2_E2E_20261011.json
python -m pytest -q -p no:cacheprovider tests/test_title_guard.py
cd command-center ; python -m pytest -q -p no:cacheprovider tests/test_motion_studio_manifest.py tests/test_motion_studio_ui.py tests/test_motion_studio_bundle.py tests/test_direct_gen_genjutsu.py
cd command-center/ui/tests ; node --test genjutsu_v2.test.mjs genjutsu_core.test.mjs
python tools/mp21_dataset_counters.py docs/owner/runs/STUDIO_V2_COUNTERS_20261011.json
```

Харнесс поднимает настоящий backend (`python -m bcc`, отдельный процесс) на свободном порту с одноразовой папкой данных
(НЕ :8801 владельца), открывает UI в headless Chromium (Playwright), снимает экраны и пишет JSON с результатом по каждой
строке. Исходное видео (`video-testset-private\ref-clip-05.mp4`, окно 2 с, VP8, 25 к/с) и кадры содержат изображение
человека из локальных источников владельца: они и снимки лежат ВНЕ git (`C:\Users\asd\Bossman\evidence\studio-v2-20261011`),
в git только JSON с хэшами и счётчиками.

Окружение прогона: Python 3.12.10, Chromium из Playwright (build 1243), ffmpeg из WinGet, `scipy 1.18.1` доустановлен
в пользовательский Python (без него Motion Studio показывал «не хватает scipy», `ready_*: false`).

## Вердикт

**V2 НЕ подтверждена целиком.** Из 15 строк: WORKS 12 (строки 1-8 и 10-13, подтверждены
прогоном), PARTIAL 2 (9, 14), MISSING 1 (15). Точный список того, что блокирует «подтверждена»:

1. Строка 15: нет эффекта на клипе из редактора. Нужна фоновая задача «применить образ к клипу» (кадры -> `hair_v2` ->
   сборка -> проверка файла -> manifest) с порогами E/L/S/V/C/T из `HAIR_MASK_V2_20261010.md`; их измерение на реальных
   клипах ещё не записано. Это работа на GPU/CPU, отложена из-за занятого GPU.
2. Строка 9: гейт титров нужно подать в сборку промо (`build_promo_v2.py`) после того как видео-агент закоммитит
   `edit_core.py`/`fx.py`, и подать детектор лиц (`yolo_face`) по кадрам.
3. Строка 14: авто-нарезка на сегменты и перенос масок между кадрами в редакторе отсутствуют (есть только разрез по кадру
   в Video Studio и ручной переход по кадрам).

Не входило в эту приёмку (и не заявляется): локальный аудит готовых роликов на известные дефекты (дрейф личности, плоская
маска волос, рука над лицом, свет против неона, титры над лицом) через `tools/video_gate/artifact_audit.py` — он требует
интерпретатор и модели FaceFusion на GPU, который занят; ни одно из этих измерений в этом проходе не делалось.
