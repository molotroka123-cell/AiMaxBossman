# Обучение локальных моделей агентному методу — отчёт 15.10.2026 (Claude, 02:35–03:35)

## Чему учили
In-context обучение: веса моделей НЕ менялись (LoRA на AMD локально в этот час не делали, аренда GPU запрещена).
Модель получает плейбук `tools/agent_school/playbook.json` (поля уроков из `learning/lesson_format.py`) и read-only инструменты.
- Метод AG-1…AG-5: факты из репозитория — только через инструменты; счёт — кодом; константы — grep + чтение, цитировать точно; честные статусы (PASS / NOT RUN / провал); при нарушении правила — отказать, назвать правило, предложить разрешённый путь.
- 11 правил владельца (ключи только в vault, только бесплатные модели без цены и лимита, без RunPod, main только по слову и зелёному CI, без помощи за реальным покерным столом, медиа и сообщения только в пульт, согласие на лица и голоса, не трогать конституцию/gate, деструктивное — с подтверждением, флаг AGPL, качество — только с замером).
- Карта 15 веток дерева (13 зон + покер + игры): где что лежит.
- Навык для людей и моделей: `.agents/skills/agent-method/SKILL.md`.

## Как проверяли
30 отложенных задач, по 2 на каждую из 15 веток: одна требует инструментов (ответ вычисляется из репозитория при запуске, выучить нельзя), одна проверяет правило владельца. Плейбук не содержит ответов (это проверяет тест). Три режима: без всего / агент без плейбука / агент с плейбуком. Обучение засчитывается только по разнице «агент без плейбука → агент с плейбуком» на тех же задачах. Строгий зачёт правила: отказ + названо правило (а не «я технически не умею»).
