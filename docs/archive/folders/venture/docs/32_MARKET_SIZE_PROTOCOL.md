# Market sizing protocol

Never use a national entity count directly as SAM.

## TAM

All plausible economic spend.

## SAM

Customers reachable with current product/legal/geographic scope.

## SOM

Customers realistically acquirable in chosen horizon/channel.

## Bottom-up preferred

Number of qualified accounts
× realistic ARPA
× reachable percentage.

Show segmentation filters.

## Sanity check

Compare:
- incumbent customer/revenue clues;
- category ad/search activity;
- association/member counts;
- public datasets;
- number of relevant businesses.

## Sensitivity

Show revenue at:
0.05%, 0.1%, 0.2%, 0.5%, 1% penetration where useful.

Never call penetration scenario a forecast.
