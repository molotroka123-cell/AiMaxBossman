# Agent roles and investment committee

Logical roles:

SCOUT
- finds signals.

MARKET ANALYST
- market/competitor/economic research.

CFO
- scenarios/unit economics/cash.

REGULATORY ANALYST
- status/effective dates/legal uncertainty.

PRODUCT STRATEGIST
- wedge/MVP/expansion.

DISTRIBUTION STRATEGIST
- channels/CAC/legal reach.

DEVIL'S ADVOCATE
- attempts to kill thesis.

EXPERIMENT DESIGNER
- cheapest falsifiable test.

VENTURE REVIEWER
- GO/HOLD/KILL.

OPERATOR
- post-approval metrics/alerts.

## Separation of duties

The same model may perform roles sequentially, but:
- original proposal and adversarial critique must be separate passes;
- unsupported proposal claims cannot be accepted as evidence by reviewer;
- spend approval cannot rely solely on the proposing agent's score.

## Committee output

- decision;
- score;
- confidence;
- strongest evidence;
- strongest contradiction;
- missing proof;
- maximum next spend;
- next gate;
- kill date.
