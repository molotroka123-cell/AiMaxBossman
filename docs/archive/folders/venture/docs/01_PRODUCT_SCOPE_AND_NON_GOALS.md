# Product scope and non-goals

## Foundation scope

This phase defines:
- commercial objects;
- evidence standards;
- score;
- stage gates;
- economics;
- approvals;
- legal transition;
- metrics;
- venture-review process;
- learning process.

## Explicitly outside this ZIP

- app implementation;
- database code;
- bank connectors;
- ad platform connectors;
- invoicing code;
- autonomous payments;
- OpenClaw bridge;
- autonomous company registration;
- automatic tax filing;
- legal opinion engine;
- unsolicited outreach engine.

## Future system boundary

BOSSMAN remains control plane.

Venture Engine becomes a domain feature:
- asks existing research/browser/code agents for work;
- stores commercial hypotheses/evidence;
- requests approvals;
- reads actual portfolio metrics;
- proposes capital allocation.

Execution systems remain replaceable.
