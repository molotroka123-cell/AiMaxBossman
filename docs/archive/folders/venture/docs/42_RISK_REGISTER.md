# Risk register

| Risk | Leading indicator | Threshold | Default response |
|---|---|---|---|
| Code-first behavior | build days before paid proof | >10 days without validation | freeze build |
| CAC failure | payback | >9 months low-ticket | stop scaling |
| Retention failure | M1 paid retention | materially <80% early target | interview/churn review |
| Margin failure | contribution margin | <60% structural | redesign/kill |
| Support trap | support minutes/account/week | >15 for self-serve | automate/reprice |
| Customer concentration | top account share | >25% warning | diversify |
| Channel concentration | one source of new customers | >70% | diversify |
| Vendor concentration | single critical vendor | no fallback | contingency plan |
| AI cost shock | cost/account | +20% | routing/pricing review |
| Regulatory change | planned rule delayed/changed | material | HOLD affected feature |
| Cash runway | months | <6 | cut spend |
| VAT proximity | forecast | <90 days | professional review |
| Metric fraud | provenance missing | any material KPI | block decision |
| Spam risk | source lacks valid basis | any campaign | DENY |
| Too many ventures | builds active | >1 initially | stop new builds |
| Sunk cost | rationale cites past spend | present | independent review |

Risk should be assigned:
owner, state, probability band, impact band, mitigation, next review.
