# UX-прогон 14.10.2026 от лица владельца (сборка cb6df08e → c8ed1047)

Прогон веб-интерфейса Bossman (`http://127.0.0.1:8801`) так, как это делает владелец: вход по токену, переходы по
разделам, заполнение форм, кнопки. Браузер вёл локальный скрипт Playwright (headless Chromium); токен он читал из
локального файла, в журнал и сюда токен не попадал. Скриншоты сделаны во время прогона.

Личные материалы сюда не входят: ни кадров результата замены лица, ни фото-референсов, ни сырого журнала тестового
периода (см. дефект 4).

## Найденные дефекты

1. **Карточка задачи замены лица** показывала «seed undefined · undefined×undefined». Исправлено в `d718f3ca`
   (пресет · фото · кадр). UI-тесты: 72 passed.
2. **Шрифт**: интерфейс запрашивал «Inter var», но шрифт не поставлялся; Windows подставлял заголовочный
   «Segoe UI Variable Display» для мелкого текста. Исправлено в `c8ed1047` (Inter Variable 4.1 локально, OFL).
3. **Журнал тестового периода переполнен и молчит.** `session-log.jsonl` достиг ~33,5 МБ (138 702 строки с 21.09);
   с 05:00 пишется только `log.full`, а плашка продолжает показывать «идёт запись действий» и растущий счётчик.
   Сегодняшние действия в журнал не попали. Не исправлено: нужна ротация по сессии и честная плашка «запись
   остановлена».
4. **Кнопка «Отправить в GitHub» публикует весь журнал**, а не текущую сессию: рассуждения моделей, тексты задач,
   пути на диске за месяц. Репозиторий публичный. Кнопку в этом прогоне не нажимали; публиковать журнал в таком виде
   нельзя без фильтра «только эта сессия, только UX-события». Не исправлено.
5. **Poker Vision не стартует вместе с Bossman** — нужен ручной «Запустить сервис». Не исправлено.
6. **26 задач с ошибкой** на главной висят с прошлых прогонов (`computer.act` launch calculator). Не разбирались.

## Что не проверено

- Живая сессия Poker Vision на столе (нет открытого стола/записи).
- Мобильная вёрстка и тёмная тема после смены шрифта.
- Результат замены лица оценивается отдельно и сюда не кладётся (личное видео).
