## Проверено — дефектов класса не найдено

- **GET /api/web/episodes** (features/web_research/api.py:458-490): сортировка ДО обрезки, возвращает `total`+`shown` — эталонный образец честного списка; ирония в том, что этот паттерн не перенесён на остальные ручки.
- **GET /api/runs/{id}/events** (api.py:837-844): курсорная пагинация по `after` + кап 1000 — корректно.
- **GET /api/tasks?mission_id + before_id в mission_console** (ui/pages/mission_console.js:314-315): единственное место UI, где курсорная догрузка реализована.
- **/api/apps, /api/skills, /api/missions, /api/models, /api/agents, /api/providers, /api/schedules, /api/coding-sessions** — без капов (риск только перф, скрытия хвоста нет).
- **Страницы Skills/Benchmarks/Governor/Healing/Tasks** — error-контракт корректен (errorBanner/errorNote на rejected, blank только на fulfilled).
- **activity (api.py:601-603 + events.py:103-109)**: desc-лента с ретеншеном — усыщение по дизайну осмысленно, бейджей «полный журнал» не рисует.
