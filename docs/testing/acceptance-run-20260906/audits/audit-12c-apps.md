## Поведение при «Запустить» (флаг/health/409) — верифицировано

- Без `BOSSMAN_APPS_CONTROL_ENABLED=1`: `/start` и `/stop` → 409 c подсказкой установить флаг (apps_control.py:498-503); UI честно деактивирует кнопку и объясняет (apps.js:291-297) — корректно, не баг.
- С флагом: port_busy → 409 «порт занят процессом, которого BOSSMAN не запускал» (apps_control.py:408-413) — честно; но из UI эта ветка почти недостижима, т.к. чужой процесс заранее сделает карточку «запущенной» (A12c-03).
- Ожидание готовности: `_wait_ready` → проба health из `_launch_card` (тот же `_probe`, apps_control.py:356) — наследует ложный green A12c-03 для «ready» исхода (чужой процесс успел ответить раньше смерти нашего — маловероятно, но возможно при гонке).
- Остановка: гасится только собственный pid; чужой — сообщение ok:true (см. A12c-03).
