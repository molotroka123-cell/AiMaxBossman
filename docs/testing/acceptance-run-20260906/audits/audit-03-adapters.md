## Что проверено и НЕ нашло проблем (чтобы не искать повторно)
- **app_launch allowlist/argv-инъекция**: deny-by-default, canonical_app с forbidden-chars (`/\:;&|<>"'` + `%$*?!`, длина<=64), resolver только в System32/SysWOW64/Windows + `shutil.which` с проверкой `_within` после resolve; argv из одного элемента, без shell, stdin/out/err=DEVNULL. Аргументы от планировщика отсутствуют как класс.
- **policy обходит**: args["semantic"] не может СНИЗИТЬ подтверждение (только добавить, policy.py:94-107); вводимые текст не участвует в лексиконе улик (анти-инъекция, policy.py:72-84); bossman-surface токены deny.
- **BROWSER navigate схема**: двойная проверка http/https (policy.py:144-147 + toolkit/browser.py:398-401), blocked-домены, _blocker_check. Redirect после goto на blocked-домен перепроверяется только на СЛЕДУЮЩЕМ действии — за рамкой adapters, отмечено в A3-01-контексте.
- **Manager CAS/OwnerStateChanged**: owner-команды не затираются шагом; вердикт «approved action stale» корректен (вне области, см. FIXED-OP-PARK-001).
- **Screenshot naming**: time.time_ns() коллизий не даёт; retention in-window работает в пределах процесса.
