## Проверено — дефектов НЕ найдено (фиксации для будущих аудитов)

- **Сохранение DOM-спецов** (эмпирически, byte-for-byte): DOCTYPE с внутренним подмножеством `[<!ENTITY…]>`; комментарии (включая conditional `<!--[if IE]>…<![endif]-->`); PI `<?php…?>`; CDATA `<![CDATA[…]]>`; entity/charref (`&amp;`, `&#x1F600;`, `&nbsp;`, `convert_charrefs=False`); содержимое `<script>` со строками `"</div>"` и JSON-LD; `<template>`; SVG `viewBox`/`linearGradient` — и при правке соседа (verbatim), и при правке самого SVG (rebuild из полей, `attr_case`); астральный Unicode в тексте; оборванный хвост документа (`absorb`); итеративный обход без RecursionError.
- **Path-инъекции через project id**: все маршруты принимают `pid: int` (FastAPI-конвертер), `_pdir` → `str(int(pid))` (`web_designer.py:71-72`), `_version_path` → `v{int(version)}.html` — обхода каталога нет.
- **PICKER_JS-инъекция**: `PICKER_JS` не содержит `</script`; вставляется текстовым узлом и сериализуется raw — преждевременное закрытие тега невозможно; инжект не мутирует хранимый код (`_strip_bd_ids`/bd_id в поле узла).
- **MAX_HTML_CHARS**: единая точка проверки `_save_code` → 413 на всех путях (включая ответ модели и откат) — покрытие тестом `test_oversized_document_is_refused_on_every_write_path` подтверждено; схемные лимиты согласованы. Замечания A9-01/A9-12 — см. таблицу.
- **Stale selection/edit (base_version) на сервере**: `edit_project` сверяет и версию, и ожидаемый тег (`LookupError` → 404/409), `ai_edit` фиксирует базу до await и проверяет при записи — серверная часть корректна; дефекты живут на клиенте (A9-06/A9-07) и в `_sync_meta_fields` (A9-09).
- **postMessage снаружи**: `ev.source !== frame.contentWindow` отсекает чужие окна — прямая подделка извне невозможна; остаточный риск — через сам кадр (A9-08).
- **Viewport** (`web_designer_viewport.js`): валидация схемы/диапазонов, изоляция ключей по проекту, отсутствие writes в HTML проекта — корректно; `saveViewport` валидирует до записи, повреждённый localStorage не ломает редактор.
