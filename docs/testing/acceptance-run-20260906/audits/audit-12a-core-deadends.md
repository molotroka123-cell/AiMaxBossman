1. **UI ЕСТЬ.** `http://127.0.0.1:8700/` и `/ui` отдают `bossman-core/ui/index.html` («Bossman Control»: 7 панелей Пульт/Агенты/Модели/Изменения/Подтверждения/Расходы/Проекты, WS-обновления, PWA manifest+sw). `api.py:522-528` монтирует `/ui` (StaticFiles html=True) и `/` → FileResponse, только если `UI_DIR` существует; `Dockerfile:26` копирует `ui` — в docker-деплое тоже работает. Но каждый API-вызов требует device-токен Stage 6 (prompt на 401, index.html:62-78): без токена владелец видит только оболочку с ошибками во всех панелях.

3. **`backend_patch/INTEGRATE.md` НЕ существует** ни в одной точке репо (grep по имени файла и каталога — 0). Каталог `bossman-core/ios/` существует (BossmanRemoteApp/BossmanRemoteKit + project.yml). Шаг 1 «Fastest path» в INSTALL.md мёртв.
4. **Approvals UI ЕСТЬ**: `ui/index.html:206-225` панель «Подтверждения» с кнопками Да/Нет + бейдж на всех вкладках + WS-обновление; плюс remote-app (`remote-app/app.js:99-109`), iOS (`ios/.../BossmanAPI.swift:62-68`), REST `/approvals`, `/remote/approvals`.
