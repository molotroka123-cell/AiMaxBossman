# Пакет аудита для Claude — НЕ Windows-приложение

1. Прочитать AUDIT_RU.md.
2. Прочитать MASTER_PROMPT_RU.md и выполнить его в актуальном AiMaxBossman.
3. Для проверки новых находок: `python reproduce_findings.py` в этой папке.

В source/ две точные копии проверяющего кода с GitHub. Скрипт сверяет их Git blob identities до исполнения. Он использует только stdlib, TemporaryDirectory и синтетические subprocess/evidence fixtures: никакой Windows, реальной модели, сети или записей в репозиторий.

Нельзя копировать synthetic FROZEN/PASS из reproduction_results.json в реальные артефакты приёмки. Они показывают ошибки в принятии некорректных входов.

Никаких автоматических изменений репозитория этот пакет не делает. После исправлений upstream runner должен воспроизводить иной ожидаемый результат; перенесите случаи как нормальные регрессионные тесты, а не ослабляйте утверждения.
