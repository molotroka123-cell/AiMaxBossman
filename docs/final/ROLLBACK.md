# Откат

Документ отвечает на один вопрос: как вернуть рабочее состояние, если правки
этого прогона окажутся хуже, чем то, что было.

## Точки возврата

| Что | SHA | Чем ценна |
|---|---|---|
| Начало прогона (канонная ветка) | `ef5abca89ad6e5a50025daaa04d416f7480c6080` | состояние до всех правок этого прогона |
| Опорная заморозка владельца | `910ca901ddcd84c13d65f9246dfec394088c29bf` | ранее принятый владельцем exact SHA |
| Продуктовая линия (соседняя ветка) | `5b673262dbee69c1f460253ba874111fad95cbfb` | гибридные порты, File Intelligence, OpenHands, один Windows-архив |

Полный список с назначением — `docs/final/KNOWN_GOOD_SHAS.json`.

## Откат целиком

```
git fetch origin claude/bossman-control-v03-43igbk
git checkout -B откат ef5abca89ad6e5a50025daaa04d416f7480c6080
```

Ветку владельца при этом НЕ перематывать силой: раздел 27 задания запрещает
затирать чужую работу. Откат живёт отдельной веткой, решение о её продвижении
принимает владелец.

## Откат по отдельности

Каждая правка этого прогона — самостоятельный коммит и снимается независимо,
`git revert <sha>`:

| Коммит | Что вернётся | Чем это грозит |
|---|---|---|
| `28c2aaae` | тест колеса снова зовёт pip с `--no-build-isolation`; гейт задержки снова считает голый p100 | Command Center CI py3.12 снова красный; root-ci py3.11 снова красный на чужом срыве хранилища |
| `9a387477` | исчезает раннер удержания интеллекта | гейт остаётся красным и закрыть его снова будет нечем |
| `2f40d0cc` | исчезают документы памяти проекта | следующая модель снова начинает с нуля |
| `4dea03ab` | превью Video Studio снова mp4/H.264; тесты пикера снова кликают через `frame_locator` | превью не играется в поставляемом браузере; две приёмки снова красные |

## Что откатом НЕ лечится

* расхождение двух линий разработки — это не правка, а история; см.
  `docs/final/CURRENT_STATE.md`;
* красный гейт удержания интеллекта — он красный из-за отсутствия замера, а не
  из-за кода;
* отсутствие прогона на целевом железе.

## Проверка после отката

```
python scripts/verify_clean_install.py
python -m pytest tests -q
cd command-center && python -m pytest tests -q
```

Состояние считается восстановленным, только когда `CLEAN_INSTALL=PASS`.
Чекаут, который импортируется, но не ставится, доказательством не является.
