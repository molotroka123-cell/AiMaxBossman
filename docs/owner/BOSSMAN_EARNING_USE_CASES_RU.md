# Bossman: практические применения с заработком (11.10.2026)

Запрос владельца: «Создай минимум 3 практических применения Bossman с заработком».
Ниже четыре сценария, под каждый — что в Bossman уже есть (с привязкой к коду), чего не
хватает, первый шаг и честная оценка. Ни один из них не является подтверждённой выручкой:
это рабочие потоки, которые можно продать, когда указанные пробелы закрыты.

## 1. Сервис «AI-видео для блогеров»: face swap / смена персонажа в своих роликах

- **Кто платит:** блогеры и малые бренды, которым нужен ролик с их лицом/персонажем на
  основе трендового референса (вертикальный формат, 9:16, без растяжения).
- **Что есть:** `.agents/skills/video-face-swap-facefusion/` (FaceFusion через Bossman,
  pose gate, Gate 0/1 в `tools/video_gate/`), `tools/genjutsu/film.py` (Wan2.1 VACE,
  локально), V2-пайплайн `tools/v2_pipeline/`, метрики сходства (11.10: среднее 0.70 по 172
  кадрам на IMG_0889, CPU, без облака). Политика: лица только с согласия, медиа не покидает
  ПК — это и продаётся как преимущество (приватность).
- **Чего не хватает:** GPU-стабильность (TDR, перезагрузка), автоматическая сшивка границ
  эффектов (11.10: «на границах эффектов лицо резко переключается»), прайс и форма заказа в
  пульте/Jeff, оценка ≥6 по каждому ролику (TZ Motion V2).
- **Первый шаг:** 3 бесплатных ролика знакомым блогерам за отзыв → цена за ролик 15–30 с.
- **Аналоги:** Higgsfield/Genjutsu делают это в облаке и дороже; локальная приватная
  обработка с метрикой сходства на каждом кадре — отличие, но не монополия.

## 2. Poker Vision: запись рук с экрана iPhone и разбор по GTO

- **Кто платит:** игроки в онлайн-покер (подписка/разовый разбор сессии).
- **Что есть:** `apps/poker-vision/` (распознавание стола, `recording_dataset.py` — импорт
  записей владельца, тесты), поток UxPlay → экран iPhone на ПК, 2 записи локально.
- **Чего не хватает:** независимая разметка карт (GLM-разметка отклонена, обучение NOT_RUN),
  held-out проверка точности, GTO-движок/солвер (открытый) и формат отчёта по сессии.
  Live-подсказки во время реальной игры на деньги запрещены правилами румов — продавать
  только пост-разбор и тренажёр.
- **Первый шаг:** точность распознавания карт ≥ 99 % на 500 размеченных вручную кадрах →
  отчёт «ошибки сессии» для 3 игроков.
- **Аналоги:** PokerTracker/Hand2Note — по hand history, а не по видео; разбор экрана
  мобильного приложения без HH — ниша, но нужна точность.

## 3. Калькулятор обменника / учёт сделок для криптообменников

- **Кто платит:** малые обменные пункты (ручной учёт в Excel/Telegram).
- **Что есть:** `bossman_shared/market_cases/` (кейсы сделок, периоды 21→20),
  `docs/evidence/orchestra-cloud/` — 30 граничных случаев от облачного QA, K1m6a-лента
  рынка (только paper), пульт для отчётов.
- **Чего не хватает:** импорт реальных сделок (CSV/Telegram), отчёт за период, сверка
  комиссий; юридическая проверка (в РФ/Казахстане обмен лицензируется).
- **Первый шаг:** 1 обменник-пилот, бесплатный месяц, цель — экономия 2–3 часов учёта в
  день → подписка.
- **Аналоги:** 1С, Google Sheets-шаблоны; преимущество — локальный ИИ, который сам ведёт
  учёт по сообщениям из Telegram.

## 4. Jeff как платный ИИ-ассистент в Telegram (паспорта клиентов)

- **Кто платит:** небольшие сервисы и эксперты, которым нужен бот с голосом, памятью и
  «паспортом» каждого клиента (стиль, история, задачи).
- **Что есть:** `bcc/pit/` (Jeff 2.0: паспорта, голос RUAccent/chatterbox, фото-распознавание,
  identity_guard), два бота (пульт owner-only, Jeff для всех), маршрутизация
  локальные → бесплатные облачные модели.
- **Чего не хватает:** биллинг (Telegram Stars/ЮKassa), лимиты на клиента, оферта и
  политика данных (см. `docs/owner/TELEGRAM_MONETIZATION_WORKFLOW_20261011.md`), SLA
  ответа без ПК владельца (нужна автономность после перезагрузки — делается сегодня).
- **Первый шаг:** 5 платных мест по подписке для знакомых экспертов; измерить
  retention 30 дней.
- **Аналоги:** много (Manybot, ChatGPT-боты); отличие — локальная приватность, голос
  владельца и паспорт клиента, но это нужно доказать удержанием, а не описанием.

## Что общее для всех четырёх

1. Выручка считается только по поступившим деньгам, не по «технически готово».
2. Личные медиа/данные клиентов не покидают ПК; в отчётах указывается, где что
   генерировалось (правило владельца 11.10).
3. Любой платный внешний сервис — только после явного «да» владельца.
4. Порядок запуска по готовности: 1 (видео) → 4 (Jeff) → 3 (обменник) → 2 (покер).
