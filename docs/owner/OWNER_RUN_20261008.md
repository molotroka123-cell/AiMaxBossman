# Запуск одной версии Bossman 08.10.2026 (ПК владельца)

Источник: `main` после слияния PR #98 (одна линия: green/tree-leaves 4a14c26c + прежний main + исправления 08.10).
Точный SHA, имя архива и SHA-256 — в последнем комментарии PR #98 и в итоговом сообщении Claude: этот файл
не может содержать SHA коммита, в котором он сам лежит.

Same-product контракт Terminal Run: CLI, окно и Telegram — один backend :8801, одни данные, память, модели, задачи и STOP.

## 1. Скачать и проверить архив

1. GitHub → Actions → «One-download Windows application» → прогон на нужном SHA → артефакт `bossman-windows-<SHA>`.
2. Внутри — `BOSSMAN-Windows-x64-<sha12>.zip`. Проверить хэш:
   ```powershell
   Get-FileHash .\BOSSMAN-Windows-x64-<sha12>.zip -Algorithm SHA256
   ```
   Должен совпасть с SHA-256 из комментария PR. Не совпал — не ставить.

## 2. Поставить (Switch) — со снимком и откатом

```powershell
cd <рабочая копия main>
pwsh -NoProfile -File tools\owner_one_bossman.ps1 -Action Switch -Sha <SHA-40> `
  -Archive <путь>\BOSSMAN-Windows-x64-<sha12>.zip -ArchiveSha256 <SHA256>
```

Switch по порядку: снимок текущего (процессы, задачи, ярлыки, конфиги) → `rollback.ps1` → распаковка рядом со старой
сборкой (старая не трогается) → мягкая остановка старых процессов (без force) → холодный бэкап данных с проверкой →
перенастройка Jeff/Пульта на один backend → задачи автозапуска → старт → ожидание `/health/live`.

Простой ~2–3 минуты. Ключи: `tools\keys_guard.py` сам возвращает пропавшие ключи из DPAPI-копии и обновляет копию
перед стартом backend (в логе одна строка `keys: OK (N names)`, значения не печатаются); Backup кладёт папки ключей
рядом с бэкапом данных. Вручную: `python tools\keys_guard.py verify` (0 — всё на месте, 1 — ключей не хватает, 2 — копии нет).
Новый ключ можно прислать в «Пульт» одной командой `/key OPENROUTER_API_KEY=...` — запишется только в локальный файл,
сообщение удалится, в ответе будут только имена.

## 3. Проверить после установки (5 минут)

| Проверка | Как | Ожидается |
|---|---|---|
| Та же версия | `curl http://127.0.0.1:8801/health/live` | `build_sha` = SHA из PR, не `SOURCE_IDENTITY_UNKNOWN` |
| Jeff отвечает | любое сообщение в Telegram | ответ локальной моделью |
| STOP | кнопка STOP или `bossman stop <задача>` (`--all` — глобальный STOP) | задача остановлена, Jeff жив |
| Пульт | отчёт/статус в Telegram | приходит в разрешённый чат |
| CMD | `Bossman CMD` → `status` | тот же backend :8801 |
| Ничего не потеряно | `python tools\local_completeness_manifest.py --root %USERPROFILE%\Bossman --out %USERPROFILE%\Bossman\handoff\local-manifest-20261008.json` | `COMPLETE` или список GAPS для переноса |

## 4. Откат

```powershell
pwsh -NoProfile -File <Evidence>\rollback.ps1            # путь печатает Switch: "Rollback: ...\rollback.ps1"
pwsh -NoProfile -File <Evidence>\rollback.ps1 -StartOld  # плюс запустить старую задачу Jeff
```

Откат снимает новые задачи автозапуска, возвращает конфиги Jeff/Пульта и ярлыки из снимка. Данные не удаляются.
