# Общий пульт: постоянные референсы и локальный промпт

## Команды

- `/refs` — состояние; `/refs on` — включить для будущих генераций до отмены; `/refs off` — выключить, оставив привязки; `/refs clear` — очистить привязки и выключить режим. Состояние зашифровано в существующем Store и переживает restart.
- Фото с `/ref 1` и `/ref 2` — заменить две группы референсов. Только владелец; собственные снимки или согласие человека.
- При активном режиме новое фото с обычной подписью или `/edit описание` — целевое фото + две группы передаются Qwen-Image-Edit. Изображения не отправляются в облако.
- `/create image описание` и `/create video описание` — выбранная локальная Qwen с `uncensored` в настроенном имени дорабатывает промпт; кнопки запускают исходный или предложенный вариант. Это идентификатор настроенной модели, не независимый сертификат отсутствия ограничений.
- `/img описание` использует активные референсы. `/video 1 описание` при активном режиме сначала создаёт фото по ним и только затем оживляет этот кадр. Это две реальные генерации, не прямое видео по четырём снимкам.
- `/cancel` — отмена генерации; `/stop` блокирует новые генерации. `/refs off` не отменяет уже запущенную задачу.

## Четыре снимка владельца

Исходники и высветленные копии остаются вне Git. Для локального теста четыре референса объединены в два листа (1+3 и 2+4); редактор получает цель первой, два листа следом. Его действующий предел — 3 входных изображения. Геометрия человека не дорисовывается при подготовке: яркость gamma=1.35, brightness=0.03; при компоновке высота листов 1280 px. Это не 4K и не восстановление новых деталей.

Если требуется полноценное LoRA-обучение, нужен отдельный датасет/базовая модель/независимые тесты. Привязка референсов не обучает веса и не доказывает точное воспроизведение тела или личности.
