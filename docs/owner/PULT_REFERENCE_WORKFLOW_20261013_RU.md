# Общий пульт: постоянные референсы до отмены

Активный контракт 13.10.2026; актуальная архитектура —
[Bossman agent](../v2.2-20261013/AGENT_ARCHITECTURE_RU.md), выбор моделей —
[MC22-16](../v2.2-20261013/GENERATION_MODEL_SELECTION_RU.md).
Исторические результаты не перенесены в текущий PASS.

## Команды и результат

- `/refs` — состояние; `/refs on` — включить для будущих генераций до отмены;
  `/refs off` — выключить, сохранив привязки; `/refs clear` — очистить и выключить.
- Фото с `/ref 1` или `/ref 2` заменяет соответствующую группу. Состояние хранится
  в существующем encrypted owner Store; restart проверяется отдельно.
- При активном режиме фото с `/edit изменение` использует цель и сохранённые refs.
  Обычная подпись может входить в edit напрямую; явные `/create image|video` вызывают
  существующий путь доработки промпта. Не считать, что Qwen вызывалась без receipt.
- `/img` использует refs; текущий `/video` с refs может сначала создать изображение,
  затем оживить его. Это две генерации, не обучение видео на четырёх снимках.
- `/cancel` отменяет текущую/ожидающую генерацию согласно существующему ownership;
  `/stop` запрещает новые действия. `/refs off` не отменяет уже начатый job.

На checkpoint editor — обычный Qwen-Image-Edit-2509; его текущий предел — 3 входа:
цель и два листа. Четыре исходных refs были механически объединены в два листа;
это conditioning, не LoRA, не восстановление тела и не 4K-обучение. Личные оригиналы
и подготовленные копии сохраняются вне Git. Дополнительный ML-анализ и обучение
не следуют автоматически из включения refs.

## Требуемый выбор моделей

При MC22-16 владелец отдельно выбирает edit и video, по умолчанию предпочтителен
подключённый проверенный uncensored-профиль. Если совместимого edit engine нет,
пульт показывает причину и альтернативы; обычный редактор не переименовывается в
uncensored. Модель и refs фиксируются при enqueue; изменение /refs или настройки
влияет на новые задачи и не меняет уже поставленное задание молча.
