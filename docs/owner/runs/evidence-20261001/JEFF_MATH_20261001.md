## 6. Риски

- Ошибка разбора: помощник выдаст уверенную, но не ту подсказку (двусмысленная история, обратная задача, неожиданная формулировка). Смягчение: «только однозначное», отказ при двух обработчиках, при прошедшем времени без ясного вопроса, при лишних числах, консервативные регулярные выражения, тест «подсказка на корпусе всегда согласуется с ключом» и на 40+ обычных фраз; но естественный язык шире корпуса. Отдельно при разработке были найдены и исправлены: `НДС` с данными вместо вопроса, `x²`, `просто` как `рост`, число в `(NUM)` без группы, стоимость регулярки на 590 цифрах (2 с -> лимит 100 цифр).
- Модель может проигнорировать подсказку или переписать число неточно; ответ после этого строго проверен только на корпусе.
- Подсказка добавляет в ответ пояснение; при многоходовых формулировках модель после ответа может добавлять числа (виден строгий артефакт). Предложение на следующий шаг: просить «итог в конце» (не включено, чтобы не подгонять под оценщик).
- Влияние на приватность: подсказка локальна, без сети, строится только из чисел сообщения; но оно уходит облачной модели как и сообщение (то же, что и текст сообщения). Правила персоны и приватности не затронуты.
- Совместимость файла настроек: при ВЫКЛ поле `math_assist: false` делает файл нечитаемым для старой сборки Jeff (она вернётся к стандартным настройкам); по умолчанию (ВКЛ) файл не меняется. Описано на странице настроек.
