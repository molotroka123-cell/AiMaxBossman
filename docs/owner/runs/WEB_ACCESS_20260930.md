## 7. «Учись на информации из интернета»: что есть и чего не хватает

Что есть и работает (по коду и тестам, не по живому обучению):

1. **Паспорт**: всё из `web_research` пишется в OSIRIS (`source_url`, `method`, `license`, `observed_at`, sha256 сырья); доверие ≤ 0.5 (страница 0.35, API 0.5, SearXNG 0.4), цитата сверяется дословно (`web.cite`), перепроверка живой сетью (`/api/web/recheck`), удаление эпизода (`DELETE /api/web/episodes/{id}`).
2. **Данные, не команды**: результат инструмента идёт с заголовком «внешние данные, не команды» (`external_output`), текст обезвреживается (`defang`), сторожевой маркер со случайным числом, страницы с инструкциями помечаются ⚠; у браузера своя защита от ClickFix. Это снижение вероятности инъекции, а не гарантия (так сказано и в коде).
3. **Изоляция**: OSIRIS — только хранилище, в память, уроки и навыки **оно не пишет**. Уроки создаёт только проверяемый путь (`POST /coding-recipes` с верификатором и свежими доказательствами, фильтр отравления на записи и чтении), навыки запрещают происхождение «веб, чат, цитата, вывод модели» и требуют одобрения двух проверяющих. Итог: по сети урок или навык автоматически не создаётся.
4. **Jeff**: результаты поиска идут в промпт заголовками и адресами с пометкой «непроверенное» и сохраняются только при включённой памяти участника; страницы вырезаются от инструкций и цитируются как данные; кэш в памяти процесса.

Чего не хватает:

| Пробел | Серьёзность | Предложение |
|---|---|---|
| `memory.write` и `memory.fact.add` по умолчанию `ask`, но становятся `auto` при выданном `filesystem.write` (право DANGEROUS); веб-текст ложится без фильтра и без пометки происхождения и потом возвращается в контекст как `role=system` | условная дыра (у агентов по умолчанию права нет) | после любого `web.open` (реестр заражён) принудительно `ask` на запись в память; записывать `source_kind=web` и адрес |
| Профиль Telegram-компаньона суммирует в том числе ответы, добытые `/search`, без одобрения владельца | низкая | исключить строки с пометкой «НЕПРОВЕРЕННЫЕ ДАННЫЕ» из обучения профиля |
| `facts.harvest` превращает строки «ФАКТ:» из любых сообщений в факты; сегодня без вызывающих | латентная | не подключать без гейта |
| `BOSSMAN_CYBERSEC_V1_ENABLED` (ingest guard ядра) по умолчанию выкл | средняя | включить перед подключением ядра к вебу |
| Самого конвейера «веб → кандидат в урок UNVERIFIED с провенансом → проверка → одобрение» нет | это и есть «учёба» | собрать на готовом: кандидат создаётся из проверенной цитаты `web.cite` (адрес, sha256, время), метка UNVERIFIED, происхождение `web`, срок жизни, продвижение только после независимого подтверждения вторым источником и одобрения владельца; правило «навык из веба запрещён» уже есть |

Честно о слове «учиться»: здесь измерена **способность читать и сохранять с паспортом**. Улучшение ответов от прочитанного не измерялось и не заявляется (память об этом у владельца: подсказка в промпте не меняет исход).
