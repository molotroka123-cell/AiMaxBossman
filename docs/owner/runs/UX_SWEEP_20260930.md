# UX-обход классической оболочки Command Center, 30.09.2026

Полоса `ux-sweep` роя 30.09. Обход настоящим Chromium (Playwright, python из `venv-calls`) на СВОЁМ экземпляре
`127.0.0.1:8846` (дерево `wt-bugtest-0930`, свежий каталог данных, песочница вместо профиля пользователя).

## 1. Инцидент в начале прогона (обязательно прочитать)

Первый прогон шёл на экземпляре, у которого каталог данных был свой, но раздел Telegram в Настройках читает
`%LOCALAPPDATA%\Bossman\telegram-companion\` (путь не зависит от `BCC_DATA_DIR`). Обход нажал на странице
«Настройки» три кнопки раздела Telegram и затронул РЕАЛЬНОЕ хранилище компаньона владельца (в 13:33 по местному):

| Запрос | Что сделал |
|---|---|
| `PUT /api/telegram/profile/<id владельца>` | пересохранил цифровой профиль владельца (кнопка «Сохранить профиль») |
| `DELETE /api/telegram/profile/<id владельца>` | УДАЛИЛ профиль владельца (версия 1 от 22.09.2026 13:28) — без какого-либо подтверждения |
| `POST /api/telegram/export` | создал `exports\user-*.jsonl` и `all-users.jsonl` (санитизированный журнал, локально) |

Не тронуты: `config.json` (mtime не менялся), токен бота, Telegram по сети (только loopback-проба `/api/telegram/models`),
запуск/остановка компаньона. Журнал переписки (18 записей) цел. Восстановление профиля взял на себя лид;
в живое хранилище эта полоса больше не писала.

Причина и меры:

* раздел Telegram — единственное место оболочки, где состояние лежит вне каталога данных экземпляра; любой тестовый
  экземпляр на этой машине работает с живым хранилищем, пока не переопределён `BOSSMAN_TELEGRAM_CONFIG` и `LOCALAPPDATA`;
* дефект продукта, вскрывший это: «Удалить профиль» удалял без подтверждения. Исправлен (UX-04 ниже);
* остальной прогон идёт только на изолированном экземпляре: `LOCALAPPDATA`, `APPDATA`, `USERPROFILE`, `HOME`,
  `BOSSMAN_TELEGRAM_CONFIG` указывают в `swarm-20260930\ux-sweep\sandbox`, данные в `data2`; в песочнице создан ФИКТИВНЫЙ
  Telegram-профиль (фиктивные id и токен), на нём и проверялись кнопки профиля;
* сверка живых каталогов владельца до/после изолированного прогона (`mtime_before.json` / `mtime_after.json`):
  `private` — не менялся (последняя запись 28.09); `CommandCenter` — число файлов то же (3650), растёт только
  `testing\session-log.jsonl` (пишет живой экземпляр :8801); `telegram-companion` — после инцидента файл
  `companion.sqlite3` менялся в 13:56 и каталог `exports` исчез (это действия лида по восстановлению и/или живого
  компаньона: изолированный экземпляр туда не пишет, его `BOSSMAN_TELEGRAM_CONFIG` указывает в песочницу).

Вторая находка того же рода: кнопка «Разрешить запуск приложений» (страница «Приложения») без подтверждения включила
запуск локальных процессов, после чего обход запустил `ai-webcam-vision` на порту 8870 и `ai-3d-maker`. Оба остановлены
через `POST /api/apps/<id>/stop`, политика возвращена в «выключено». Кнопка «Запустить 1.5» (страница «Bossman 1.5»)
запустила в песочнице сборщик рынка (одно публичное чтение Twitch, статус UNREADABLE) и self-improve (упёрся в ключи);
оба процесса завершены. Обе кнопки внесены в список «не нажимать» обхода.

## 5. Оставлено (причина)

| Что | Причина |
|---|---|
| `Music Studio`: «Генерация пока недоступна: ConnectError: All connection attempts failed» | cross_lane: `ui/pages/music_studio.js` и `bcc/features/music_studio.py` ведёт другая полоса |
| `Автономия`: английская фраза бэкенда «constitution is not pinned by the user: run `bossman autonomy constitution pin`…» рядом с русской | cross_lane: `ui/pages/autonomy.js` |
| Браузер пишет `Failed to load resource … 4xx` в консоль на каждый честный отказ сервера (403/409/400) | поведение Chromium, страницей не отключается; осмысленный текст пользователю при этом показан |
| Английские заголовки старых страниц («Needs You», «Task Composer», «Quick Command», «START») | закреплены существующими тестами (`test_cc_ux_p2_findings`, `test_desktop_dock_overlap`); менять вместе с тестами — отдельная задача |
| Технические коды статусов на страницах «Bossman 1.5», «Пульт владельца», «Обучение трейдингу», «Jeff · обзор» (`NOT_STARTED`, `queued:0`, `MODEL_GUARD`, английский текст диагностики) | не ошибки, а диагностика; перевод — косметика, не успели |
| Мелкие цели касания на 390 px (чекбоксы 13–15 px, `select` 19 px) | стилевое решение, не дефект поведения |
| Родная кнопка «Choose Files / No file chosen» в карточке запуска на «Главной» | подпись даёт браузер (у владельца с русским Chromium — по-русски) |
| «Разрешить запуск приложений» включает запуск процессов без подтверждения | не деструктивно и обратимо; решение о подтверждении — за владельцем |
| Изоляция раздела Telegram от каталога данных экземпляра | архитектурное решение (одно хранилище компаньона на машину), вне полосы; до правки тестовые экземпляры обязаны задавать `BOSSMAN_TELEGRAM_CONFIG` |
| Шаги мастеров с вводом (Цели, модель, Motion, Rave-запуск, Video Studio) | пустая отправка проверена на 15 страницах (`modal_probe.py`), полный ввод — не успели |
