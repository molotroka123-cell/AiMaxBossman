## Порядок (по шагам, каждый проверяется)
1. **Установка.** Выключить ПК, вставить диск в свободный слот M.2 2280, включить. «Управление дисками» → GPT → NTFS → метка `BossmanData` → буква `D:`.
2. **Защита и скорость.** Исключения Defender для `D:\Models`, `D:\Ollama`, `D:\HF` (как сейчас для `C:\Users\asd\Bossman\models`). Замер скорости чтения большого файла (ожидание ≥ 2 000 МБ/с).
3. **Медиамодели первыми** (они главные для генераций): `robocopy C:\Users\asd\Bossman\models D:\Models /E /COPY:DAT /MT:8 /R:1 /W:1 /LOG:...`, затем сверка числа файлов и sha256 выборки. Затем папку `models` на C: переименовать в `models.old`, создать связку `mklink /J C:\Users\asd\Bossman\models D:\Models`. Пути во всех конфигах остаются прежними — ничего в коде не меняется.
4. **Ollama.** Остановить Ollama, скопировать модели в `D:\Ollama`, задать `OLLAMA_MODELS=D:\Ollama` (пользовательская переменная), запустить, проверить `ollama list`.
5. **Hugging Face.** `HF_HOME=D:\HF`, перенести кэш.
6. **Проверка.** Одна фото-генерация и одна видео-генерация: время загрузки по журналу замеров (`/api/direct-gen/timings`), сравнить с сегодняшними 17 / 27 мин. Цель: холодная загрузка фото ≤ 60 с.
7. **Неделя на новом диске без ошибок** → удалить `models.old` и старые копии на C:. До этого откат: убрать связку, вернуть имя `models`.
