# Боссман учится сам 24/7 — коротко для владельца

**Что делает.** Пока компьютер включён, Боссман по кругу решает учебные задачи на фейковых
данных: разбор входящих (SwapMe / Fresh Vibes), сценарии администратора, перепроверку
утверждений K1m6a по биржевым данным. Каждую задачу проверяет детерминированный проверщик.
Работает на своих моделях, без Claude: сначала локальная модель (Ollama), потом бесплатные
облачные модели (цена 0/0 проверяется вживую), в крайнем случае `z-ai/glm-5.3-flash` под
жёстким дневным лимитом в $.

**Как он улучшается (честно).**
1. Ошибка → «урок-кандидат» в карантине. Сам по себе урок ничего не меняет.
2. Урок проверяется A/B на отложенных задачах (сам пример в проверку не входит), 2 повтора,
   только локальная модель, $0.
3. Только если прирост есть в каждом повторе (≥ 2 задачи) и нет новых нарушений безопасности,
   Боссман создаёт запрос на подтверждение и пишет вам в пульт.
4. Урок применяется **только после вашего «Разрешить»** (/approvals в пульте или
   «Подтверждения» в Bossman). Урок — это пример в подсказке разбора: прав, инструментов и
   Computer Use он не даёт, ничего не отправляет и не публикует.
5. Откат одной командой:
   `python tools\owner_journeys\lesson_pipeline.py rollback <id урока> --state-dir <папка>`
   (список: `... lesson_pipeline.py list --state-dir <папка>`).

**Куда приходят отчёты.** Только в пульт (бот-компаньон @penisacemagic_bot), никогда в Jeff.
По-русски, коротко: цель, циклы, % правильного разбора, маршрут (локально / облако / GLM),
расходы из лимита, работа за 24 ч, уроки, готовность, блокеры. Каждые 6 ч и сразу при
событиях: смена готовности, СТОП, достигнут лимит $, серия ошибок, урок ждёт решения.
Не больше 12 сообщений в сутки, повторы и секреты не отправляются, без сети — очередь.
Цель и пороги — в `<папка>\goal.json` (можно править: `report_every_h`, `targets`, `ab`).

**Пауза и стоп.**

| что | как |
|---|---|
| пауза | файл `<папка>\PAUSE` или `start_learning_247.ps1 -Pause`; снять — `-Resume` |
| стоп из пульта | /stop или /pause (или «СТОП» в Bossman): текущий цикл прерывается, обучение стоит до «Продолжить» (/resume) |
| полный стоп | `start_learning_247.ps1 -Stop` (файл `<папка>\STOP`): процесс завершается ≤ 60 с и **не стартует** при следующем входе, пока не `-Resume` |
| вы заняты | идёт рендер Studio (`sd-cli.exe`) или загружена другая модель Ollama — задачи с моделью ждут, идут только задачи без модели |
| мало памяти | < 12 ГБ свободно — ждёт |

СТОП, нажатый ещё до первого запуска обучения, на обучение не влияет (он относится к
управлению компьютером); любой новый СТОП — влияет.

**Лимит $.** `<папка>\ladder.json`: `daily_cap_usd` (по умолчанию 0.50), `per_cycle_cap_usd`
(0.05). Деньги резервируются **до** вызова по худшему случаю; при исчерпании облако
отключается до следующих суток, работа идёт локально. Отключить платный уровень:
`"allow_max_cloud": false`. Ключ OpenRouter берётся из env-файла (`-KeyFile`), в отчёты и
логи не попадает.

**Запуск.** Одна команда (её же регистрирует автозапуск при входе, после backend):

```powershell
powershell -ExecutionPolicy Bypass -File tools\owner_journeys\start_learning_247.ps1 `
  -StateDir "$env:USERPROFILE\Bossman\learning247" -KeyFile "<env-файл с OPENROUTER_API_KEY>" `
  -BackendUrl http://127.0.0.1:8820 -Foreground
```

`-Status` — жив ли и в каком режиме. Процесс с пониженным приоритетом, один экземпляр.

**Готовность.** `python tools\owner_journeys\learning_247_readiness.py --state-dir <папка>`
печатает `LEARNING_247=READY` или `NOT_READY` с цифрами. Подробности (критерии, маршрут,
журналы): `docs/owner/journeys/LEARNING_247.md`.
