Для Argon, Claude, Codex и любого исполнителя. Режим обычный, без bypass-флагов.

```
Цель: довести СУЩЕСТВУЮЩИЙ Bossman (бэкенд :8801, пульт в Telegram, приложение :8840,
War Terminal :8830, генерация фото и видео, помощник обменника) до уровня приложения
Tier-1: быстро, надёжно, красиво, предсказуемо, безопасно. Не переписывать, не делать второй
бэкенд, бот или базу. Улучшать то, что есть.

Сначала прочитай: AGENTS.md, docs/archive/2026-10/owner/BOSSMAN_DAY_20261019_RU.md,

ЧТО ЗНАЧИТ TIER-1 (пороги заданы ДО замеров и не двигаются):
1. Скорость
   - Приложение: первый экран ≤ 1.5 с по tailnet; переход между вкладками ≤ 100 мс.
   - Прокрутка чата во время ответа без рывков: ≥ 55 кадров/с на 390 px (замер в браузере).
   - Ответ модели: первый токен ≤ 2 с для тёплой модели.
   - Фото: тёплая загрузка модели ≤ 25 с; вторая задача той же модели в очереди без
     повторной загрузки (живой замер tools/direct_gen_bench/warm_queue_bench.py PASS).
2. Надёжность
   - 24 ч без ручных перезапусков: бэкенд, пульт, приложение (журнал + /health каждые 5 мин).
   - Рестарт во время задачи не теряет задачу (A22-05): возобновление или честный FAIL с причиной.
   - Лаунчеры планировщика не зависают (BossmanOne-3-Companion); один poller пульта.
   - 0 красных тестов в main; CI на точном SHA подтверждён.
3. Качество интерфейса (навык .agents/skills/ui-ux-pro-max)
   - Контраст текста ≥ 4.5:1, цели касания ≥ 44 px на всех экранах, видимый фокус,
     состояния загрузки/пусто/ошибка на каждом экране, русский текст без англицизмов.
   - Плавные анимации 150–250 мс, уважение «уменьшить движение».
   - Чат как у лучших приложений: стриминг без скачков, автопрокрутка только когда пользователь внизу,
     кнопка «вниз», копирование, повтор, остановка ответа.
4. Предсказуемость
   - Каждая генерация пишет замеры; время в UI «по замеру N генераций» или «примерно».
   - Ни одной ложной «готово» или «осталось 1 с».
5. Безопасность и приватность
   - Пульт и приложение только владельцу; CSRF и сессия переживают повторный вход.
   - Ключи и личные медиа не покидают ПК; секрет-скан PASS перед каждым push.
   - Красная команда раз в сутки: доступ без входа, обход путей, утечки — отчёт в docs/audits/.
6. Польза (деньги)
   - Помощник обменника: живой прогон владельцем в Telegram PASS; PDF котировки с логотипом
     после утверждения владельцем; дневной итог в пульт.

КАК РАБОТАТЬ
- Каждый пункт: замер «до» → правка в ветке → тесты (включая тест, который падал до правки) →
  замер «после» на том же наборе → статус PASS/FAIL/BLOCKED/NOT_RUN с SHA и командой.
- В main только с доказательствами (правило владельца: «внедряй в main после доказательств
  полезности и работы»), fast-forward, без force.
- Каждый инцидент пульта или приложения превращается в тест и исправление в коде.
- Перед включением на живом ПК: активных генераций 0. Генерации владельца всегда первыми;
  во время генераций не качать большие файлы и не гонять тяжёлые тесты.
- Порядок: (1) прокрутка и дизайн чата; (2) «Gemma по запросу»: промпт → запуск фото →
  выгрузка модели; (3) живой замер тёплой очереди; (4) лаунчер пульта и UTF-8 сообщений;
  (5) возобновление задач после рестарта; (6) 24-часовой прогон; (7) PDF обменника.

  медленные замеры, жалобы владельца), ставит задачу, решает её в ветке и проверяет.
```
