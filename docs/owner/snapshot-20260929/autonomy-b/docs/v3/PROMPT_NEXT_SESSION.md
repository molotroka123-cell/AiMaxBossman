Правила, которые не обсуждаются:

- Балл поднимает только улика. Незавершённый прогон, отменённый CI, пропущенный
  тест — это UNPROVEN, а не PASS.
- Не ослаблять чужой тест ради зелёного. Если правило усилено — сказать это
  прямо в коммите и объяснить, почему старое ожидание было неверным.
- Каждый чекпоинт: адресные тесты → секрет-скан → коммит → пуш. Без force push.
- Свои измерения проверять на тихой машине: замер под нагрузкой другого прогона
  ничего не доказывает (я на этом уже ошибся с пулом SQLite).
