# Bossman Command v0.1 — настройки Jeff

Панель для владельца: как Jeff разговаривает с участниками. Меняется только
**манера речи** (стиль и тон). Права, доступы, память, приватность и правила Jeff
панель не меняет: у участников по-прежнему нет компьютера, shell, файлов, прав
владельца и чужих персон.

## Где

Окно Bossman → боковое меню, раздел «Агенты и модели» → **«Настройки Jeff»**
(адрес `#/jeff-settings`; также через палитру команд Ctrl+K).
Страница доступна только владельцу (вход в Bossman). У окна Jeff для участников
(порт 8850) этих адресов нет вообще.

Изменения действуют **со следующего ответа Jeff**, без перезапуска — и в Telegram,
и в окне Jeff.

## Ползунки (0–10, по умолчанию как в конфигурации Jeff, обычно 5)

| Ползунок | Что делает |
|---|---|
| Инициатива | сам предлагает следующий шаг |
| Любопытство | уточняет недостающее по задаче |
| Глубина | больше деталей и объяснений |
| Краткость | меньше слов и повторов |
| Теплота | дружелюбнее и мягче |
| Юмор | больше уместных шуток |
| Прямота | говорит прямо, без обиняков |
| Креативность | нестандартные идеи |

Пресеты: **Обычный** (стоковый Jeff), **Дерзкий** (прямота 9, юмор 8, краткость 7,
теплота 4), **Тёплый** (теплота 9), **Краткий** (краткость 10, прямота 8).

«Дополнительно о стиле» — короткая заметка (до 800 символов), например «без
канцелярита». Она подаётся модели как пожелание к стилю и не может выдать
инструменты или права.

## Откат

Кнопка **«Откат к обычному»** — стоковый Jeff для всех: стиль и настройки
отдельных участников сбрасываются, лимиты расходов остаются. Промпт после отката
побайтно равен промпту машины без файла настроек.

## Отдельный участник

Блок «Отдельный участник»: выберите участника (по имени аккаунта окна Jeff или
«Telegram · владелец / участник N» — Telegram ID нигде не показывается и не
хранится), задайте свой стиль, «Сохранить для участника». Остальных участников это
не затрагивает. «Убрать настройку участника» — вернуть его к общим настройкам.

## Лимит расходов

«$ в день» и «$ на одну задачу» могут только **понизить** уже настроенный потолок,
но не поднять его. Jeff сейчас отвечает только через бесплатные модели, поэтому
фактический потолок — $0 при любых значениях в панели (он показан на странице).
Существующий дневной лимит бесплатных запросов не меняется.

## Файл

`<данные Bossman>\pit-v1.7\jeff-settings.json` — по умолчанию
`%LOCALAPPDATA%\Bossman\CommandCenter\pit-v1.7\jeff-settings.json` (рядом с
`cloud_budget.json` Jeff). Другой путь можно задать переменной
`BOSSMAN_JEFF_SETTINGS`.

```json
{"version": 1,
 "defaults": {"system_extra": "", "behavior_scales": {"directness": 9, "humor": 8}},
 "users": {"<ключ участника Jeff, 64 hex>": {"behavior_scales": {"warmth": 9}}},
 "budgets": {"usd_per_day": 2.0, "usd_per_job": 1.0}}
```

Если файл повреждён или содержит неверные значения, Jeff работает как обычно, а
в журнал один раз пишется предупреждение; страница показывает «Файл настроек
повреждён», и «Сохранить» откладывает старый файл в копию `.invalid-*.bak`.
Значения ползунков вне 0–10 обрезаются до границ.

## Jeff Admin (Bossman 1.9): участники, память, доступ, готовность

Та же страница «Настройки Jeff», тот же бэкенд (`/api/jeff-settings/...`), никакой новой панели.

- **Профиль участника** (`PUT /jeff-settings/participants/{ключ}/profile`): имя, роль-пометка (прав не даёт), разрешённые и закрытые темы, язык ответов, голосовой ответ, Jeff в Telegram вкл/выкл. Файл `pit-v1.7/owner-profiles/<ключ>.json`, по одному на человека, вне папки его памяти.
- **Сохранённый контекст** (`GET /jeff-settings/participants/{ключ}`): факты (подтверждённые помечены), число сырых записей, сводки, согласия, журнал обращений к памяти. Только этого человека; текст системных инструкций и скрытые рассуждения не отдаются.
- **Очистка и отзыв**: `POST .../clear {scope: facts|history|summaries|derived|all}`, `DELETE .../facts/{id}`, `POST .../pause-memory` (владелец может только выключить память; включает её сам участник), `POST .../revoke` (доступ закрыт в Telegram и в окне Jeff, данные стираются) и `POST .../restore`. Отзыв хранится вне папки участника: «удалить мои данные» его не снимает; повреждённый файл трактуется как отзыв.
- **Изоляция памяти**: память каждого участника лежит в своём пространстве и никогда не смешивается с чужой; эту защиту нельзя отключить, страница показывает результат проверки.
- **Готовность и события** (`GET /jeff-settings/status`): токен Telegram задан?, STT/TTS, облачный лимит, ошибки, последние действия владельца, пульс Jeff.
- **Пульс Jeff**: `pit-v1.7/heartbeat.json` (Telegram) и `pit-v1.7/web/heartbeat.json` (окно): доступность, задержка и время последнего ответа, выбранные LLM/STT/TTS, очередь, ошибки. Читается через `bossman pit status`, `/api/jeff/health` окна и страницу. Процессов опроса Telegram должно быть 0 или 1.
- Jeff отвечает только через локальную модель или OpenRouter `:free` с проверенной нулевой ценой; платный или непроверенный маршрут в каталог не попадает.
- Задача STOP не трогает Jeff; общий STOP (`/api/control-plane/stop-all`) останавливает Jeff флагом `stop.flag`.
