# Откат на прежний архив Bossman

Каждый архив `BOSSMAN-Windows-x64-<SHA>` самодостаточен: Python, браузер, ffmpeg и
все модули лежат внутри его папки. Данные владельца (база, ключи, журнал,
медиатека, настройка медиадвижка) лежат ОТДЕЛЬНО —
`%LOCALAPPDATA%\Bossman\CommandCenter` (или папка из `BCC_DATA_DIR`). Поэтому
откат — это смена папки приложения, а не переустановка.

## Перед первым запуском нового архива

1. Не удалять папку прежнего архива (например `C:\Bossman-Test\BOSSMAN-Windows-x64-0c3e22ffd44c`).
2. Сделать копию папки данных:
   ```powershell
   $d = "$env:LOCALAPPDATA\Bossman\CommandCenter"
   Copy-Item $d "$d.bak-$(Get-Date -Format yyyyMMdd-HHmm)" -Recurse
   ```
   Копия нужна и для upgrade/rollback-проверки: на ней, а не на рабочих данных,
   проверяется, что новая версия открывает старую базу и что старая версия
   открывает свою копию после отката.
3. Записать SHA-256 нового ZIP (`Get-FileHash`) и SHA из `MANIFEST.json`.

## Откат

1. Закрыть Bossman (окно приложения; при необходимости `Get-Process python | Where-Object Path -like "*<новая папка>*" | Stop-Process`).
2. Запустить `Start-Bossman.cmd` из папки ПРЕЖНЕГО архива. Он использует ту же
   папку данных. Если новая версия мигрировала базу и старая её не открывает,
   вернуть копию из шага 2: переименовать текущую `CommandCenter` в
   `CommandCenter.failed-<время>` и скопировать `CommandCenter.bak-…` на её место.
3. Медиадвижок: файл `CommandCenter\media\config.json` относится к данным, а не к
   архиву — после отката он остаётся; прежняя версия без поддержки sd.cpp его
   просто игнорирует.
4. `Collect-Diagnostics.cmd` из НОВОЙ папки перед удалением — чтобы дефект, из-за
   которого откатились, не остался без улик. ZIP с вырезанными секретами лежит в
   `CommandCenter\owner-run\<время>\diagnostics.zip`.

## Что откат НЕ делает

- не возвращает файлы, которые агент создал/изменил в папках владельца — их
  список см. в Flight Recorder журнала задач;
- не отменяет внешние действия (отправленные сообщения, скачанные файлы);
- не трогает модели llama-server и папку моделей медиадвижка.
