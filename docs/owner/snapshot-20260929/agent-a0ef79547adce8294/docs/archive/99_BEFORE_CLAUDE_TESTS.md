## Что адаптировано (а не принято вслепую)

1. **`FactStore` как адаптер.** Пак написан под объектный API, наш модуль —
   функциональный. Реализацию не переписывал: добавил тонкий `FactStore` +
   `parse_time` + `public_fact` поверх `write_fact`/`query_facts`. Работают и
   инструменты пака, и наши приёмы.
2. **Строгость формы факта стала параметром.** Наша валидация требует 15–80 слов
   (приём mem0 для фактов **из диалога**). Тесты пака пишут структурные факты в
   два слова, и это законно: `subject`/`predicate`/`object` уже несут смысл.
   Добавлен `strict_form`: строгая проверка остаётся для `harvest` и записи
   человеком, программный API пишет мягко. Запреты на местоимения и
   неразрешённые относительные даты действуют **всегда**.
3. **`as_of(world_at=…)`** — переименовано из `when`: имя оси прямо в сигнатуре.
   `when` оставлен синонимом.
4. **`public_fact` отдаёт `datetime`, а не строку** — иначе сравнение по времени
   в тестах невозможно, а FastAPI сериализует datetime сам.
5. **Тест `.gitignore` из пака исправлен.** Он проверял игнор через отсутствие
   выдачи по запросу «secret symbol», но этот запрос находит разрешённый
   `visible_symbol` по общему токену «symbol». Игнор при этом **работает**:
   файла нет в индексе. Проверка переписана на источники результатов.
6. **Сканер секретов научен точечной пометке.** Он ловил две тестовые
   «канарейки» — заведомо фальшивые значения, которыми тесты доказывают, что
   секрет НЕ утекает в снапшот. Вместо отключения проверки для каталога тестов
   добавлен маркер `# ci-secret-scan: allow` построчно.
