# Что берём из аналогов — 18 сентября 2026

Это сравнение продуктовых возможностей по публичным первичным страницам,
не независимый benchmark качества генерации и не заявление «лучше всех».

| Источник | Полезная идея | Реализация Bossman / граница |
|---|---|---|
| [Higgsfield](https://higgsfield.ai/) | модели изображений/видео, пресеты и повторение | единая Studio, схема под модель, reuse; реальные Higgsfield модели не включены без официального подключения |
| [Runway Academy](https://academy.runwayml.com/) | повторяемые workflows, изображения/видео и работа с персонажами | раскадровка по существующим рецептам, роли референсов; перенос движения и синтез голоса не заявлены |
| [LTX](https://ltx.io/) | связность нескольких кадров, локальные веса и ComfyUI workflows | коллекции кадров, существующий локальный ComfyUI; последовательность персонажа не объявляется гарантированной |
| [open-higgsfield](https://github.com/wide-trace/open-higgsfield) | один composer, настройки каждой модели, история результатов | собственный код, локальные проверенные байты, без лимита 60, именованные отказы и доказательства; чужой код не переносился |

Ось выигрыша Bossman: контроль файла, происхождения, расходов и передачи
референсов плюс использование результата в существующих редакторах. Качество
чужих моделей зависит от доступа владельца; его нельзя улучшить обещанием UI.
