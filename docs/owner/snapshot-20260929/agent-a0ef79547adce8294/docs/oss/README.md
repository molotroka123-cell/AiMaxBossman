# Локальные open-source инструменты Bossman

В интерфейсе откройте **«Локальные инструменты»** (`#/oss`). Здесь собраны
подключения и формы для чтения документов, расшифровки WAV и поиска по заметкам.
Карточка «Настроено» означает наличие конфигурации, а не выполненную задачу.
Проверка модели, Windows и Radeon 8060S проводится отдельно на компьютере владельца.

## Что действительно подключено

| Движок | Где использовать | Граница этой интеграции |
|---|---|---|
| [llama.cpp](https://github.com/ggml-org/llama.cpp) | «Модели», существующий провайдер `openai_compat` | Каталог и подключение локального сервера. Модель, шаблон чата, tool calling и скорость нужно проверить отдельно. |
| [Docling](https://github.com/docling-project/docling) | «Локальные инструменты» → «Документ → текст» | PDF с текстовым слоем, DOCX, PPTX, XLSX, CSV. **Без OCR**: сканы не объявляются распознанными. |
| [Qdrant](https://github.com/qdrant/qdrant) | «Локальные инструменты» → «Поиск по заметкам» | Дополнительный локальный индекс **до 2000 фрагментов**, включается явно. Нужен локальный сервер эмбеддингов. |
| [faster-whisper](https://github.com/SYSTRAN/faster-whisper) | «Локальные инструменты» → «Запись → текст» | WAV PCM16, до 10 минут и 32 МиБ. CPU/int8; веса модели устанавливаются отдельно. |
| [SearXNG](https://github.com/searxng/searxng) | «Веб-поиск» | Отдельный сервис с JSON API. Нужен интернет; поисковый запрос передаётся его поисковым движкам. |
| [ComfyUI](https://github.com/Comfy-Org/ComfyUI) | «Изображения» → `ComfyUI (local text-to-image)` | Генерация по тексту с совместимым SD/SDXL checkpoint. **Без видео, вариаций, редактирования и произвольных custom nodes**. |
| [UI-TARS](https://github.com/bytedance/UI-TARS) | Существующий Computer Operator | Визуальная модель уточняет координаты одиночного/двойного клика. Это не установка отдельного UI-TARS Desktop и не замена контроля разрешений. |
| [GrapesJS](https://github.com/GrapesJS/grapesjs) | «Веб-дизайн» → «Конструктор блоков» | Уже существующий редактор статического HTML/CSS с сохранением проектов и историей. |

### Пять ответов на направление, а не один

Для Windows-архива те же восемь направлений записаны в `MANIFEST.json`
(`oss_directions`) по пяти отдельным полям. `BUNDLED` считается по факту
установки пакета в runtime архива; `CONFIGURED` — всегда действие владельца
после распаковки (карточка «Настроено» — это конфигурация, не выполненная
задача); `VERIFIED` в манифесте всегда `false` — проверка выполняется на
вашей машине способом из колонки «как проверить».

| направление | BUNDLED | CONFIGURED | MODEL_REQUIRED | EXTERNAL_SERVICE_REQUIRED | как проверить (VERIFIED — только вами) |
|---|---|---|---|---|---|
| llama.cpp | нет: сервер не в архиве | провайдер `openai_compat` | да (GGUF) | да (`llama-server`) | русский ответ, JSON по схеме, задача с инструментом |
| Docling | да (`docling-slim`) | нет | нет (без OCR) | нет | известная фраза из PDF с текстовым слоем; скан → `NO_TEXT` |
| Qdrant | да (`qdrant-client`, локальный режим) | папка заметок, модель и адрес эмбеддингов | да (модель эмбеддингов) | да (сервер эмбеддингов) | заранее записанный факт найден |
| faster-whisper | да (`faster-whisper`) | `BOSSMAN_WHISPER_MODEL_PATH` | да (CTranslate2) | нет | короткий WAV расшифрован |
| SearXNG | нет | `BOSSMAN_WEB_SEARXNG_URL` и флаги | нет | да (контейнер) | реальный запрос с ссылками |
| ComfyUI | нет | `BOSSMAN_COMFYUI_URL`, checkpoint | да (SD/SDXL) | да (ComfyUI) | открывающийся PNG; «Стоп» → «Повторить» |
| UI-TARS | нет | `BOSSMAN_COMPUTER_PLANNER=uitars`, маршрут | да (визуальная модель) | да (локальный маршрут) | безобидный клик по координатам модели |
| GrapesJS | да (`ui/vendor/grapesjs` в колесе) | нет | нет | нет | правка заголовка, сохранение, переоткрытие |

Профиль установки `command-center[runtime]` теперь включает пакеты
`documents`, `speech`, `semantic-memory`: Docling Slim 2.127.0,
faster-whisper 1.2.1 и qdrant-client 1.15.1. Он используется и Windows-сборкой.
**Пакеты не содержат веса моделей и не загружают их автоматически при старте.**
llama-server, ComfyUI и SearXNG устанавливаются и запускаются отдельно.
Docling использует штатный PDF-парсер без моделей; Qdrant работает через
`qdrant-client` в локальном режиме, отдельный сервер Qdrant не нужен.

## Подготовка Windows

1. Установите сборку нужного SHA по [основной инструкции](../../INSTALL.md).
   Для неё нужны подтверждение проверки архива в Actions и соответствующий артефакт.
   Наличие нового коммита не обновляет уже скачанный ZIP.
2. Из распакованной папки запустите `Start-Bossman.cmd`; для диагностики —
   `Evening-Test.cmd`. Сохраните пользовательский каталог данных при обновлении.
3. Для установки из исходников используйте PowerShell в корне репозитория:

   ```powershell
   .\start-bossman.ps1
   ```

   При обновлении зависимостей запускайте без `-SkipInstall`.
   Для последующих запусков доступен `.\start-bossman.ps1 -SkipInstall`.
4. Сначала проверьте документы и редактор сайта, затем подключайте модели
   по одной. Не загружайте одновременно несколько больших моделей в общую память.

Переменные ниже задаются **до запуска Bossman**, в том же PowerShell.
Они действуют только в текущем окне: при новом запуске задайте их снова.
Не подставляйте в примеры ключи и не сохраняйте личную конфигурацию в Git.

### Документы: можно начать без модели

Создайте отдельную папку и положите туда копии тестовых документов:

```powershell
New-Item -ItemType Directory -Force 'C:\Bossman-Test\Documents' | Out-Null
$env:BCC_FILE_INTELLIGENCE = '1'
$env:AIFS_ROOTS = 'C:\Bossman-Test\Documents'
.\Start-Bossman.cmd
```

При запуске из исходников последняя команда — `.\start-bossman.ps1 -SkipInstall`.
В форме укажите полный путь к файлу на компьютере Bossman. Извлечение только
читает документ; оно не сортирует файлы и не требует работающего сортировщика.
Действуют существующие ограничения доступа к репозиториям, секретам и состоянию
приложения. Лимиты: 20 МиБ входного файла, до 100 страниц PDF, 200000 символов
ответа; сокращённый текст помечается. Для Office дополнительно ограничены
распакованный размер и число записей контейнера.

Если пакет отсутствует, переустановите текущий профиль `runtime` или добавьте
`command-center[documents]` в существующее окружение разработки. Пустой скан
возвращает `NO_TEXT`; для OCR потребуется отдельная настроенная интеграция.

### Локальная языковая модель

Возьмите зафиксированный официальный выпуск llama.cpp и совместимую GGUF-модель.
Пример запуска уже установленного сервера:

```powershell
& 'C:\Bossman\llama\llama-server.exe' -m 'D:\Models\model.gguf' --host 127.0.0.1 --port 8080 --alias bossman-local --ctx-size 8192 --jinja
```

В Bossman выберите `openai_compat`, адрес `http://127.0.0.1:8080/v1`
и фактическое имя модели `bossman-local`. Подробности, проверка Vulkan и
ограничения шаблонов: [llama.cpp](../integrations/llamacpp.md).
Успешное получение каталога моделей ещё не подтверждает генерацию ответа.

### Голос и память

Для распознавания заранее разместите локальную модель faster-whisper/CTranslate2
с файлами `model.bin`, `config.json`, `tokenizer.json`:

```powershell
$env:BOSSMAN_WHISPER_MODEL_PATH = 'D:\Models\faster-whisper-small'
```

После перезапуска выберите WAV в форме и язык `ru` либо автоматическое определение.
Поддерживаются mono/stereo, 8–48 кГц. Этот адаптер использует CPU/int8;
ускорение Radeon не заявлено. Это расшифровка выбранного файла, не постоянное
прослушивание микрофона и не синтез речи.

Для Qdrant сначала запустите совместимую **модель эмбеддингов**. В форме памяти
укажите папку заметок, её реальное имя модели, фактическую размерность вектора
и адрес вида `http://127.0.0.1:8081/v1/embeddings`. Затем нажмите
**«Включить Qdrant» → «Обновить индекс» → «Найти в заметках»**.
Обычная чат-модель без embedding API для этого не подходит. Память остаётся
в Markdown/SQLite, векторный индекс можно перестроить; обучение весов не выполняется.
При превышении 2000 фрагментов используйте **«Использовать обычный поиск»**.
Ограничения выбора backend: [исследование Qdrant](../research/qdrant.md).

### Интернет-поиск, изображения и клики

- **SearXNG:** выполните [инструкцию контейнера](../../config/oss/searxng/README.md)
  с зафиксированным digest официального образа. Она включает JSON-выдачу,
  `BOSSMAN_OSIRIS_ENABLED`, `BOSSMAN_WEB_RESEARCH_ENABLED` и
  `BOSSMAN_WEB_SEARXNG_URL=http://127.0.0.1:8888`. После перезапуска проверьте
  реальный запрос в «Веб-поиске»; ошибки движков не равны отсутствию результатов.
- **ComfyUI:** в работающий локальный ComfyUI установите совместимый SD/SDXL
  `.safetensors` checkpoint. Перед запуском Bossman задайте
  `BOSSMAN_COMFYUI_URL=http://127.0.0.1:8188` и
  `BOSSMAN_COMFYUI_CHECKPOINT=имя-файла.safetensors`. Начните с одной картинки
  512×512. Настройка, ограничения отмены и проверка PNG: [ComfyUI](COMFYUI.md).
- **UI-TARS:** сначала настройте обычный Computer Operator и локальный маршрут
  подходящей визуальной модели. Задайте `BOSSMAN_COMPUTER_PLANNER=uitars` и
  `BOSSMAN_UITARS_MODEL=имя-существующего-локального-маршрута` для core-процесса;
  если он запущен отдельно от панели, согласуйте окружение обоих процессов.
  Текстовой модели недостаточно. Порядок настройки: [UI-TARS](../integrations/uitars.md).

## Как принять результат на своём компьютере

Проверьте извлечение известной фразы из документа, сохранение сайта после
перезапуска, расшифровку короткого WAV, поиск заранее записанного факта,
интернет-поиск с реальными ссылками и создание открывающегося PNG.
Для модели отдельно проверьте русский ответ, структурированный JSON и задачу
с разрешённым инструментом. Для Computer Operator — безобидный клик,
запрещённое действие, паузу/остановку и масштабирование Windows.

Сохраните SHA сборки и результат каждого сценария. Успешные проверки адаптеров
и установки пакетов не заменяют этот прогон и не означают общей готовности
моделей, GPU или всех функций приложения. Ни одна из этих интеграций сама
по себе не обучает локальную модель и не присваивает сборке статус freeze.
