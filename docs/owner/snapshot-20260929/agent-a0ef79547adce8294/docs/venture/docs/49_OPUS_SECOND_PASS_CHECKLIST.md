# Opus second-pass checklist

After the first audit, perform a second pass pretending the first answer was
written by an overconfident founder.

Try to find:
- hidden optimism;
- impossible conversion assumptions;
- unsupported market size;
- missing tax/VAT timing;
- underestimated support;
- underestimated integration cost;
- unpriced AI usage;
- no legal customer-acquisition path;
- no payer;
- fake moat;
- no kill date;
- “pilot” that is actually free consulting;
- scale plan before retention;
- cashflow ignored;
- company-formation trigger too early/late;
- metric that can be gamed.

Return:
`SECOND_PASS_SURVIVED: YES/NO`

and the five most dangerous remaining assumptions.
