# Portfolio management

## Portfolio metrics

- total MRR;
- collected cash;
- contribution margin;
- burn;
- runway;
- active ventures;
- validation spend;
- revenue concentration;
- channel concentration;
- experiment velocity;
- time-to-revenue.

## Monthly allocation

Each active venture receives:
- keep;
- increase;
- decrease;
- hold;
- kill.

Allocation is based on marginal expected return, not sunk cost.

## Concentration

Warning:
top customer >25% venture revenue.

Critical:
top customer >40% without contractual security.

## Portfolio maturity

Early:
one build-stage venture.

Later:
expand only when contribution funds extra capacity and operating systems exist.

## Sunk-cost rule

Past spend is evidence about the project, not a reason to continue.
