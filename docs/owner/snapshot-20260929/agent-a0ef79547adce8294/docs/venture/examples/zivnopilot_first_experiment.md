# EXP-ZP-001 — Problem and price proof

Segment:
Choose one: independent electricians OR plumbers in Czechia.

Do not mix trades in first sample.

## Hypothesis

Owners repeatedly lose meaningful time/revenue managing:
inbound customer -> quote -> schedule/change -> completion -> payment/invoice.

## Interviews

Target:
15 qualified.

Pass problem proof:
>=9 independently report material repeated admin pain in the same workflow.

## Paid concierge

Offer:
manual/AI-assisted “job admin pilot” representing the proposed workflow.

Test price:
499 CZK/month equivalent or a concrete pilot fee.

Payment proof:
>=3 independent customers pay.

## Budget

<=5,000 CZK.

## Kill/hold

If pain exists but no payment:
test segment/offer once.

Do not build full SaaS simply because interviews are positive.
