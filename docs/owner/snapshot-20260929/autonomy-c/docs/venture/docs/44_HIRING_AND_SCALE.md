# Hiring and scale

## Default

Do not hire to create activity.
Hire to remove a measured bottleneck.

## First hiring triggers

Support:
support load blocks product/sales.

Sales:
qualified lead volume exists but owner cannot process economically.

Engineering:
validated backlog produces measurable lost revenue and internal capacity is
saturated.

Operations:
reconciliation/onboarding volume is predictable.

## Contractor first

Prefer bounded contractors for uncertain needs.

Track:
- cost;
- output;
- bottleneck removed;
- time saved;
- revenue enabled.

## Employee/full-time

Requires:
- runway;
- recurring contribution;
- workload persistence;
- legal/payroll readiness.

Venture Engine proposes; human decides.
