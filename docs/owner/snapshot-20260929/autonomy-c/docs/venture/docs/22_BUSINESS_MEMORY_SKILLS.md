# Business memory and skill learning

## Durable memory rule

Persist evidence-backed commercial lessons, not vibes.

Required:
- segment;
- context;
- experiment;
- sample;
- outcome;
- date;
- confidence;
- scope;
- invalidation condition.

## Example

Good:
“Experiment E-041: 7/10 qualified electrical contractors named quote follow-up
or schedule changes as weekly admin pain; 3 accepted a paid concierge pilot.”

Bad:
“Tradespeople hate admin.”

## Skill Forge integration

Repeated proven behavior may become a skill:
- regulatory-opportunity-scan;
- competitor-pricing-audit;
- paid-pilot-design;
- churn-retrospective;
- unit-economics-review.

Promotion uses existing skill evaluation.

A commercial skill cannot gain permissions outside Governor/approval policy.
