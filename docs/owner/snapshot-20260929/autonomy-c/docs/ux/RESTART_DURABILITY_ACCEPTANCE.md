# Перезапуск менеджера: работа продолжается, побочные эффекты не дублируются

Сценарий приёмки выполнен как автоматический тест, а не как ручной прогон:
`command-center/tests/test_ux2_restart_durability.py`.

## Сценарий 1 — та же работа после перезапуска

| Поле | Значение |
|---|---|
| mission_id (задача) | `tasks.id`, созданный в процессе №1 |
| run_id | `task_runs.id` того же процесса |
| состояние до перезапуска | `tasks.status=running`, `task_runs.status=running`, аренда воркера истекла, `checkpoint.step=2` |
| момент перезапуска | процесс №1 остановлен (`Services.stop`), незавершённый прогон остался в базе |
| состояние после перезапуска | процесс №2 стартовал на тех же данных, `engine.recover()` вернул тот же прогон в очередь (`attempt` увеличен) |
| возобновлённый шаг | тот же `run_id`, привязка к тому же `task_id` |
| duplicate_count | **0** (в таблице один прогон на задачу) |
| side_effect_count | **1** (ровно одна запись `status=completed`) |
| участие владельца | не потребовалось: ни одного «продолжить» |
| итог | `tasks.status=completed` |

Проверяемые утверждения теста:

- `run["task_id"] == task_id` — привязка к миссии не потеряна;
- `len(runs) == 1` — перезапуск не создал второй прогон;
- `len(completed) == 1` — работа завершена ровно один раз;
- `completed[0]["id"] == run_id` — продолжен именно тот прогон, а не новый.

**PASS** (требование `duplicate_count = 0` выполнено).

## Сценарий 2 — подтверждение владельца переживает перезапуск

| Поле | Значение |
|---|---|
| подтверждение | `terminal.run` / `ls ./artifacts` |
| до перезапуска | решение владельца `approved` (`decided_by=human:owner`), затем использовано (`consume → True`, статус `consumed`) |
| после перезапуска | новый процесс на тех же данных |
| повторное использование | `consume → False` |
| попытка переиграть решение | `decide(..., False, "attacker")` не меняет ни статус, ни автора |

**PASS**: использованное подтверждение нельзя предъявить второй раз даже из
нового процесса, а чужое «решение» не подменяет решение владельца.

## Что этот тест НЕ доказывает

- Не проверялся перезапуск с настоящим платным провайдером: модель заменена
  локальным `FakeAdapter`, потому что доказывается durability движка, а не
  качество ответа модели.
- Не выполнялся реальный внешний побочный эффект (письмо, публикация); контракт
  «ровно один раз» доказан на durable-пути подтверждений.
