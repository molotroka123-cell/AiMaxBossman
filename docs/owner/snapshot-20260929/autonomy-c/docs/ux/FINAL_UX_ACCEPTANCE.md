## 0. Три разных SHA — не путать

| Роль | SHA | Что именно им доказано |
|---|---|---|
| **code-fix SHA** | `fc09a1cd0063898c4ded3bf677524652bda89b91` | последний коммит с изменениями кода/тестов; на нём прогнаны все наборы и бенчмарк |
| **CI-verified docs SHA** | `07446047673c0e49598fca11395bf8552ac2974c` | `fc09a1c` + первая версия этого файла; четыре из четырёх workflow зелёные |
| **final freeze SHA** | текущий коммит (только документация) | добавляет это разделение SHA и два обучающих fix-log; его собственный CI должен быть зелёным, иначе freeze не объявляется |

Коммит не может содержать собственный SHA в своём тексте, поэтому final freeze
SHA назван в git log и в отчёте владельцу. Ни один из трёх SHA не заменяет
другой: код доказан на `fc09a1c`, зелёный CI — на `0744604`, а этот коммит
меняет только документацию.
