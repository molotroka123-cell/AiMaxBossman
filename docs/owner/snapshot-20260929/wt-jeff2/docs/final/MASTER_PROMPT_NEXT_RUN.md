## 4. ПАМЯТЬ И КОНТЕКСТ — ГЛАВНОЕ УЛУЧШЕНИЕ ЭТОГО ПРОГОНА

### OpenContext
`https://github.com/0xranx/OpenContext` · JavaScript

Персональное хранилище контекста для AI-ассистентов: сохранить, найти и
переиспользовать знания о проектах между сессиями, репозиториями и чатами.

**Режим: SHADOW / MIRROR, и только он.** Родная память Bossman остаётся
АВТОРИТЕТНОЙ. OpenContext получает копии и отвечает как ДОПОЛНИТЕЛЬНЫЙ
источник кандидатов. Порт: `ContextStoreRuntime` за реестром адаптеров.

Обязательно:
* изоляция пространств имён по проекту — контекст чужого проекта не течёт;
* атрибуция источника у каждого ответа: кто это сказал и когда;
* обнаружение устаревания: контекст, противоречащий текущему состоянию
  репозитория, помечается, а не выдаётся как истина;
* переключение обратно на родную память — одним флагом, без деградации.

**Жёсткие запреты:** никаких ключей, токенов и паролей в открытом виде;
никакого слепого приёма `.env`, учётных данных и приватных секретов;
биометрия по умолчанию не хранится.

**Проверка, без которой интеграция не принимается:** взять реальную
владельческую сессию, перезапустить продукт, доказать, что восстановленный
контекст ДЕЙСТВИТЕЛЬНО сократил повторные вопросы и не привнёс ложных
утверждений. Сравнение — против родной памяти, парное, на одних и тех же
предметах.

## 5. КАНДИДАТЫ ИЗ ЗАДАНИЯ ВЛАДЕЛЬЦА

### 5.1 ai-file-sorter
`https://github.com/hyperfield/ai-file-sorter/` · C++

Локальные визуальные модели дают осмысленные имена файлам:
`IMG_2048.jpg` → `облака_над_озером.jpg`; для аудио и видео — имена из
метаданных.

* **Сначала ЮРИДИЧЕСКИЙ ПРЕФЛАЙТ.** Проверить фактическую лицензию upstream
  на конкретном закреплённом коммите. Без явно совместимой лицензии — только
  `OPTIONAL_EXTERNAL_BACKEND` или `REFERENCE_ONLY`. **Не вендорить код в
  ядро.**
* На kymr05 УЖЕ есть родная `bcc/file_intelligence/` — второй комплект
  писать запрещено. Либо внешний бэкенд за существующим портом, либо отказ.
* **Никаких массовых переименований без ДЕТЕРМИНИРОВАННОЙ карты отката.**
  Каждое переименование — запись `было → стало` с возможностью отката одной
  командой. Предпросмотр обязателен, применение — после подтверждения
  владельца.
* Проверка эффекта: имя файла на диске изменилось и это подтверждено
  независимым чтением каталога, а не ответом движка.

## 7. РЕСУРСЫ: ВЛАДЕЛЕЦ НЕ ХОЧЕТ 15 ДЕМОНОВ НА СВОЕЙ МАШИНЕ

Замерено на прошлом прогоне, отсюда и отсчёт:

| Величина | Сейчас |
|---|---:|
| импорт `bcc.api` | 656 мс |
| подъём до первого ответа по HTTP | 1390 мс |
| RSS в покое | 108.8 → 109.2 МиБ за 30 с (утечки нет) |
| процессор в покое | **3.0 % одного ядра** — опрос очереди раз в секунду |

Требования:
* **ленивый старт**: подсистема не поднимается, пока её не позвали;
* **остановка по бездействию**;
* **никакого постоянного резервирования GPU** — на единой памяти 128 ГБ
  занятое моделью вычитается из общей памяти, авторитет над бюджетом
  остаётся у губернатора Bossman;
* **никакого опроса вхолостую** — см. watchfiles;
* **ОДИН менеджер сайдкаров** (`bcc/hybrid/sidecar.py`), а не по менеджеру
  на интеграцию.

Каждая новая интеграция обязана приложить «до/после» по этим четырём
величинам. Ухудшила — обосновать или снять.

## 8. НЕ ПОДГОНЯЙ ТЕСТЫ

Запрещено: удалять падающие тесты; помечать важные как skipped; поднимать
пределы, чтобы позеленело; снижать пороги покрытия; мокать все интеграции,
чтобы ни один настоящий путь не исполнялся; зашивать ожидаемый вывод;
ослаблять approvals и политику; считать недоступный бэкенд успехом;
заявлять, что тесты на железе прошли, когда железа не было.

**Чини реальность, а не табло.**

Три урока прошлого прогона, которые стоили времени (см. BL-006…BL-008):

1. «Убрал X — заработало» **не является причинной связью**, пока тот же
   эффект не воспроизведён на отдельном стенде без остального продукта. По
   ложному диагнозу уже была написана правка — не поехала.
2. **«Флейк» не бывает корневой причиной.** Приёмка редакторов мигала
   3/2 из пяти; причина оказалась в скорости превью (1.45 с → 0.45 с), и
   чинилась СКОРОСТЬ, а не ожидание в тесте.
3. Коммит, добавляющий или двигающий `skipif`, обязан нести результат
   `python tools/skips_registry.py`. Эта ошибка повторилась дважды за один
   прогон.
