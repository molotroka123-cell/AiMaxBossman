## 1. Что теперь верно, а что отменено

| Отменено | Действует |
|---|---|
| «вписать open-higgsfield в Боссман вместо Video Studio» | **отдельный форк в своём репозитории на GitHub, на своём стеке** |

| переносить чужой код в наш репозиторий | код форка живёт только в форке |

Вердикт `REFERENCE_ONLY` из `OWNER_IDEA_OPEN_HIGGSFIELD.md` остаётся в силе
**для нашего репозитория**: чужой код без лицензии сюда не попадает, стек сюда
не тянется, эгресс в публичный Blob сюда не приходит. Форк — другая дорожка,
и она ничего из этого не нарушает, пока две дорожки не смешиваются.

**Жёсткая граница.** Ни одна строка форка не коммитится в AiMaxBossman. Ни
одна строка Боссмана не коммитится в форк. Общего у них только твоя голова.

## 5. Где форк выигрывает — восемь осей, каждая проверяема

Это не идеи «вообще», а дыры, найденные чтением их кода. Каждая закрывается
в их же стеке и видна судье за минуту.

1. **Байты не теряются.** Их README сам признаёт: результаты живут на CDN
   платформы, и старая история «может пережить срок жизни CDN и показывать
   дыры». Форк, который скачивает результат при завершении и хранит его у
   пользователя (File System Access API или OPFS), закрывает главную жалобу
   их собственного README. Плюс снятие потолка в 60 записей.
2. **Отказы различаются.** Сейчас всё сводится к одному `PlatformError`.
   Нет ключа, 401 отвергнут, 402 нет кредитов, 429 лимит, 404 модель снята,
   отказ по контенту, битый ответ — семь разных состояний с разными
   действиями. Это самая заметная разница в реальной работе.
3. **Кредиты на экране.** Официальный сервер отдаёт баланс; у владельца,
   к примеру, `credits = 0`, план `free`. Показывать остаток до отправки и
   списание после — то, чего нет ни в клоне, ни в его UX.
4. **Каталог шире.** Официальный каталог — 98 моделей: видео 41,
   изображения 34, 3D 17, звук 6. В клоне 38 и только две поверхности.
   Добавить звук и 3D значит удвоить продукт, а не «добавить пунктов».
5. **Происхождение прогона.** В записи истории нет ни seed, ни времени, ни
   стоимости, ни хэша результата. Форк, который это показывает и умеет
   повторить прогон побайтно, выглядит инструментом, а не демо.
6. **Дедлайн по модели, а не общий.** Опрос 4 с и 10 мин одинаковы для
   быстрой картинки и для 30-секундного видео. Каталог уже несёт схему —
   пусть несёт и дедлайн.
7. **Приватность загрузок.** Публичный Blob означает, что референс
   пользователя доступен по ссылке кому угодно. Токены с ограничением
   времени и области — короткая правка с большим весом.
8. **Тесты.** Их ноль. Форк с настоящим набором на каталог, маппинг
   запросов и разбор статусов — единственный, на который можно смотреть без
   страха. Это же твоя страховка от регрессий на конкурсе.

Дальше по вкусу: раскладки клавиш, очередь заданий, пакет больше четырёх,
локализация, доступность.

## 6. Лицензия: предупреждение, которое стоит денег

У апстрима **нет файла лицензии**. По условиям использования GitHub публичный
репозиторий можно смотреть и форкать средствами самого GitHub, но прав на
распространение вне GitHub или на коммерческое использование отсутствие
лицензии не даёт. Практические следствия:

* форк держать **на GitHub**, как форк, а не как выложенный отдельно код;
* свою лицензию на чужой код поставить нельзя — только на файлы, написанные
  тобой, и это надо назвать явно;
* **спроси прямо**: заведи issue в апстриме с вопросом о лицензии для
  участников конкурса. Организатору это тоже нужно, и вопрос ставит тебя в
  список серьёзных участников.

## 7. Порядок работ форка

1. Условия конкурса и ссылка (§2) — записать сюда.
2. Форк на GitHub, свой рабочий бранч, `pnpm install`, `pnpm dev`, убедиться,
   что сборка поднимается с твоим ключом.
3. Быстрая победа первой: различимые отказы (§4.2) плюс баланс кредитов
   (§4.3). Одно утро работы, видно сразу.
4. Сохранение байтов и снятие потолка истории (§4.1).
5. Каталог: звук и 3D (§4.4) — самая тяжёлая и самая заметная ось.
6. Тесты (§4.8) прикручивать по ходу, а не в конце.
7. README форка: чем он отличается, с картинками до/после. Судья читает его
   первым.

## 8. Что это меняет для V8 внутри Боссмана

Ничего. V8 продолжается по `docs/v8/IMPLEMENTATION_PLAN.md`, фаза 0 первой.
Форк не заменяет ни студию, ни Video Studio. Единственная связь: то, что ты
узнаешь на форке о поведении платформы, полезно каталогу студии — но
переносить туда можно **знание, а не код**.
