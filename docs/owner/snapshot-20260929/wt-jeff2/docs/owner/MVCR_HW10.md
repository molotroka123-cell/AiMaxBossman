# HW-10 — МВД ЧР: подготовка пакета на ПЕРВИЧНОЕ ПМЖ (trvalý pobyt)

Речь о **первичном** разрешении на постоянное пребывание (povolení k trvalému pobytu), а не о продлении
карточки пребывания. Bossman готовит пакет для вашей проверки и **останавливается на `WAIT_APPROVAL`**.
Заполнить форму ≠ подать заявление: даже если на сайте есть онлайн-форма, её заполнение — не подача.

## Что запускается

Скрипт `app-support/mvcr_prepare.py` (в репозитории — `tools/mvcr_prepare.py`) проходит шаги:

1. **official_rules** — официальные страницы только с доменов реестра: `mvcr.cz`, `mv.gov.cz`,
   `ipc.gov.cz`, `portal.gov.cz`, `frs.gov.cz` (последний — только чтение). Похожие адреса
   (`mvcr-cz.info`, `mvcr.cz.что-то.info`, `http://`, IDN, логин/запись/оплата) отвергаются с причиной.
   Записываются адрес, время получения и sha256 каждой страницы; цитаты правила о сроке, пошлины
   и способа подачи.
2. **residence_timeline** — периоды проживания только из ваших **подтверждённых** фактов с источником.
   Показывается расчёт по датам (дни, годы/месяцы/дни, разрывы). Пересечения, неподтверждённые
   периоды и неверные даты — вопросы, а не догадки. Вывода «вы имеете право на ПМЖ» нет.
3. **current_form** — выбор действующей формы; форма с пометкой «archiv/neplatný» считается
   устаревшей и не выбирается. Нет действующей — `BLOCKED`.
4. **download_and_verify** — тип файла по байтам (HTML-страница ошибки под именем `.pdf` отвергается),
   sha256, PDF открывается и читается, проверяется, что это именно žádost o trvalý pobyt.
   Для каждого файла — JSON с происхождением (`downloads/provenance/`). Из двух форм выбирается
   новейшая по версии, старая помечается как устаревшая; неясно — `BLOCKED`.
5. **fill** — рабочая копия `work/filled_vN.pdf` (прежние версии сохраняются), оригинал не трогается
   (только чтение). Заполняются лишь поля с подтверждённым значением. Подпись и дата подписи — никогда.
   Остальное — `MISSING_DATA` с вопросом; никаких заглушек, похожих на данные.
6. **reopen_verify** — записанный PDF открывается заново, значения сверяются поле за полем;
   если есть `pypdfium2`, строятся превью страниц.
7. **package** — папка `package/` и `review.md` на русском с десятью разделами отчёта; затем запрос
   подтверждения в очереди подтверждений Bossman (`bcc.approvals`) — статус `WAIT_APPROVAL`.

Повторный запуск продолжает с сохранённого состояния (`state.json`): скачанное не качается заново,
черновик сохраняется, ничего не отправляется. Изменили факты — перезаполняется форма, прежнее
подтверждение перестаёт относиться к новому пакету, создаётся новое.

## Что нужно от вас

1. **Папка документов** (`--owner-folder`) — только она читается, ничего в ней не меняется.
   Нельзя: системные папки, `.ssh`/секреты, папку репозитория. Папка вывода должна быть вне её.
2. **Файл фактов** (`--facts`, JSON) — только то, что вы подтверждаете:

```json
{
  "schema": "bossman.mvcr.facts.v1",
  "as_of": "2026-09-22",
  "person": {
    "surname": {"value": "…", "confirmed": true, "source": "doc:pas.pdf"},
    "given_names": {"value": "…", "confirmed": true, "source": "doc:pas.pdf"},
    "birth_date": {"value": "ГГГГ-ММ-ДД", "confirmed": true, "source": "doc:pas.pdf"},
    "nationality": {"value": "…", "confirmed": true, "source": "owner:подтвердил в чате"},
    "passport_number": {"value": "…", "confirmed": true, "source": "doc:pas.pdf"},
    "address_cz": {"value": "…", "confirmed": true, "source": "owner:…"}
  },
  "residence_periods": [
    {"id": "P1", "from": "ГГГГ-ММ-ДД", "to": "ГГГГ-ММ-ДД", "basis": "вид пребывания",
     "confirmed": true, "source": "doc:povoleni.pdf"},
    {"id": "P2", "from": "ГГГГ-ММ-ДД", "to": "ongoing", "basis": "…", "confirmed": true, "source": "doc:…"}
  ]
}
```

`source`: `doc:<файл в вашей папке>` (файл должен существовать — берётся его sha256, содержимое не
копируется) или `owner:<где подтверждено>`. Без `confirmed: true`, без источника, со значением-заглушкой
(`XXX`, `???`, `neznámo`) или с `conflicts_with` факт не используется — появляется вопрос.
Если поля реальной формы названы иначе, укажите соответствие в `--field-map` (`{"имя поля": "ключ факта"}`).

## Как запустить (Windows, из папки Bossman)

```powershell
.\runtime\python.exe app-support\mvcr_prepare.py --owner-folder "D:\Documents\MVCR" --facts "D:\Documents\mvcr_facts.json" --out "$env:LOCALAPPDATA\Bossman\CommandCenter\owner-run\mvcr" --json
```

Решение по пакету (только из `WAIT_APPROVAL`; пакет не должен меняться после просмотра):

```powershell
.\runtime\python.exe app-support\mvcr_prepare.py --facts ... --out ... --decide approve   # или deny
```

`--approvals-db` — файл SQLite очереди подтверждений; по умолчанию `<out>\approval\approvals.sqlite`.

## Статусы и коды выхода

| Статус | Код | Смысл |
|---|---|---|
| `WAIT_APPROVAL` | 0 | Пакет полный и проверен, ждёт вашего решения |
| `PARTIAL_MISSING_DATA` | 10 | Частичный пакет + список вопросов (`package/questions.json`, раздел 5 отчёта) |
| `BLOCKED` | 20 | Дальше идти нельзя; причина в выводе (нет официального источника, только устаревшая форма, файл не PDF, …) |
| `APPROVED_FOR_MANUAL_DELIVERY` | 0 | Вы одобрили: пакет окончательный, подаёте **лично**. Ничего не отправлено |
| `DENIED` | 0 | Вы отказали: ничего не отправлено, черновик сохранён |
| `REFUSED` | 21 | Решение не принято: повтор, пакет изменён после просмотра, нет ожидающего подтверждения |
| — | 2 | Ошибка аргументов |

## Где лежит результат

`<out>\package\review.md` — отчёт; `zadost_VYPLNENO_NEPODEPSANO.pdf` — заполненный черновик;
`zadost_ORIGINAL.pdf` — оригинал; `pokyny\` — официальные инструкции; `manifest.json` — sha256 каждого
файла и что именно покинуло бы компьютер; `sources.json`, `residence_timeline.json`, `field_review.json`,
`questions.json`. В `run.log` нет ваших персональных данных.

## Чего Bossman НЕ делает (и не может — такого кода нет)

- не подаёт заявление, не отправляет e-mail, не пишет в Datová schránka, не загружает файлы;
- не подписывает и не ставит дату подписи;
- не платит пошлину и не создаёт платёжный документ;
- не записывает на приём (frs.gov.cz — только чтение);
- не входит через BankID / NIA / eObčanka;
- не делает вывода о вашем праве на ПМЖ — только арифметика по подтверждённым датам с цитатой правила.

## Что проверено только на синтетике

Тесты (`tests/test_mvcr_prepare.py`) идут на выдуманном сайте и выдуманном человеке. Это не
`OWNER_HARDWARE_PASS`. Реальные адреса страниц МВД, реальная форма (есть ли в ней заполняемые поля
и как они названы), реальная пошлина и способ подачи проверяются только вашим прогоном.
