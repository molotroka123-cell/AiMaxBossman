# Research budget discipline

Research has a cost:
- model compute;
- paid databases;
- interviews;
- ads;
- founder time.

## Question before research

What decision will change?

If no decision changes, do not buy more research.

## Escalation

Free/public evidence
→ customer interview
→ low-cost experiment
→ paid data only if needed.

## Stop

When evidence is sufficient for next gate, stop researching and run the
market test.

Analysis paralysis is a venture failure mode.
