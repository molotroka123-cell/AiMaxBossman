# Pricing engine

Price from value, not token cost.

Inputs:
- customer's economic loss;
- replacement/manual cost;
- incumbent price;
- support burden;
- switching cost;
- buyer budget;
- value metric;
- expansion route.

## Tests

Compare:
- monthly vs annual;
- trial vs no trial;
- free vs no free;
- setup fee;
- seat vs location vs job vs document vs usage.

## Required measurement

For every pricing cohort:
- visitors/leads;
- conversion;
- ARPA;
- refunds;
- support;
- retention;
- downgrade/upgrade.

## Guardrail

Do not underprice simply to generate “traction”.
A product with users but no contribution is not validated.
