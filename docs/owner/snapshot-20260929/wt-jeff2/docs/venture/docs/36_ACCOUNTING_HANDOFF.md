# Accounting handoff

Monthly package per legal entity:
- sales invoices;
- collected payments;
- refunds;
- payment fees;
- subscriptions;
- contractors;
- ads;
- hosting/API;
- receivables;
- VAT-relevant classifications;
- asset purchases;
- owner reimbursements where applicable.

Per venture:
- revenue;
- contribution;
- allocated shared expense;
- cumulative invested cash.

## Reconciliation

Unmatched payment is an exception.

Do not infer tax classification from description when uncertain.
Flag accountant review.
