# AI WebCam Vision — низкое разрешение для детектора: только геометрия (шаг 1)

Проект `CCTV_YOLO` рассмотрен как **референс**, а не как источник кода. Из него
не перенесены: Gradio-демо, зашитый публичный HLS-поток, второй vision-движок и
отдельная архитектура. Перенесена только безопасная половина идеи: пересчёт
рамки объекта из маленького изображения детектора обратно в исходный кадр.

## Что сделано

| Файл | Что это |
|---|---|
| `apps/ai-webcam-vision/src/ai_webcam_vision/pipeline/lowres_detection.py` | чистая геометрия: `ImageSize`, `BoundingBox`, `Detection`, `LetterboxTransform`, `should_sample_for_detection` |
| `apps/ai-webcam-vision/src/ai_webcam_vision/pipeline/__init__.py` | экспорт новых типов |
| `apps/ai-webcam-vision/tests/test_lowres_detection.py` | 9 узких тестов (масштабирование и выключенный режим) |

Свойства модуля:

- **никакой модели и никакого захвата**: нет `opencv`, `torch`, `ultralytics`,
  нет сети, нет загрузки весов, нет записи кадров;
- **выключено по умолчанию**: `should_sample_for_detection(enabled=False, …)`
  всегда `False`; в рантайме модуль пока никем не вызывается (проверено
  поиском по `src/` — ссылок нет), поэтому поведение приложения не изменилось;
- **ограничение частоты**: `every_n_frames` задаёт прореживание, значения < 1
  отвергаются;
- рамка, целиком попавшая в поля letterbox, объектом не считается; частично
  вышедшая за край — обрезается по границам исходного кадра.

## Сохранено без изменений

RTSP/Tapo-транспорт, переподключение с backoff и состояния здоровья не
затронуты (в diff их файлов нет). Не добавлено: распознавание лиц, аудио,
постоянное хранение сырого видео, публичный RTSP-порт. В Bossman по-прежнему
уходят только производные события и метрики.

Валидация: **fixture/unit**, без живой камеры, без GPU и без модели. Ни одного
утверждения про CUDA, YOLO или высокое разрешение здесь не сделано.

## Три оставшихся шлюза приёмки (из пакета)

1. **Gate B — приватность и лицензия модели.** Нужно письменное решение
   владельца: допускаются ли эфемерные (только в памяти) кадры высокого
   разрешения, и какая лицензия у выбранной модели. Кадр не должен попадать в
   лог, результат задачи или контракт с Bossman — наружу только производные
   поля. Требуется тест: URL и пароль камеры не появляются в логах,
   исключениях, API и сохранённом состоянии.
2. **Gate C — железо и живой прогон.** Локальный файл модели без сетевой
   загрузки; честный отчёт CUDA/CPU (импорт Torch не считается использованием
   GPU); прогон неперсонального локального фикстура с проверкой точности
   `source → inference → source`, лимита памяти, частоты и здоровья детектора;
   один явно разрешённый RTSP-прогон, подтверждающий reconnect/backoff и что
   сырое видео по-прежнему не пишется.
3. **Промотирование функции.** Только после B и C: провайдер детектора,
   состояние `disabled` отдельно от `unavailable` в здоровье, откат к
   эвристическому наблюдению при отказе — детектор не блокирует восстановление
   камеры и не выдумывает обнаружения.

## Точный следующий тест

`apps/ai-webcam-vision/tests/test_lowres_detection.py::test_partial_box_is_clipped_to_source_bounds`
уже закрывает геометрию. Следующим должен появиться тест шлюза B:

```
tests/test_lowres_privacy_boundary.py::test_detector_path_never_leaks_frame_or_camera_secret
```

— он обязан провалиться до появления провайдера и пройти только тогда, когда
путь детектора доказуемо не выносит наружу ни кадр, ни секрет камеры.
