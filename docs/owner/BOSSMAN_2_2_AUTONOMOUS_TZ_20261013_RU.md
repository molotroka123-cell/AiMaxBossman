# ТЗ владельца: Bossman 2.2 — агент Windows в Telegram

Актуализация 13.10.2026. Статус: **требования; не акт приёмки**.
Основной контракт — [агентная архитектура](../v2.2-20261013/AGENT_ARCHITECTURE_RU.md),
[39 требований](../v2.2-20261013/REQUIREMENTS_RU.md) и
[выбор моделей](../v2.2-20261013/GENERATION_MODEL_SELECTION_RU.md).

Дальше единственный исполнитель изменений — Argon. Его
[план с четырьмя коммерческими направлениями](../v2.2-20261013/ARGON_IMPLEMENTATION_PLAN_RU.md)
включает один законченный пилот и evidence для последующего независимого аудита качества.

## Что должен получить владелец

Задача обычным языком в общем owner-only пульте → план → настоящее наблюдение Windows
→ управление приложениями/браузером/файлами/разрешёнными командами → проверка результата
→ файл или отчёт обратно. Агент продолжает полезную независимую работу при блокере,
восстанавливается после сбоя и сохраняет STOP. CLI, UI и пульт используют одного Bossman.
Claude/Codex/Gemini не обязательны для принятого production пути.

## Исполнение и модели

- Локальная Qwen — предпочтительный планировщик, исполнитель и диагност. Наблюдение
  использует настоящий desktop/UIA и совместимую vision-модель при необходимости.
- Prompt, image, edit и video выбираются отдельно. Главный предпочтительный профиль
  генерации — uncensored, с реальной привязкой модели и отдельным выбором владельца.
  Неподключённая модель показывается недоступной, без тихой замены обычной.
- Проверяющий получает постусловие и артефакты в чистом контексте; другое семейство
  предпочтительно. Ограниченную независимость и вмешательства учителя фиксировать.
- 256k — прежняя цель; default adaptive 64k присутствует в коде checkpoint. Реальные
  context/model ID/hash фиксируются по конфигурации, а не по старому обещанию.
- До трёх осмысленных попыток на ошибку, проверка обязательна, откат при ухудшении.
  Общего искусственного дедлайна нет; технические таймауты, ресурсный бюджет и STOP остаются.

## Права и решения владельца

Широкий доступ к ПК действует в рамках поручения и принятой конституции. Уже данное
разрешение сохраняется; рутинные разрешённые шаги не требуют нового вопроса. На шаге
с новым чувствительным эффектом пульт показывает действие/причину и кнопки решения;
блокируется только зависимая часть. Личные материалы не отправляются моделям в облако.

`af92a0fd` фиксирует принятую владельцем конституцию v2, а не непринятый черновик v1.
Перед исполнением сверить актуальный runtime pin/hash; модель пин не пишет и не
меняет gates. Продвижение в main, деньги, публикации, внешние сообщения, важное удаление
и изменение защиты выполняются по действующим owner approvals и их области.

## Первый приёмочный результат

Настоящий Telegram → Блокнот → синтетический файл → независимая проверка → доставка.
Отдельно STOP, stale/wrong window, restart, отказ чужому ID, отсутствие дубля.
Затем реальный выбор моделей и короткая нейтральная генерация с замером скорости.
Общее полное управление Windows, независимое обучение, autostart/headless и freeze
получают собственные доказательства; наличие кодовых маршрутов не заменяет их.

Jeff, Motion, Operations, Reports, Poker, Music, Social Farm, Apps и дерево остаются
в том же продукте. Коммерческие результаты и North Star принимаются по полному реестру.
