## Правило выбора

Оценивать каждый кандидат на одной и той же безопасной fixture: (а) точность/полнота, (б) p95 полного времени, (в) RAM/VRAM/CPU, (г) часы интеграции и ухода, (д) риск данных/лицензии, (е) возможность STOP и rollback. Взять зависимость лишь при измеренной пользе относительно существующего пути. Не учитывать GitHub stars как доказательство качества. Лицензия **кода** не даёт права использовать чужие данные, веса, торговые курсы или личный экспорт.

## Что особенно важно для продажи

1. **Сначала текущие активы.** `Docling` уже имеет адаптер; OpenHands/OpenCode, Playwright, faster-whisper, локальные модели и свой watchdog уже фигурируют в репозитории. Повторная установка или второй сервер увеличит время до демонстрации.
2. **Пять причин не тянуть проект в stable сразу:** лицензия не закреплена на точном ревизии; неизвестны права на данные; новая служба дублирует работающую; нет сравнительного результата; STOP/permissions не проходят fault-injection.
3. **Цепочка саморазвития:** Inspect AI/существующий evaluator фиксирует baseline → OpenCode/существующий воркер предлагает кандидат → отдельный verifier пытается его опровергнуть → владелец применяет кандидат → holdout после restart показывает прирост либо откат. mini-SWE-agent и GEPA в этой цепочке опциональны. Никаких заявлений «сам научился», пока нет переноса на неизвестную задачу.
4. **Цепочка первого платного отчёта:** разрешённый источник → существующий War Terminal/Docling → OCDS Kit только при OCDS → человеческая сверка → PDF с источниками → согласованная поставка → квитанция оплаты. Ни один OSS не заменяет договор на данные и принятие клиентом.

## Проверка и решения по порядку

| Когда | Действие | Условие `GO` | Условие `NO-GO` |
|---|---|---|---|
| После разбора CI | Один runner для frozen eval (существующий или Inspect) | Повторяемый baseline/holdout, локальные задачи, полные traces без личных данных | Нет фиксированного оценщика или наблюдаемой разницы. |
| После выбора клиента/источника | Docling/OCDS Kit на пяти документах | 5/5 сверенных карточек, права на данные, измеренная стоимость | Лицензия данных неясна, поля молча теряются. |
| После D1 | WinSW только если Task Scheduler не держит soak | Чистый restart/STOP, ровно один poller | Дублирование службы или невозможный откат. |
| После G3 | mini-SWE-agent/GEPA, по одному | Статистически/практически значимый прирост на frozen holdout без роста риска/затрат | Улучшение только на train или память вместо переноса. |

**Ничего из списка этим документом не установлено, не скачано и не запущено.** Точный версии/коммиты — snapshot исследований, не новые lockfile-пины. При следующем цикле обновить upstream снимок и повторить лицензионную сверку.
