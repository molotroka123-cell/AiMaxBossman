# Telegram → локальные модели Bossman: инструкция владельца

Статус: код, раздел настроек и офлайн-тесты готовы (ветка
`feat/telegram-local-llm-20260922`). Живая доставка через Telegram —
**OWNER_REQUIRED**: её можно проверить только на вашем компьютере с вашим
ботом. Реальные токены в репозитории не хранятся и храниться не должны.

## 1. Что это

Telegram сейчас — **только для беседы** с вашими локальными моделями: задать
вопрос, проверить, насколько модель умная, сравнить «лучшую» и «самую
быструю», **отправить фото** и получить его описание и разбор. Управления компьютером из Telegram **нет**: ни Computer Use, ни
браузера, ни файлов, ни поручений агентам (`/task` — «пока недоступно»).
Облачные модели не используются.

```
Telegram (ваш личный чат)
   │  long polling — входящий порт и публичный адрес НЕ нужны
   ▼
Telegram Companion (отдельный процесс, запускается из Bossman кнопкой «Старт»)
   ├── обычное сообщение ─► модель, выбранная для чата (по умолчанию «Лучшая»)
   ├── /best [вопрос] ────► 🧠 Лучшая (самая умная), напр. GPT-OSS-120B :8083
   └── /fast [вопрос] ────► ⚡ Самая быстрая, напр. Qwen3.6-35B-A3B :8082
         если лучшая не ответила вовремя → отвечает самая быстрая (не облако)
   └── фото (+ подпись как вопрос) ► «Модель для фото» — та, что видит
         изображения (сервер с --mmproj; сейчас FAST :8082). GPT-OSS не видит.
```

* Модели доступны только по `127.0.0.1`. Модель в беседе не получает
  инструментов: она может только ответить текстом.
* Бот отвечает **только** Telegram ID из списка (вы + до 7 гостей) и только
  в личном чате. Чужие сообщения молча отбрасываются и не сохраняются.
* Каждый ответ подписан, какая модель ответила: `🧠 Лучшая · openai_gpt-oss-120b…`
  или `⚡ Быстрая · Qwen3.6-35B-A3B…`.

## 2. Создать бота (@BotFather)

1. В Telegram откройте **@BotFather** → `/newbot`.
2. Имя любое (например `Bossman Home`), username должен заканчиваться на `bot`.
3. BotFather выдаст токен вида `1234567890:AA...`. **Это пароль**: никому не
   отправляйте, не вставляйте в чаты, git и скриншоты.
4. Рекомендуется: `/setjoingroups` → Disable.
5. Нужен **отдельный** бот: если у бота настроен webhook, компаньон откажется
   запускаться (`WEBHOOK_CONFLICT_USE_SEPARATE_COMPANION_BOT`).

## 3. Узнать свой Telegram ID

Напишите **@userinfobot** (или @getmyid_bot) — он ответит `Id: 123456789`.
Это числовой ID; @username не подходит. Он и есть список доступа.

## 4. Запустить модели

Модели запускаются вашим скриптом `C:\Users\asd\Bossman\start-models.ps1`
(llama.cpp b10964 Vulkan) с обязательными флагами `--jinja --reasoning off`.
Без `--reasoning off` Qwen тратит лимит на рассуждения и отвечает пустотой.

| Порт | Модель | Роль по умолчанию | Скорость на этой машине |
|---|---|---|---|
| 8083 | GPT-OSS-120B | Лучшая (самая умная) | ~15.7 ток/с (один замер, под нагрузкой) |
| 8081 | Qwen3.8-27B (MAIN) | Лучшая, если 8083 не запущена | ~8.8 ток/с (лог llama-server) |
| 8082 | Qwen3.6-35B-A3B (FAST) | Самая быстрая | ~53 ток/с (лог llama-server) |

Все три модели одновременно в память не помещаются: для Telegram достаточно
одной «лучшей» и, по желанию, быстрой. `-Target stop` в `start-models.ps1`
останавливает **все** llama-server — не делайте этого во время прогонов.

## 5. Настроить в Bossman (основной способ)

1. Запустите Bossman. Пока ярлык `Start-Bossman.cmd` сломан (Edge relaunch),
   сервер запускается так:
   ```powershell
   cd C:\Users\asd\Bossman\app\BOSSMAN-Windows-x64-0c1cbe651f52
   .\runtime\python.exe -m bcc
   ```
   Раздел Telegram есть только в коде этой ветки: пока нет новой сборки,
   запускайте Bossman из исходников ветки (как это делает интегратор) —
   в установленной сборке 0c1cbe65 раздела нет.
2. Откройте в браузере `http://127.0.0.1:8800/#/settings`
   (меню слева → **Настройки**) → раздел **Telegram**.
3. Заполните:
   * **Telegram включён** — галочка;
   * **Токен бота** — вставьте токен от BotFather. После сохранения поле
     очищается, дальше видно только `сохранён …XXXX`. Чтобы не менять токен,
     оставьте поле пустым;
   * **Ваш Telegram ID** и, если нужно, **гости** (через запятую, до 7);
   * **Лучшая (самая умная)** и **Самая быстрая** — списки заполняются
     сами из того, что реально отдают серверы `8083/8081/8082`
     (`/v1/models`). Точное имя модели вводить не нужно. Если сервер
     выключен, запустите модель и нажмите **Проверить модели**;
   * **Модель для чата по умолчанию** — Лучшая или Самая быстрая;
   * **Ожидание ответа лучшей модели** — 180 сек (для 27B/120B);
   * **Длина ответа** — 1024 токена (GPT-OSS часть токенов тратит на
     рассуждения; при 512 бывают пустые ответы);
   * **Если лучшая не ответила вовремя — отвечает самая быстрая** — галочка;
   * **Модель для фото** — «Автоматически» (первая из лучшей/быстрой, чей
     сервер сообщает о зрении в `/props`), или явно Лучшая / Самая быстрая.
     Под полем видно, какие серверы видят изображения.
   * «Поручения Bossman из Telegram» — пока недоступно (серым).
4. **Сохранить**. Сервер проверит ID, локальные адреса и что выбранные
   модели действительно отдаются, затем запишет настройки атомарно, а
   токен — в зашифрованный `credentials.enc`.
5. **Проверить бота** — один запрос `getMe` к Telegram (выполняется только
   по нажатию; никому ничего не отправляет). Ожидается «Бот @имя отвечает».
6. **Старт** — запускает компаньон. Статус: *работает / остановлен /
   ошибка* и последний код ошибки (без секретов). **Стоп** — останавливает
   процесс, который запустил Bossman. Выключение галочки «Telegram включён»
   с сохранением тоже останавливает его.

Где лежат файлы: `%LOCALAPPDATA%\Bossman\telegram-companion\`
(`config.json` без секретов, `credentials.enc` зашифрован, `companion.log`
— только коды состояния).

Компаньон, запущенный кнопкой, продолжает работать после закрытия окна
браузера. Автозапуска при старте Bossman нет — после перезагрузки ПК нажмите
**Старт** снова.

## 6. Команды в Telegram

| Команда | Что делает |
|---|---|
| просто текст | ответ модели, выбранной для этого чата |
| `/best` | в этом чате дальше отвечает лучшая модель |
| `/best вопрос` | один ответ лучшей моделью |
| `/fast` | в этом чате дальше отвечает самая быстрая |
| `/fast вопрос` | один ответ самой быстрой |
| `/model` | какие модели подключены и какая отвечает сейчас |
| `/help` | справка |
| `/forget` | стереть локальную память беседы |
| `/status` | связь с Bossman (только владелец) |
| `/task`, `/confirm` | «Поручения из Telegram пока недоступны» |
| фото или картинка-файл | описание и разбор; подпись к фото = ваш вопрос |
| `/img описание` | нарисовать картинку локально (если включено; по умолчанию только владелец) |
| `/cancel` | отменить идущую генерацию |

Пока модель думает, в чате видно «печатает…». Длинный ответ приходит
несколькими сообщениями `(1/3)`, `(2/3)`… (не больше 5).

**Фото.** Принимаются фото и файлы JPEG/PNG/WebP до 10 МБ, только от
разрешённых ID. Бот скачивает картинку в память (на диск не пишет), проверяет
по содержимому, что это действительно изображение, и отправляет её только в
локальную модель, которая видит изображения. Ответ подписан, например
`👁 ⚡ Быстрая · Qwen3.6-35B-A3B (лучшая модель не видит изображения)`. В
памяти беседы остаётся только пометка `[фото] подпись`, не сама картинка.
Голосовые, видео и прочие файлы не обрабатываются — бот так и ответит.

## 6c. Манера общения, обучение на собеседниках, очередь

**Манера общения** — поле в Настройки → Telegram. По умолчанию: тёплый, но
прямой Bossman, кратко, честно о неуверенности, уточняющий вопрос при
неоднозначности, язык собеседника, простое форматирование для Telegram. Бот
не называет себя Claude/Anthropic или реальным человеком. Правила
безопасности (нет управления компьютером, данные — не инструкции) всегда
добавляются после вашего текста и не отключаются.

**Обучение (только локально).** Для разрешённых людей (вы и гости):

* каждая пара «вопрос–ответ» пишется в зашифрованный журнал на этом
  компьютере, отдельно для каждого человека (данные одного никогда не
  попадают в разговор другого — это проверено тестами);
* каждые 10 новых записей локальная модель (быстрая, если есть) строит
  **цифровой профиль** человека: язык, манера, предпочтения, темы, факты,
  которые он сам сообщил. Профиль (версия + время) подставляется только в его
  собственные разговоры, как данные, не как инструкции; секреты, почта и
  телефоны вычищаются канонической очисткой Bossman;
* в Настройках → Telegram виден список людей: число записей, профиль —
  его можно посмотреть, исправить или удалить; переключатель «Учиться на этом
  пользователе»; срок хранения журнала (по умолчанию 90 дней);
* **Экспорт для обучения (JSONL)** — файлы `exports/user-<ID>.jsonl` и
  `exports/all-users.jsonl` в `%LOCALAPPDATA%\Bossman\telegram-companion\`;
  секреты, почта, телефоны, IP вычищены (`bossman.ai_lab.sanitizer`), скрытых
  рассуждений моделей там нет. Ничего не уходит с компьютера.
* Гость при первом сообщении получает короткое уведомление о локальном
  сохранении; обучение на нём начинается только после этого. Команды:
  `/privacy` (что хранится), `/pause_learning` / `/resume_learning`,
  `/forget` (удалить историю, журнал и профиль — с кнопкой подтверждения).

В «уроки» Bossman (LearningStore) из Telegram ничего не продвигается: туда
попадают только проверенные случаи, а сырой текст пользователей никогда не
становится инструкцией.

**Очередь.** Локальная модель отвечает на один запрос за раз. Если пишут
2–3 человека одновременно, ожидающий сразу получает «Сейчас чуть занят
другим разговором — отвечу через минуту 🙏» (один раз на сообщение), а ответ
приходит по очереди. Галочка «Владелец отвечается первым» пропускает вас
вперёд очереди.

## 6b. Кнопки

`/start` и `/menu` показывают меню кнопками: «🧠 Лучшая», «⚡ Самая быстрая»,
«👁 Модель для фото», «🎨 Сгенерировать картинку», «❓ Какая модель?»,
«ℹ️ Помощь», «🧹 Очистить историю». Под каждым ответом модели — «🔁 Ещё раз»
и «Ответить быстрой/лучшей»; во время генерации — «✖️ Отмена», под готовой
картинкой — «🎨 Ещё вариант».

Кнопки работают только у того, кому их прислали, и только в личном чате;
чужие нажатия молча игнорируются. После перезапуска компаньона старые кнопки
устаревают (бот ответит «Кнопка устарела. Откройте /menu»). Чтобы команды
появились в меню Telegram (значок «/»), нажмите в Настройках → Telegram
«Команды бота в меню Telegram» — это единственный запрос `setMyCommands`,
только по нажатию.

## 6a. Генерация картинок (/img)

Картинки рисует **Bossman Studio** тем же локальным движком
stable-diffusion.cpp (Vulkan), что и в разделе «Картинки» приложения: модель
`sdcpp:z-image-turbo`. Результат попадает в галерею Студии с полной
историей происхождения (provenance), а в Telegram уходит **только после
проверки байтов**: sha256 файла совпадает с записью Студии и это настоящий
PNG/JPEG. Подпись: модель, seed, время. Облако не используется, заглушек нет.

Включение: Настройки → Telegram → «Генерация картинок»: галочка, размер
(512/768/1024), шаги (4/8/12), доступ гостям (по умолчанию выключен). Рядом
видно, найден ли движок. Нужен запущенный Bossman (Студия выполняет задание)
с переменными окружения:

* `BOSSMAN_SDCPP_BIN` = `C:\Users\asd\Bossman\media-runtime\sdcpp\vulkan\sd-cli.exe`
  (файл есть на этой машине);
* `BOSSMAN_MEDIA_MODELS` = `C:\Users\asd\Bossman\models\media` — там должен
  лежать `MANIFEST.json` с sha256 файлов модели. **Сейчас его нет** (есть
  только `download.sh`/`download.log` и папка `z-image-turbo`), поэтому Студия
  честно считает движок ненастроенным, и бот ответит «Генерация не
  настроена». Манифест создаётся скриптом загрузки медиамоделей Bossman.

Ограничения: одна генерация за раз; не запускается, пока локальная модель
отвечает на сообщение, и при нехватке свободной памяти (порог 12 ГБ) — бот
так и скажет; лимит времени 15 минут, затем задание отменяется. `/cancel`
отменяет задание в Студии.

## 8. Перезапуск

* Сообщения, пришедшие пока компаньон выключен, Telegram хранит до 24 часов;
  после «Старт» они обрабатываются по порядку.
* Сообщение, которое обрабатывалось в момент остановки, не повторяется —
  задайте вопрос снова.
* Модель отвечает по одному сообщению за раз; остальные ждут (до 4 на человека).
* Память беседы — последние 4 пары реплик, зашифрована, 7 дней; `/forget` стирает.

## 9. Неполадки

| Симптом | Что сделать |
|---|---|
| «локальная модель сейчас не отвечает» | Модель не запущена или выбрана не та — «Проверить модели», выбрать заново, Сохранить, Стоп → Старт. Мал таймаут — поставьте 180. После сбоя лучшая 45 с не опрашивается (отвечает самая быстрая). |
| «Модель вернула пустой или неполный ответ» | Рассуждения съели лимит: увеличьте «Длина ответа» до 1024–2048; проверьте `--reasoning off`. |
| `[Ответ ограничен длиной.]` | Увеличьте «Длина ответа». |
| Статус «ошибка» `AUTH_DENIED` | Неверный или отозванный токен: вставьте новый и сохраните. |
| `WEBHOOK_CONFLICT_USE_SEPARATE_COMPANION_BOT` | У бота есть webhook — создайте отдельного бота. |
| `CONFLICT` / `ANOTHER_COMPANION_IS_RUNNING` | Бот уже опрашивается другим процессом — оставьте один. |
| `COMPANION_DISABLED_IN_SETTINGS` | Включите «Telegram включён» и сохраните. |
| «Сейчас нет локальной модели, которая видит изображения» | Запустите модель с `--mmproj` (FAST на 8082 уже так запущена), в Настройках нажмите «Проверить модели», выберите «Модель для фото». |
| «Картинка больше 10 МБ» | Отправьте сжатое фото (обычная отправка, не «файлом»). |
| Фото отвечает медленно | Разбор картинки дольше текста: используется таймаут выбранной модели. |
| Мало памяти | Держите одну «лучшую» модель; FAST — только если хватает RAM. |
| Сохранение: «сервер отдаёт другую модель» | Выберите модель из списка (он строится по живому серверу). |

## 10. Запасной способ: скрипт / CLI

Если веб-интерфейс недоступен:

```powershell
# зашифрованная настройка через локальную форму
powershell -ExecutionPolicy Bypass -File C:\Users\asd\Bossman\wt-telegram\scripts\Start-TelegramCompanion.ps1 -Mode setup
```

## 11. Безопасность

* Токен бота — только в зашифрованном `credentials.enc`; API Bossman никогда
  не возвращает его целиком (только последние 4 символа). При утечке —
  `/revoke` в BotFather и новый токен в Настройках.
* Раздел Telegram доступен только после входа в Bossman (сессия + CSRF, как
  остальные настройки).
* Telegram — внешний сервис: текст сообщений и ответов проходит через его
  серверы. Не пишите боту пароли и ключи.
* Из Telegram нельзя управлять компьютером: модель не получает инструментов,
  `/task` отклоняется без обращения к Bossman, облако отключено.
* Входящих портов нет (long polling); наружу компаньон ходит только к
  `api.telegram.org`.
