## 2. Натуральная модель красителя

Почему «кислотно»: целевая хрома накладывается равномерно на все пиксели. У настоящей окраски по тёмным волосам: тени и корни темнее и менее насыщенны; хрома растёт со светлотой до потолка; блики сохраняют оттенок, но белеют; просвечивает исходный цвет.

Модель (`dye_model.py`) по рангу яркости пикселя `t` внутри волос своего кадра (0 = самая тёмная прядь, 1 = блик):
`L(t)=L0+(L1-L0)t^gam`, `C(t)=C0+(Cmax-C0)*smoothstep(tc-w, tc+w, t)`, `h(t)=h0+dh(t-0.5)`, блик: `C*=1-sd*spec`, `L+=sl*spec*(96-L)`; корни: `L*=1-rd*r`, `C*=1-rc*r` (r = близость к границе кожи); просвет: `(a,b)=(1-u)(a,b)_dye+u(a,b)_src`, `u=u0(1-t)`. Тонкая структура прядей исходника добавляется как у RefLook. Композит премультиплицированный: `out = I + alpha (T(F) - F)`, F = цвет переднего плана без старого фона.

Подгонка (`fit_presets.py`): по эталонам владельца, внутри GT-маски, 40 бинов по рангу яркости оригинала, медианы L, a, b эталона, bounded least squares. Фронт: pink, platinum, blue, red (кадр gf7). Вид сзади: chestnut-brown, copper-red, ash-platinum (маска = область изменения между natural-dark и эталоном). Средняя dE00 по бинам: 0.3–2.3 (максимум 10 у platinum).

Натуральное семейство (`build_presets.py`) выведено той же моделью: форма кривых (темнота теней, подъём хромы, наклон оттенка, блик) взята с эталонов «вид сзади» (chestnut/copper = тёмный класс, ash-platinum = светлый), масштабирована под целевую светлоту бликов, потолок хромы и оттенок. Цвета-цели — правдоподобные салонные значения Lab фотографии, не спектрофотометрия. Мягкие версии pink/blue/red/platinum = подогнанные по эталону кривые, у которых потолок хромы x0.62–0.80, хрома теней x0.5–0.6, глубокие тени L0 x0.6, добавлены корни и просвет.

`hair_presets_natural.json`: 19 пресетов: 4 «эталонных» (stylised), 3 «вид сзади» (natural), 8 натуральных (chocolate, chestnut, copper, burgundy, plum, ash-blonde, navy-black, platinum-natural), 3 мягкие pink/blue/red-natural, teal-green (stylised). Поля: name, label_ru/en, kind natural|stylised, кривые Lab, source подгонки, swatch.

## 3. Выход маски за волосы

Реализовано (`bleed.py`): (a) эрозия внешнего контура 1–2 px только там, где фон ярче волос (и ниже по хроме, чем потолок краски), плюс более резкий ramp альфы в этой зоне; (b) премультиплицированный композит с оценкой цвета переднего плана (деконтаминация); (c) зажим: кожа (парсинг лица) исключается, если пиксель не тёмный как волосы; вне расширенной матты человека не красим; пиксели ярче собственных волос кадра (рубашка, стена) отсекаются; (d) метрика.

Метрика на кадре с настоящим GT (gf7), доля изменённых пикселей (dE76>4) вне GT, расширенной на 2 px, к площади волос:

| Цвет | до (v2b) | после | видимое (dE>8) до -> после | F1@3px до -> после | IoU до -> после |
|---|---|---|---|---|---|
| pink | 10.4 % | 8.4 % | 9.8 -> 8.1 % | 0.491 -> 0.591 | 0.831 -> 0.842 |
| platinum | 10.3 % | 8.5 % | 9.7 -> 8.3 % | 0.521 -> 0.588 | 0.833 -> 0.841 |
| blue | 10.6 % | 8.3 % | 9.9 -> 8.0 % | 0.479 -> 0.594 | 0.830 -> 0.843 |
| red | 10.4 % | 8.3 % | 9.7 -> 8.0 % | 0.488 -> 0.586 | 0.831 -> 0.842 |

**Порог 0.5 % НЕ достигнут** (8.3 % вместо 10.4 %). Причина измерена: 85 % остатка — два пятна (тень под подбородком справа ~11 тыс. px, чёрная толстовка слева ~9 тыс. px), которые SegFormer/SAM2 относят к волосам; по цвету (L 2-4, a, b около 0) и по текстуре они неотличимы от чёрных волос (см. STATE.md разделы 7-8). Края (контур 2-3 px) вклад дают мало: эрозия 0->3 px снижает лишь 9.1 -> 8.3 %. Достижимо только данными: ручной трафарет на кадрах (агент stencil).

На 6 кадрах видео (ролик (b), кадры 75, 95, 115, 135, 160, 185 x 4 цвета; GT нет, поэтому метрика hair_v2.frame_metrics: изменённые пиксели вне матты человека на изменённый пиксель): draft v2b 7.3 % (max 12.0 %) -> natural+bleed 2.1 % (max 4.6 %); доля кожи 0.17 % -> 0.07 %. Сводка на всём ролике (hair_summary, каждый 3-й кадр цветных планов): ролик (b) leak 9.25 % -> 3.22 % (worst 12.3 -> 6.2 %), кожа 0.27 -> 0.11 %; промо №6 leak 8.38 % -> 2.73 % (worst 12.4 -> 5.1 %), кожа 0.25 -> 0.10 %. (Цифра 1.4 % из задания относилась к другой выборке кадров; здесь одна и та же выборка до/после. Цель 0.5 % по этой метрике тоже не достигнута.)

## 5. OSS-метод на GPU

Не запускался: у машины AMD Radeon 8060S без CUDA, в окружениях нет torch; HairFastGAN по README только Linux+CUDA; `t3_done.flag` тоже не появился. Следовательно, вывод «побеждает ли HairFastGAN модель красителя» не сделан. Из обзора ожидание: генератор дрейфует личность и фон, требует выровненного 1024-кропа и не даёт контроля потолка хромы, поэтому для 9:16 видео по кадрам не лучше.
