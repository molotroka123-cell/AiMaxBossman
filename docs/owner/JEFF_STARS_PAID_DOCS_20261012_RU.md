# Jeff: платный помощник по документам на Telegram Stars (12.10.2026)

Статус: **готов к тестовой среде Telegram, публичный запуск НЕ выполнялся.** Реальные списания, публичный запуск и
рассылки — только после одобрения владельца. Stars не названы прибылью нигде в продукте и в этом документе.

## 1. Официальные условия Telegram (проверено 12.10.2026 по первоисточникам)

Источники: `core.telegram.org/bots/payments-stars`, `core.telegram.org/bots/api` (разделы `sendInvoice`,
`answerPreCheckoutQuery`, `refundStarPayment`, `SuccessfulPayment`, `RefundedPayment`), `core.telegram.org/bots/features`
(тестовая среда), `core.telegram.org/api/stars`, `telegram.org/tos/bot-developers` (п. 6.2), `telegram.org/tos/stars`.

| Тема | Что сказано | Как учтено |
|---|---|---|
| Цифровые услуги | Продаются только за Stars, валюта `XTR`, `provider_token` пустой, в `prices` ровно один элемент | счёт: `currency=XTR`, `provider_token=""`, один пункт (тест) |
| Подтверждение | `pre_checkout_query` нужно подтвердить **за 10 секунд**, иначе платёж отменяется | ответ в цикле опроса до всего прочего; обновление каталога вынесено в фон |
| Идентификатор платежа | `telegram_payment_charge_id` в `successful_payment`, нужен для возврата | первичный ключ платежа в учёте |

| Поддержка | бот обязан отвечать на `/paysupport`; спорный платёж пользователь передаёт в BotFather | `/paysupport` создаёт обращение, `/tickets` у владельца |
| Условия | обязателен `/terms`, понятный текст; полная ответственность за споры на владельце бота | `/terms`, ссылка на него в описании счёта |
| Холд и вывод | Stars на балансе могут быть недоступны для вывода **до 21 дня**; вывод через Fragment в TON, с 2FA владельца; минимум/максимум и курс задаются клиентским конфигом (`stars_revenue_withdrawal_min/max`, `stars_usd_withdraw_rate_x1000`) — **числа в доках не приведены** | выведенное и расходы вносятся владельцем вручную отдельными строками |

| Возврат Stars покупателем | продажи Stars покупателям окончательные; возвраты разработчик делает только за недоставленную услугу | текст `/terms` |
| Рекомендация Telegram | не продавать в реальном времени цифровое, что нельзя отозвать/заморозить | доступ — отзываемые кредиты в учёте, а не файлы |
| Тестовая среда | `https://api.telegram.org/bot<token>/test/METHOD`, отдельный тестовый аккаунт и бот через @BotFather; Stars там бесплатны | `BOSSMAN_TELEGRAM_TEST_ENV=1` |
| Налоги | на владельце бота, Telegram их не считает и не платит | вне продукта; в условиях запуска |

Чего в официальных страницах **нет**: конкретных чисел минимального вывода, курса Stars→USD и срока холда сверх
«до 21 дня». Их нельзя называть как факт до проверки в «Мои Stars» владельца.

## 2. Продукт

**Один пакет «Документы: 30 дней»**: 199 ⭐, 30 дней, 150 запросов (вопрос с цитатами / сводка / черновик сообщения),
до 25 документов. **Бесплатный пробный лимит**: 3 запроса и 2 документа на человека, один раз.

- Загрузка файла (txt, md, csv, json, xlsx, docx, pptx, epub; PDF — если на установке есть `pypdf`, иначе честный отказ).
- `/ask <вопрос>` — ответ только по фрагментам, с номерами `[n]` и блоком «Источники» (документ · место · точная фраза).
- `/summary [№]`, `/draft <задача>`, `/docs`, `/deldoc <№>`, `/plan`, `/buy`, `/terms`, `/paysupport`.
- Владелец: `/payments`, `/refund <charge_id>`, `/tickets`, `/ledger_add withdrawal|expense …`.
- Включается `BOSSMAN_JEFF_PAID_DOCS=1`; без флага Jeff ведёт себя как раньше (тест).

### Известные ограничения после ревью 3

- **Сверка по `getStarTransactions` не реализована.** Событие оплаты, пропущенное при простое дольше суток (Telegram
  хранит необработанные обновления 24 часа), в учёт не попадёт; владелец видит расхождение только сверкой «Мои Stars» с
  `/payments`. Автоматическая сверка — отдельная задача.
- **Запрос остаётся списанным, если модель ответила, а доставка в Telegram не удалась.** Это сознательная политика
  (ответ был произведён и оплачен вычислением); возврат такого запроса — только через `/paysupport`.
- Job Object назначается процессу сразу после запуска (миллисекунды): ребёнок сам ставит потолки на себя первым делом,
  поэтому окно не открывает память, но `AssignProcessToJobObject` на Windows 7 и старее не поддерживает вложенные задания.
- Ячейка таблицы длиннее 2000 символов обрезается парсером `file_intel` молча (по ячейке, не по документу); «частично»
  этого не отмечает.
- Оценка «~M» для docx считает абзацы с текстом и таблицы, для pdf — страницы через `pypdf`; для epub и json общее число
  неизвестно, сообщение говорит «в файле их больше».

## 4. Себестоимость одного пользователя (измерено, не оценено «на глаз»)

Замер 12.10.2026, локальная модель через Ollama, тот же маршрут запросов, что у Jeff (без «рассуждений»):

| Показатель | Значение |
|---|---|
| запрос к документу ~31 тыс. символов | 1717–1723 токена на входе, 46–52 на выходе |
| время ответа (модель прогрета) | 3.7–3.8 с |
| цена модели | 0 $ (локальная, бесплатные маршруты Jeff) |

Расчётная часть (допущения указаны явно, не измерены): ~120 Вт × 4 с ≈ 0.13 Вт·ч на запрос → при 0.10 $/кВт·ч ≈
0.00001 $; 150 запросов пакета ≈ 0.002 $. Если бы маршрут был платным (гипотеза 1 $ / 5 $ за млн токенов вход/выход):
≈ 0.002 $ на запрос, ≈ 0.3 $ на пакет. Платные маршруты в Jeff выключены владельцем. **Основная стоимость — не модель,
а поддержка и ваше время**; её нужно измерить на первых пользователях.

## 5. Цена-гипотеза

199 ⭐ за пакет — **гипотеза для эксперимента**, не цена рынка. Что неизвестно: чистый денежный эквивалент Stars при
выводе (зависит от клиентского конфига и курса TON/Fragment), спрос и конверсия. Правильная последовательность:
техническая готовность → интерес → принятый заказ → подтверждённая оплата → вывод → прибыль после расходов.
Сейчас достигнут только первый пункт и только в симуляции.

## 6. Условия запуска (что нужно от владельца)

1. **Тестовая среда Telegram** (шаг только для человека): создать тестовый аккаунт (клиент → Settings ×10 → Accounts →
   Login → Test), создать бота через @BotFather тестовой среды, дать токен. Запуск: `BOSSMAN_TELEGRAM_TEST_ENV=1`,
   `BOSSMAN_JEFF_PAID_DOCS=1`. Проверить руками: `/buy` → оплата → `/ask` → `/refund`.
2. Одобрить цену, текст `/terms` и пробный лимит.
3. Включить `allowlist_open` для публичного доступа (иначе платить смогут только перечисленные люди) и решить, кто
   отвечает на `/paysupport` (сейчас владелец вручную через `/tickets`; пуша владельцу нет).
4. Проверить в «Мои Stars» реальные минимум вывода, курс и холд; налоги и самозанятость — на владельце.
5. Не включать «темы в личных чатах» (комиссия 15 %).
6. PDF: поставить `pypdf` в сборку, иначе PDF честно отклоняются (скан без текста всё равно не читается).

## 7. Пределы честности
