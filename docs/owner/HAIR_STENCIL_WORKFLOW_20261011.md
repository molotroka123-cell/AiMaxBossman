## 2. Как исправить кадры за ~10 минут

1. Откройте `hair_stencil_editor.html` двойным щелчком (браузер, интернет не нужен; работает и на телефоне в узком окне).
2. **Кадры** -> выберите все PNG из `frames`. **Маски** -> все PNG из `auto_masks`. Пары находятся по имени сами.
3. Красный слой = «волосы» по версии системы. Ластик (`E`) убирает тень под подбородком, толстовку, фон, лишнее на щеке. Кисть + (`B`) дорисовывает пропущенные пряди. Размер: ползунок или `[` `]`; мягкость краю 20-40.
4. `Ctrl+S` / **Сохранить PNG**: файл получает то же имя + `_edited` (например `adb-promo6_clip1_f00106_edited.png`). Следующий кадр: `PageDown`. Правки при переходе не теряются; **Сохранить все** скачивает все изменённые.
5. Положите `*_edited.png` в папку `edited` рядом с `frames`.

Время: 9 кадров x ~1 мин = ~10 минут; исправлять надо только грубые области (тень, одежда, пропущенный клок), мелкие волоски не нужны.
Исправлять нужно не все 9: если кадр авто-маска передала верно, можно сохранить его без правок (он всё равно будет опорным).

## 3. Как запустить распространение

Нужен Python с OpenCV + numpy (flow) или venv с torch+sam2 (sam2/fused). Всё на CPU; GPU и FaceFusion не нужны.

```
python tools/trend_edit/stencil/stencil_propagate.py run ^
   --pack C:\Users\asd\Videos\Bossman-Genjutsu\hair-stencil-20261011\adb-promo6_clip1 ^
   --edited C:\Users\asd\Videos\Bossman-Genjutsu\hair-stencil-20261011\adb-promo6_clip1\edited ^
   --backend flow
```

Результат: `<пакет>\propagated\masks\<имя>_fNNNNN.png` (8 бит, мягкая маска на КАЖДЫЙ кадр отрезков), `preview.jpg`, `report.json`.
В `report.json` блок `holdout`: каждый исправленный кадр по очереди выбрасывается, клип распространяется от остальных, результат сравнивается с вашей правкой (IoU, F1 3 px) и с «копией ближайшего опорного кадра» (чтобы было видно, что даёт распространение). Это и есть доказательство качества на ваших данных.

Бэкенды: `flow` (DIS optical flow, цепочка кадр за кадром вперёд от предыдущего и назад от следующего опорного кадра, смешение по расстоянию, потом guided filter в полосе +-6 px; ~0.3 c на кадр), `sam2` (SAM2.1-tiny video predictor, маски как промпт; CPU, 2-4 c на кадр), `fused` (среднее двух + тот же refine). RAFT не подключён (не нужен torch-оптический поток для этого уровня; по факту DIS хватает, см. цифры).

Ожидаемое время: flow ~1 мин на 90 кадров отрезка (+ ~0.5 мин на holdout-проверку); sam2 ~10-18 мин на тот же объём на CPU под низким приоритетом.

## 5. Поиск источника, где волосы разделяются проще

Метрика (`find_sources.py`, 10 кадров на клип, SegFormer CPU): доля границы волос, рядом с которой (в пределах 12 px) лежит тёмная (L* < 30) НЕ-волосяная область крупнее волоска: `dark_clothes_bg` (одежда/фон) и `neck_shadow` (тень на шее у кожи). `score = 1 - (dark_clothes_bg + 0.5 * neck_shadow)`. Клип «пригоден», если волосы целиком в кадре (не обрезаны краем) минимум в 60 % кадров и голова >= 70 px.

## 6. Параметры и ограничения

- Авто-маска пакетов: SegFormer x SAM2.1-tiny (ONNX, CPU) + рост 4 px + guided filter r8 thr 0.3. Мой повтор на gf7: IoU 0.850 / F1@3 0.576 (бенч 11.10: 0.860 / 0.655; разница в выборе кандидата SAM без GT). 2.5 c на кадр.
- Выбор кадров: признаки по маске (смещение центра волос от центра кожи как прокси поворота/наклона, заполненность, размер, положение, 3 главные компоненты формы маски, время). Это НЕ угол головы (детектора лица/FaceFusion нет), но порядок смены позы схватывает. Метод по умолчанию k-center с локальным поиском (минимизирует худшее расстояние от кадра до ближайшего опорного; k-means оставлен флагом `--method kmeans`, на тесте он проигрывал равномерной выборке по худшему кадру).
- Распространение работает внутри непрерывного отрезка (`spans_s` в `keyframes.json`); через склейку A->B не идёт.
- SegFormer-B2-clothes: лицензия некоммерческая (только личное использование), как и остальной конвейер волос.
- Размеры после правки: маску можно подставить в `hair_v2.recolor` вместо alpha; в ролики это НЕ подключено.
