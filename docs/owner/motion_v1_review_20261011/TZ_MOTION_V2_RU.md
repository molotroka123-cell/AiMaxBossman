## 1. Цель, формат, аудитория
4 ролика (`01_sources/owner_inputs_4/input_01..04`) довести до v2 в формате **9:16 1080×1920 без растяжения** (недостающую область **дорисовывать**, не тянуть), со сохранённым звуком; показать владельцу «до/после». Аудитория: владелец → соцсети (тик-ток/инста).

## 2. Требования владельца (его слова в этой сессии; ID сообщений пульта недоступны)
- Довести 4 видео до V2, 9:16, «не растягивать, а пригенерировать»; качество и выход «минимум на 100% лучше по всем параметрам» (сообщение 11.10).
- Приоритет: face swap 2.0 и Genjutsu object swap 2.0; можно брать опенсорс и учить на RunPod (сообщение 11.10; **последним указанием платные запуски только с отдельным явным разрешением**).
- Порядок этапов: 1 face swap видео→видео, 2 clothes swap, 3 mimics 2.0 (мимика ≥ 99 %), 4 фон; тест на каждом, потом дальше.
- Волосы естественные, как на его референсах; не «шапка/кислота»; не слайдшоу вместо смены одежды; титры не на лице; нормальное разрешение; чистые до/после; честные подписи; без бренда Higgsfield.
- Оценка текущего v2: 2/10; цель ≥ 7–8/10 (слепая).
Предположение исполнителя (не требование): «на 100% лучше» = не менее чем вдвое сократить разрыв до эталона либо достичь абсолютного порога.

## 4. План исправления (по стоимости эффекта)
1. **Входы:** брать оригиналы (input_02 = ref-clip-02; для 03/04 исходники `ref-clip-*`, а не v1-выход). Содержимое: 01/04 ≈ x 322–958 из 1280; 02/03 наклонная панель, вписанный прямоугольник ≈ x 190–1085, y 15–1050 (оценка по кадру, автодетект не сработал: размытые поля дают градиенты).
2. **9:16 outpaint:** Wan2.1 VACE `outpainting` (up/down, expand_ratio ≈ 0.35–0.55); оригинал накладывается обратно (PSNR ≥ 38 дБ в исходной области); шов ≤ 6/255. Площадка: A100 80 ГБ SECURE (14B) или локально 1.3B (≈ 2 ч/ролик).
3. **Лицо:** FaceFusion quality (hyperswap_1a_256, pixel-boost 1024, xseg_1, gfpgan 25), поза-гейт, нарезка; Genjutsu replace / Wan2.2-Animate (A100) как полная замена персонажа.
4. **Мимика:** замер `mimics_gate` (≥ 0.99), затем `expression_restorer`/LivePortrait.
5. **Волосы/одежда/фон:** `HAIR_STENCIL_WORKFLOW`, VACE 14B с маской одежды, RVM/SAM2 + согласование света и контактная тень.
6. **Апскейл** Real-ESRGAN на мастере; титры в родных 1080×1920 вне лица (`title_guard`).
7. **Монтаж** по биту, 20–25 с, чистые сегменты и before/after.

## 5. Критерии приёмки (зафиксированы ДО прогона)
- Формат: 1080×1920, SAR 1, масштаб равномерный (|sx−sy|/s ≤ 0.5 %), длительность ±0.1 с, fps источника.
- Расширение: доля сгенерированных пикселей ≤ 45 %; исходная область = исходник (PSNR ≥ 38 дБ); шов ≤ 6/255; мерцание сгенерированной зоны ≤ 1.5× исходной.
- Резкость (дисперсия Лапласа лица) ≥ 1.5× v1.
- Лицо: arcface mean ≥ 0.70, min ≥ 0.59, потерянных кадров ≤ 2 %. Мимика ≥ 0.99.
- Волосы: GT IoU ≥ 0.90, F1@3px ≥ 0.80. Одежда ≤ 0.276. Фон 7/7.
- Звук: поток без перекодирования или |Δдлит.| ≤ 20 мс, |ΔLUFS| ≤ 0.5, пик ≤ −1 dBFS.
- Оценка по SCORECARD ≥ 8/10 и нет критического дефекта.
