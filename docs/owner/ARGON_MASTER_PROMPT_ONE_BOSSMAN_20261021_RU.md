### 4. Сборка единого Bossman — шаги
1. `git branch -r --no-merged origin/main` → таблица: каждая ветка — влить / закрыть / оставить, с причиной.
2. Влить ветки Claude из раздела 1 после их отчётов (SHA, тесты, merge-tree).
3. Все `a`-пункты (15 штук) → каждый отдельный коммит + тест, падающий без него; затем `b`, затем `c`.
4. Каждое вливание: целевые тесты + `tools/ci_secret_scan.py` + CI зелёный на SHA.
5. Выкатка только при пустой очереди генераций (или после B9-b), через лаунчер; `/health/live` = PASS и `source_identity` = SHA из `origin/main`
   у бэкенда, Джеффа, телефона, War Terminal.
6. **Приёмка «единый Bossman» (живой прогон владельца):**
   (1) очередь из 5 фото идёт, Джефф отвечает по методичке, ни разу не остановлен;
   (2) War Terminal находит тендеры по 12 ключевым словам через браузер;
   (3) STOP с телефона останавливает генерацию, Джеффа, агентов и сбор War Terminal;
   (4) перезапуск бэкенда посреди задачи → задача продолжается или просит подтверждение кнопкой;
   (5) CI зелёный на том же SHA, что запущен.
7. Отчёт в пульт по-русски: таблица 15 веток × a/b/c со статусами, SHA, что NOT_RUN и почему, и последняя строка — экономия против
   облачного эквивалента / фактические траты.

### 5. Жёсткие правила (не меняются)
- Никаких `--dangerously-skip-permissions` / `bypassPermissions`.
- Ключи, vault, DPAPI — никогда в git и никогда в сообщения; сканирование секретов перед каждым пушем.
- Пульт — только владельцу, ровно один получатель.
- Не определять место съёмки фото до координат; не делать откровенных правок реальных людей; лица — только с согласия.
