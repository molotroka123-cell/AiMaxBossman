# Общий пульт: локальный промпт, генерация и модели

Актуальный контракт 13.10.2026. Исходники сверены на `main b046b3b3`; это не подтверждение
идентичности работающего пульта. [Новый выбор моделей](../v2.2-20261013/GENERATION_MODEL_SELECTION_RU.md)
MC22-16 документирован отдельно и ещё требует реализации/сквозной приёмки.

## Существующие входы

| Действие | Команда/вход |
|---|---|
| Видео/оживление фото | `/vid идея`, `/vid 10 идея`, фото с `/vid идея` |
| Картинка | `/pic идея`; существующий выбор фото `/imgmodel` |
| Подготовка промпта | `/create image идея`, `/create video идея`; явный вход в локальную Qwen |
| Редактирование | Фото с `/edit изменение`; refs проверяются отдельно |
| Стиль | `/style текст`, `/style`, `/style сброс` |
| Постоянные референсы | `/refs`, `/refs on`, `/refs off`, `/refs clear` |
| Скорость | `/speed`, `/speed 20` |
| Управление | `/cancel`, `/stop`; существующая пауза/возобновление по общему scope |

На checkpoint разрешённые прямые owner сценарии автоматически ставят генерацию в
очередь; не описывать кнопку «Запустить» обязательным шагом каждого запроса. Ветки
уточнения/черновика и существующие кнопки остаются по текущему коду. Точный маршрут
и активную версию подтвердить через runtime; обычная подпись с refs может идти прямо
в edit, а не через Qwen. Новое требование — одинаковый выбор модели для всех входов.

## Роли моделей

Промпт дорабатывает настроенная локальная Qwen, визуальную работу делает Studio.
Фактические model ID/tag проверяются по runtime и каталогу; старое имя в README
не доказывает вызов. Сейчас фото имеет `/imgmodel`, refs edit связан с обычным
Qwen-Image-Edit-2509, video — с обычным Wan2.2 TI2V 5B. Общий селектор prompt/image/
edit/video и главный проверенный uncensored-профиль — контракт MC22-16.
Скачанные UC/heretic/A14B веса не объявляются подключёнными по одному имени.

## Очередь и скорость

Переиспользуются gen_refine/generate/animate и очередь Studio. Очередь новых заданий
GenRefine на checkpoint хранится в памяти: сохранённый черновик `queued` не доказывает
durable recovery после crash. Это разрыв для A22-05/MC22-01/16. Длинная работа не
должна блокировать STOP и обработку следующей control-команды. Не повторять доставку
при неизвестном результате и не запускать второй poller.

Существующий `gen-speed.jsonl`: refine_s, wait_s, queue_s, gen_s, total_s, model/preset/
размеры/frames/steps/seconds/ok/error. `gen_s` включает участок опроса и получения файла,
это не чистый inference; точность ограничена polling. Cold load и inference отдельно
публикуются только если действительно измерены. Новая модель должна попадать в snapshot
job и запись benchmark с revision/hash; сравнивать одинаковые параметры и cold/warm.

## Приёмка и правила

Owner Telegram → локальный ответ Qwen → выбранная модель → job → готовый нейтральный
файл → декодирование/hash → подтверждённая доставка. Отдельно STOP/отмена/restart и
смена модели во время очереди. Тесты fake API и наличие файла на диске не заменяют
этот roundtrip. Свежего полного PASS этот документ не утверждает.

Допустимая смена обычной одежды не должна отвергаться только по слову «переодеть».
Общие правила обработки изображений и owner permissions сохраняются. Приватные
фото/подписи не читать для диагностики маршрута и не отправлять облачным моделям.
