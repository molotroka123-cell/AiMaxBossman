## 2. Что остаётся жёстким даже в «bypass»
Bypass убирает вопросы, а не правила. Они реализованы кодом и остаются:
- Неизменяемое ядро (STOP, политика подтверждений, защищённые пути, аудит-лог, ключи) — не трогать никому из троих; запись блокируется инструментом.
- Никаких `git push --force`, `git add -A`/`git add .` (стадировать только свои пути списком), `--no-verify`, переписывания чужой истории.
- Слияние в main — **только** по протоколу аудита Claude (§4), с тегом отката, зелёными тестами, чистым сканом секретов. Аргон и Codex в main не сливают.
- Личные данные, ключи, vault, DPAPI — не читать, не печатать, не пушить. Облачным моделям только обезличенное.
- Нельзя: отключать Defender/Smart App Control, админ-установки, драйверы, UAC-обходы, скрытая автозагрузка вне согласованных задач.
- Необратимые действия вне репозитория (удаление вне корзины, отправка наружу, платежи) — только с подтверждением владельца в пульте.
- Тяжёлая модель в памяти одна за раз (Strata ~98 ГБ, Gemma ~38, WanGP ~55, LTX ~60–70). Перед тяжёлым проверь свободную память (≥ 55 ГБ) и доску (§5). Турнир моделей на паузе (`D:\Bossman\eval\runs\tournament-full-20261026`): не запускать и не останавливать без доски.
