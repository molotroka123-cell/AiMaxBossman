практике: Bossman умеет сам проверять ПК по чек-листу (`tools/security_audit.ps1`, только

исправления; системные изменения (firewall, службы, диски) делает владелец одним шагом с
UAC по подготовленному скрипту. Пароли, ключи и секреты аудит не читает и не печатает.

## Что уже защищает Bossman (по коду)

- Пульт отвечает только владельцу (`6273524c`); Claude/Codex/Remote Control — только с ID
  владельца, проверка на каждом вызове и перед доставкой; сырого shell из Telegram нет.
- Ключи: зашифрованное хранилище (`bcc.secrets.Vault`, DPAPI), конфиг отказывается
  загружать секреты открытым текстом; правило «vault never pushed».
- Новое: автологон через LSA-секрет, а не `DefaultPassword` в реестре (аудит это проверяет).
- Личные медиа не покидают ПК (правило 11.10), облачные агенты получают только обезличенный
  текст.
