# Bosman Terminal: закупочная и конфликтная разведка (старт 17.10.2026)

Основа: дайджест подкаста «как стать торговцем оружием через госзакупки» (`podcast-studio/digest/digest_ru.md`):
госзакупки публичны (SAM.gov, около 30 000 контрактов в день), новичок может подаваться на торги до 250 000 USD,
маржа 5–20 %, оплата через ~30 дней, поэтому нужен оборотный капитал или факторинг. Из этого же дайджеста: гость
осуждён за мошенничество (подмена происхождения товара) — это границы, которых терминал не пересекает.

## Что строим

Терминал на ядре Боссмана, который: (1) находит открытые тендеры и оценивает, какие мы реально можем выполнить;
(2) показывает, кто выигрывает контракты и на какие суммы (карта поставщиков и конкурентов); (3) следит за
конфликтами и новостями, влияющими на спрос; (4) ищет новых поставщиков и проверяет их по санкционным спискам.

## Что уже работает (проверено 17.10, `bossman_shared/procurement_intel.py`)

- TED (ЕС) — тендеры, без ключа. Реальный прогон по CPV 353 (оружие, боеприпасы) за 60 дней нашёл тендеры Литвы,
  Испании, Португалии, Франции, Германии, Финляндии; сумма и срок есть не у всех.
- USAspending (США) — награждённые контракты, без ключа (через curl: у Python на этой машине нет корня сертификата).
  Показывает победителей, например THE KINETIC GROUP SALES LLC по боеприпасам DHS на ~1,1–1,3 млн USD.
- Скоринг «реализуемо» (0–100): лимит суммы (по умолчанию 250 000), срок подачи, CPV в зоне интереса; награждённые
  контракты получают 0 и флаг `intel_only` (подать нельзя, нужны для разведки). 6 тестов passed.
- Флаг `licence_check` для военных CPV 353–357 и слов «ammunition/weapon…»: экспорт и посредничество требуют разрешений.

## Источники

| Источник | Что даёт | Доступ (проверено) |
|----------|----------|--------------------|
| TED API | тендеры ЕС | без ключа, 200 |
| USAspending | контракты США, победители | без ключа, 200 (curl) |
| UN Comtrade (preview) | потоки торговли по HS 93 и др. | без ключа, 200 |
| GDELT DOC | новости и конфликты, весь мир | без ключа, 200 (медленно, ~13 с) |
| SAM.gov | открытые возможности США | нужен бесплатный ключ (запрос с DEMO_KEY вернул 404) |
| UCDP | события конфликтов | нужен бесплатный токен (401) |
| OpenSanctions | проверка поставщиков по санкциям | нужен ключ (401) |
| ACLED | события конфликтов | нужен ключ (не проверялся) |

## Правила

- Только публичные данные и законные сделки. Лицензии, подлинные сертификаты конечного пользователя и проверка
  контрагентов по санкциям — до любого предложения. Терминал показывает флаги, решение принимает человек.
- Ключи только в хранилище, не в git. Никаких платных сервисов без решения владельца.
