## Пороги гейтов анимации (зафиксированы 10.10 ДО прогона инструмента `tools/video_gate/animation_gate.py`)

Сравниваются декодированные кадры исходника (как его видит Bossman: после CFR-нормализации) и результата, каждый кадр, без выборки.
Маска M = объединение рамок лиц исходника, расширенных на 0.6 стороны (Gate 1: 0 из 90 кадров меняли пиксель вне неё).
В Gate 0 маски нет: эффекты не применяются, меняться не должно ничего.

| Порог | Как меряется | Gate 0 (без эффектов) | Gate 1 (face swap) |
|---|---|---|---|
| T1 кадры | число кадров, FPS (±0.01), длительность (±1 кадр); выравнивание: для кадра i результата ближайший по MSE (вне M) кадр исходника из i−2..i+2 должен быть i | 100% кадров | 100% кадров |
| T2 пиксели вне M | lossless-промежуточный файл: max\|Δ\| по всем кадрам; итоговый H.264: min по кадрам PSNR вне M | max\|Δ\| = 0; PSNR ≥ 40 дБ | max\|Δ\| = 0; PSNR ≥ 40 дБ |
| T3 мимика | 68 точек лица (2dfan4), средний сдвиг / межзрачковое расстояние | ≤ 0.02 | ≤ 0.05 |
| T4 тело | 33 точки MediaPipe Pose (visibility ≥ 0.5), средний сдвиг / длина торса (плечи→бёдра; если бёдер нет — ширина плеч) | ≤ 0.02 | ≤ 0.02 |
| T5 optical flow | Farneback на ½ разрешения, средняя ошибка конечной точки между потоками t→t+1 исходника и результата, вне M | ≤ 0.25 px | ≤ 0.25 px |
| T6 дрожание | RMS второй разности по времени от (точки лица результата − исходника) / межзрачковое | ≤ 0.01 | ≤ 0.02 |
| T7 личность (только Gate 1) | arcface к фото: среднее, разброс; исходное лицо к фото | — | ≥ 0.75; ≤ 0.06; ≤ 0.30 |

## Stage 4 — background swap: пороги (зафиксированы 10.10 ДО первого прогона, metric_version s4-v1)

Подготовка этапа 4 (по порядку владельца он идёт после этапов 2 и 3). Конвейер: RobustVideoMatting (ONNX, рекуррентное
состояние между кадрами) даёт альфу человека и волос и оценку переднего плана F; SAM2.1-tiny (ONNX, по рамке YOLOX) —
опционально выбирает субъекта. Композит в родном разрешении: C = S там, где α ≥ 0.98 (пиксели исходника без изменений),
иначе C = α·F + (1−α)·B (F очищен от цвета старого фона), B — новый фон. Мастер RGB-lossless + выдача H.264 со звуком
исходника. Ничего не уходит в облако.

Пробный клип (выбран заранее): `video-testset-private/ref-clip-01.mp4`, кадры 0–89 (1280×720, 30 к/с) — приватно, локально.
Новый фон: процедурный нейтральный «студийный» градиент (генерируется кодом, без картинок из сети).
Обозначения: S — кадр исходника, C — композит, α — альфа инструмента (8 бит, та же, что использована в композите),
H — высота кадра; полосы и кольца задаются долей H (в скобках — пиксели при H = 720). ΔE — CIE76 в Lab.
P — независимая маска людей гейта: YOLOX (score ≥ 0.5) → SAM2.1-tiny по рамке, в каждом кадре исходника; субъект —
самый большой человек кадра (как v2 в Gate 0/1).

| Порог | Как меряется | PASS |
|---|---|---|
| S4-T1 кадры | число кадров, FPS (±0.01), длительность (±1 кадр); выравнивание как Gate 0 v2 (близнецы телесинхронизации — ничья), MSE считается только внутри ядра K | 100% |
| S4-T2 пиксели человека | ядро K_t = эрозия(α_t ≥ 0.98) на 0.005·H (4 px); мастер без потерь: max\|C − S\| по K всех кадров; выдача H.264: min по кадрам PSNR внутри K | max\|Δ\| = 0; PSNR ≥ 40 дБ |
| S4-T3 стабильность альфы | ошибка деформации (warping error, Lai et al. 2018): α_{t−1} переносится в кадр t обратным потоком Farneback исходника (½ разрешения, масштаб ×2), пиксели с рассогласованием прямого/обратного потока > 1 px исключены; E_t = среднее \|α_t − warp(α_{t−1})\| в полосе \|расстояние до контура α_t = 0.5\| ≤ 0.01·H (7 px) | среднее E ≤ 0.08 и 95-й перцентиль E_t ≤ 0.15 |
| S4-T4 ореол | кольцо снаружи контура α ≥ 0.5 на расстоянии 0.004·H … 0.011·H (3…8 px); средний ΔE(C, B) по кольцу, среднее по кадрам | ≤ 8.0 |
| S4-T5 следы старого фона | зона = дилатация(P, 0.06·H) минус дилатация(P, 0.015·H) (11…43 px от людей по независимой маске); доля пикселей зоны с ΔE(C, B) > 10, среднее по кадрам | ≤ 0.01 |
| S4-T6 тело | MediaPipe Pose точки 11–32 (visibility ≥ 0.5), средний сдвиг / торс, исходник против композита | ≤ 0.02 |
| S4-T7 дыры | внутри эрозии маски субъекта (P) на 0.015·H: доля пикселей с α < 0.5, среднее по кадрам | ≤ 0.005 |

Обоснование значений (до прогона):
- T2 — композит по построению берёт пиксель исходника в ядре; порог 0 проверяет, что ни выравнивание, ни кодирование,
  ни 8-битная альфа не испортили человека. PSNR ≥ 40 дБ для выдачи — как в Gate 0.
- T3 — полоса шириной ≈ 14 px; сдвиг всего контура на 1 px, не объяснённый движением исходника, даёт ≈ 1/14 ≈ 0.07;
  видимое «кипение» края (≥ 2 px) — ≥ 0.14. 0.08 = не больше ~1 px необъяснённого сдвига с запасом на ошибку потока;
  перцентиль 0.15 ловит одиночные «скачки» маски. Для сравнения в отчёт пишется та же ошибка для покадровой маски SAM2
  гейта (без памяти) — только справочно, на вердикт не влияет.
- T4 — ΔE ≈ 2.3 — порог различимости; равномерный ореол вдоль всего контура (ΔE ≥ 10) должен проваливаться. Настоящие
  пряди волос в кольце поднимают среднее, поэтому порог 8, а не 2.3. Ожидаемый риск: распущенные волосы.
- T5 — граница SAM2-tiny ошибается примерно на 1% высоты кадра (отсюда внутренний отступ 0.015·H); в зоне за ним должен
  быть новый фон. 1% зоны допускает отдельные пряди/точки; ореол вдоль контура или кусок старого фона заметно больше.
- T6 — как Gate 0/1 (пиксели тела не меняются, меняется только фон).
- T7 — внутри эрозии маски на 11 px человек есть наверняка; α < 0.5 там — дыра, сквозь которую виден новый фон.
  0.5% допускает мелочь у пальцев и щелей рука-тело, которые SAM2 закрашивает.
- Известное ограничение, без порога: отброшенные человеком тени на старом фоне (пол, стена) matting не переносит —
  в отчёт идёт как наблюдение; освещение самого человека сохраняет T2.
- Устойчивость к типам движения: метрики T3/T4 дополнительно разбиваются по терцилям величины потока исходника внутри
  человека (справочно). Контрольные кадры для контакт-листа: 0, 13, 25, 38, 51, 64, 76, 89.

Артефакты: report.json (команда, версии, устройство, sha256 входов/выходов, метрики по кадрам), side-by-side
(исходник | композит | альфа | \|Δ\| в ядре), контакт-лист контрольных кадров — в `Videos/Bossman-Genjutsu/stage4-20261010/`.
