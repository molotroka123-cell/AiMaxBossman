## 2. Слабые места (замер + внешнее ревью промо v1)
1. Идентичность плавает между кадрами, особенно при открытом рте и поворотах (минимум 0.07–0.27).
2. Лицо мягкое («пластик») в крупных планах (резкость 66–83 в 01/04b).
3. Цвет волос — плоская маска: нет прядей и света; белый выглядит шапочкой.
4. Руки перед лицом: слияние, потеря пальцев.
5. Одежда: силуэт и границы смазаны, мерцание (Stage 2 не пройден полностью).
6. Фон: вырезка заметна, свет на лице не совпадает с неоном (нет отражённых цветов и контактных теней).
7. Титры и переходы закрывают результат.

## 3. Какие фото нужны (генерируются локально: SDXL сцена → FaceFusion с её лицом → отбор по похожести ≥ 0.70)
`C:\Users\asd\Bossman\lora-datasets-20261010\gf-synth\make_synth.py` (14 сцен): рука у рта/глаза, смех с открытым ртом,
профиль, поворот через плечо, волосы на ветру (пряди), неоновая подсветка, вид сзади с пучком, униформа с поднятыми руками и
сбоку, очки, волосы синие/зелёные/белые с бликами. Идёт после освобождения GPU (ждёт, пока sd-cli занят).
