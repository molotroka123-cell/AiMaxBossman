## Где может лагать UX (мнение аудитора, проверить на ПК)

- **Vision на одном APU**: ~27 с на кадр (#25: 784 с на 27 кадров) — пока идёт vision, Jeff на той же iGPU отвечает медленнее;
  тяжёлые модели запускать по очереди.
- **Локальные «думающие» модели**: Winnow-12B тратил весь бюджет токенов на рассуждение (пустой ответ при 200 токенах,
  16–49 с) — задержка ответа Jeff/воркеров.
- **Очередь картинок/медиа — один воркер**: долгая работа держит соседние, пока её не отменят (отмена освобождает за ≤0,5 с — проверено сценарием OS-60).
- **Командная строка** теперь получает весь каталог (644 возможности) — первый показ подсказок тяжелее, зато ничего не пропадает.
- **Direct Generation**: окно опрашивает статус задачи; живой ComfyUI и кнопка «Создать» в реальном браузере на ПК не проверены (только фейковый ComfyUI).

| Где | Что может тормозить | Насколько вероятно на ПК |

| Браузер (`ui/pages/browser.js`) | скриншот раз в 3 с без защиты от наложения: на зависшей странице запросы копятся | на тяжёлых сайтах |

| Приложения (`features/apps.py`) | зависшее приложение держит список приложений ~2,4 с (health и metrics по очереди) | если одно приложение «висит» |
| Память (`tools_memory.py`) | «Переиндексировать» ждёт полный реиндекс внутри запроса, без прогресса | на большом vault — минуты спиннера |

| Облачные/локальные чаты через плагин | до 90 с тишины без стриминга | при медленной модели |
