1. Генерации владельца — главный приоритет по CPU, памяти, диску и GPU; всё остальное уступает.
2. В `main` продукт вливается только кнопкой владельца (AGENTS.md). Сегодняшние пуши в `main` сделаны по его прямым указаниям.
3. Платное только в рамках суточных лимитов `autonomy/long_run.json`: DeepSeek 2, GLM 2, Haiku 2, Mistral 0 ($). Experiential Labs `gemini-4-argon` платный (счёт 1 $), без лимита автономно не используется.
4. Ключи только в хранилище Bossman; в git, логи, пульт и отчёты не попадают. Ключи String и Experiential Labs были присланы в чат: **перевыпустить и заменить в хранилище**.
5. Безопасность контента: встроенные фильтры инструментов (в т.ч. FaceFusion) не отключаются; без явного согласия и проверки лица реальных людей в откровенное видео не подставляются.
6. Папка «Гречка» открывается только по прямой просьбе владельца, содержимое не просматривается (`grechka-send-pult.ps1`).
7. Личные фото и видео не покидают ПК.
