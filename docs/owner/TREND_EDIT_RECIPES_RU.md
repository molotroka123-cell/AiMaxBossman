# Трендовые приёмы монтажа: что нашли, как рендерим, чего не смогли (10.10.2026)

Инструменты: `tools/trend_edit/` — `beat_grid.py` (сетка битов, привязка резов), `fx.py` (приёмы), `edit_core.py`
(клипы, маски, перекраска Lab, запись, текст), `build_promo.py` (ролик 1), `build_trends.py` (ролики 2–5),
`parse_masks.py` (маски волос/одежды по кадрам). Тесты: `tests/test_trend_edit.py` (чистые части: сетка, привязка,
тайминг рамп, пунш, вайпы, экранирование текста). Всё локально: ffmpeg + numpy + OpenCV; облако и платные API не
использовались; фото/видео девушки никуда не уходят.

## 1. Откуда «тренды»

TikTok и Instagram недоступны (скрейпинг и логин запрещены и невозможны), поэтому тренды взяты из публичных статей
(WebSearch/WebFetch 10.10.2026). Это описание *приёмов*, а не статистика просмотров: какой приём «выстрелит», здесь
не измерено (`analyze_edit.py` описывает структуру, а не предсказывает просмотры).

| Приём | Что сказано | Источник |
|---|---|---|
| Velocity / speed ramp | замедление и резкое ускорение, «драматично, на бит»; в 2026 остаётся одним из главных трендовых переходов CapCut | https://www.capcut.com/help/capcut-transitions |
| Beat-sync резы | монтаж «на бит», популярен в монтажах и танцах; в 2026 в CapCut есть авто-синхронизация | там же; https://spliceapp.com/blog/what-editors-include-trending-effects-for-instagram (поиск) |
| Glitch / RGB split / flicker | «digital distortion, RGB split, flicker» для энергичных роликов | https://www.capcut.com/help/capcut-transitions |
| Zoom / cinematic fade | «smooth zoom-ins, fade blends, film-style cuts» | https://www.capcut.com/help/capcut-transitions |
| Before/After, трансформация | быстрые резы с маской или motion blur для смены одежды/сцены; hair/outfit transition шаблоны | https://www.capcut.com/help/capcut-transitions ; https://www.capcut.com/explore/transition-hair-video-before-after ; https://www.capcut.com/explore/transition-video-change-outfit |
| Outfit change «jump/snap/hair flip» | смена одежды на прыжке, щелчке пальцев, взмахе волос | https://flexclip.com/learn/dress-change-video.html (результат поиска) |
| Kinetic typography | текст «выскакивает» в такт голосу/биту; в 2026 тренд на осмысленное, а не хаотичное движение | https://www.jumbla.com/news/kinetic-typography-make-your-brand-message-unforgettable ; https://thesocialcat.com/glossary/kinetic-typography (поиск) |

Не прочитано (страницы вернули 403/404): wayin.ai (TikTok transitions), spliceapp (статья о трендовых эффектах);
по ним использованы только заголовки из поисковой выдачи. Страница CapCut «velocity edit how to» не даёт точек
кривой скорости, поэтому параметры кривой ниже — наши, подобраны на слух/глаз, а не «стандарт».

## 2. Как каждый приём рендерится у нас

| Приём | Реализация | Параметры |
|---|---|---|
| Сетка битов | `beat_grid.detect_beats`: librosa `beat_track` даёт ориентир темпа, точная сетка (период, фаза) подбирается гребёнкой по огибающей onset-силы (`comb_fit`, ±4 %) — трекер сам даёт «гуляющие» биты | трек: 130.5 BPM, период 0.4598 с, дроп на бите 20 (≈9.3 с) |
| Рез строго на бит | все границы секций — начала тактов сетки; `snap_cuts`, `section_edges`; пик энергии (`find_drop`) | рез каждый бит, затем каждые пол-бита |
| Zoom punch-in | `fx.punch_scale` + `zoom_punch`: масштаб 1+пик в момент реза, спад экспонентой (0.16 с); центр — центроид маски волос (голова) | пик 0.045–0.145 |
| Jump-cut punch | масштаб меняется скачком на бите: 1.0, 1.38, 1.0, 1.62, 1.18, 1.45, 1.0, 1.28 | trend A |
| Speed ramp / velocity | `fx.ramp_source_time` (точный интеграл кусочно-линейной скорости), `velocity_knots_balanced`: замедление до 0.4x перед битом, ускорение на бите, возврат в 1x; сбалансирована, чтобы картинка не уходила от музыки | lead 0.30 с, hold 0.10, tail 0.30 |
| RGB split | `fx.rgb_split`: красный и синий каналы сдвигаются в разные стороны, затухание 0.07 с | до 26 px (на 1488) |
| Flash frame | `fx.flash`: смесь с белым, затухание 0.045 с; на дропе 0.8 | 0.5 / 0.8 |
| Mask / wipe | `fx.wipe_mask`: h, v, diag, circle с мягким краем; reveal фона — круг из центра головы | 0.2–0.25 с |
| Before/After | `fx.split_before_after`: вертикальный разделитель едет слева направо | outfit |
| Whip pan | `fx.whip_blur`: горизонтальное размытие на ±0.14 с вокруг бита | 0.12 |
| Перекраска волос / одежды | `edit_core.recolor` — порт `recolor()` из `genjutsu_core.js` (Lab: сдвиг L к целевому, a/b к цвету, текстура остаётся), маски SegFormer-B2 (`parse_masks.py`, мягкие, EMA по времени) | пресеты конструктора: blue #1f5fd1, green #1f9d55, white #f2f0ea, black #0d0d10, uniform, denim, emerald |
| Смена фона | RVM (`tools/genjutsu/background_swap.py`) + плейт SDXL «ночной неон» | см. ниже |
| Кинетическая типографика | `ffmpeg drawtext`, шрифт `C:/Windows/Fonts/arialbd.ttf`; вылет: размер 60→100 % и подъём за 0.18 с, затухание 0.12 с; всё — выражения от `t` в одном проходе | двоеточия, запятые, `%` экранируются (`fx.escape_drawtext`) |
| Кадрирование | исходная рамка не растягивается: `fx.blur_fill` заливает свободное место размытой копией кадра (как в самом референсе) | 4:3 1488x1128 |
| 9:16 с лицом по центру | окно 634x1128, центр — сглаженный центроид волос (медиана 11 кадров + EMA), масштаб до 720x1280 | trend B |

## 3. Что реально, а что пробное

* Лицо девушки: FaceFusion, прогнано раньше (ref-promo-08); здесь только монтаж.
* Волосы и одежда: перекраска цвета по маскам (не генеративная замена). Белые/платиновые волосы выглядят плоскими:
  у чёрных волос в исходнике нет цветовой информации, Lab-сдвиг даёт серо-белую текстуру, а не блики.
* Одежда «рубашка + галстук + жилет» (ролик 1, 8–12 с): результат Wan2.1 VACE Stage 2, **пробный**, гейт Stage 2 не
  пройден полностью; клип 81 кадр / 1.35 с (60 к/с), замедлен 0.5x и показан в обе стороны.
* Фон: RVM-матирование + SDXL-плейт; в ролике 1 исходник (14.7 с) проигрывается заново с начала, чтобы покрыть
  секцию 13–28 с.
* Музыка: дорожка самого референса (`ref-clip-01.mp4`), только для личного использования владельца; права на
  трек не проверялись, публиковать нельзя без лицензии. Интро (20 битов) играет один раз, дальше петля 8 битов
  «дропа» по сетке; шов на бите, края 6 мс.

## 4. Чего не смогли

* Не смотрели и не измеряли реальные тренды TikTok/Instagram (нет доступа); «топ трека под тренд» — по описаниям
  приёмов, а не по метрикам.
* Нет предсказателя просмотров; нет A/B.
* Анимация «смена одежды на щелчок» (hand snap) требует модели движения; здесь это перекраска/сплит/вайп.
* LoRA девушки (RunPod) в роликах не использованы: ролики собраны из уже готовых результатов FaceFusion.
* Тяжёлая перекраска белого цвета на волосах с высокой частотой (пряди на фоне) даёт ореол по краю маски.
