# Epoch 7 Charter — Adaptive Reality OS

## Mission

Transform Bossman from a fast orchestrator into an adaptive decision system that maintains a typed model of reality, compiles goals into formal missions, compares strategies, executes through the cheapest capable path, proves post-state, and learns only through governed promotion.

## Non-negotiable invariants

- no stale fact may silently cross a freshness boundary
- no strategy score may override authorization or approval
- no model may manufacture evidence for an external effect
- unknown state is represented as unknown, never as a convenient default
- every effectful mission has explicit proof obligations
- every promoted skill has rollback and negative controls
- local resource routing must use measured memory state
- owner-visible work outranks optional background work

## Success definition

V7 succeeds when Bossman can receive an ordinary owner goal and autonomously:

1. compile it into Mission IR;
2. assemble current world state with freshness/provenance;
3. generate at least two viable strategies when alternatives exist;
4. estimate utility using measured cost/latency/risk/resource data;
5. choose a safe strategy;
6. execute through existing V4-V6 safety boundaries;
7. verify the actual post-state;
8. recover by changing strategy when the first path fails;
9. preserve a replayable trace;
10. propose reusable skill promotion only after evidence gates pass.

## Explicitly out of scope for first V7 implementation

- unrestricted self-modifying code
- autonomous policy changes
- autonomous credential creation or permission escalation
- removing owner approvals to improve benchmark latency
- training foundational models from scratch
- broad redesign work without functional evidence
