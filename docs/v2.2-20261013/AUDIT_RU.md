# Аудит дерева и исходного состояния

## Метод и границы

Работали три независимых аудитора: автономия/ядро, медиа/коммерческие пути,
Poker/Trading/Reports. Интегратор сверил дерево, manifest, исходные регистрации,
публичный сайт, Git refs, CI, установленную сборку и доступы провайдеров.

Первый срез был `921b8b09`; после двух текущих merge выполнена повторная статическая
инвентаризация на `ea7c9a3d9a46d8339a8917b6f4163cba0d9fb27c` в 2026-10-13T12:04:24.366853+00:00. Рабочая папка содержит чужие изменения;
они сохранены и не включены в документацию как принятый код. Полный динамический
прогон всех функций, моделей и GUI не выполнялся. Поэтому отсутствие свежего receipt
помечается NOT_RUN/UNKNOWN, а не выдуманным PASS или FAIL.

## Что теряется в карте

- Все 57 записей leaf-manifest указывают на существующие исходники и файлы тестов.
  Факт существования теста не означает, что он запущен на этой версии.
- 579 ссылок seed ведут в отсутствующие пути; уникальных путей 570.
  Из них 534 документа; 0 найдены в tag `docs-archive-20261013`.
  Архивный документ не восстановлен автоматически как действующая инструкция.
- Оставшиеся пути включают отсутствующие модули cognitive/reality/apprentice,
  feature-файлы и названия CI, ошибочно записанные как файлы. Полный перечень находится
  в [missing-source-paths.csv](inventory/missing-source-paths.csv).
- Точной ссылки из seed не имеют features: capability_tree, direct_gen, forecast, gmail_connect, model_freshness, motion_workflow_api, vibe. Это отсутствие
  точной привязки файла; концептуальная ссылка через группу могла существовать.
- Семь модулей без Feature: bossnet_nodes_v16, context_budget_v16, knowledge_fabric_v16, memory_retrieval_v16, model_foundry_v16, provider_fleet_v16, simulation_world_v16. Это библиотеки, отсутствие router
  само по себе не ошибка. Динамические ToolSpec и маршруты вне features в статический
  счётчик не входят.
- 1181 из 1745 выбранных исходных файлов не имеют точной ссылки из seed. Их нельзя
  приравнивать к потерянным функциям. Нужна смысловая связь capability → entrypoint →
  source → test → receipt; весь список сохранён в source-crosswalk.csv.

## Существенные разрывы продукта

1. **Автономия.** Документ 2.1 — DESIGN / NOT YET PROVEN LIVE. Исторический строгий
   single cycle PARTIAL, три цикла 1/3, transfer NOT_RUN; 24/48h/week не приняты.
2. **Пульт.** Новый GenRefine есть в коде: /vid, /pic, /style, /speed, правки черновика,
   локальная Qwen, кнопка запуска и FIFO. Очередь в памяти теряется после crash.
   Обычная подпись при активных refs идёт в edit_from_references, обходя этот Qwen-вход.
   Метаданные в 12:04 UTC показывали processing в chat-линии и два pending; control
   проходил. Текст и фото не читались. Это head-of-line ожидание, причина занятого
   обработчика пока неизвестна; неизвестный процесс не завершали и второй poller не запускали.
3. **Скорость медиа.** Поздний локальный bench_results сообщил image completed:
   gen_s=667.3, total_s=787.1; Wan TI2V cancelled: total_s=701.2. Изображение не
   открывалось и качество не оценивалось. gen_s включает ожидание опроса и обработку/
   получение файла, поэтому не является чистым inference. Успешный benchmark не
   доказывает передачу последнего сообщения владельца или uncensored backend.
4. **Genjutsu/Motion.** Ref conditioning не LoRA. Genjutsu training backend выключен.
   Whole-clip transformations не доказаны; часть Motion операций явно not_executed.
   SegFormer имеет ограничение NON-COMMERCIAL. Новые video weights скачаны, но не
   подключены и не прошли настоящий inference. Обычные Qwen Image Edit и Wan 5B
   нельзя переименовывать в uncensored по названию текстовой Qwen.
5. **Music.** Есть исторические реальные короткие треки ACE-Step; ещё нужны длинный
   сценарий, три варианта, оценка владельца, голосовая конверсия и доказанный training.
6. **Jeff/Stars/Calls.** Платёжный код, лимиты, изоляция и возвраты имеют simulation-
   доказательства; официальный тест/публичная оплата не предъявлены. BM25 цитаты не
   гарантируют поддержку каждого утверждения. Loopback selftest не реальный звонок.
7. **Social Farm.** 13 HTTP-операций возвращают 501; покрытие domain-кода тестами не
   делает эту поверхность завершённым коммерческим workflow.
8. **Poker.** Запись, OCR-кандидаты, калибровка, independently labelled accuracy,
   LoRA и GTO-анализ — разные стадии. Нужен holdout по отдельной записи/сессии.
9. **Trading/Pump.fun.** Paper gates сохраняются. Отдельный token helper содержит
   live-capable путь; его нельзя считать безопасным только по quarantine manifest.
10. **TimesFM.** Delta добавила локальный opt-in процесс и реальные смешанные backtest
   результаты. Выбраны Apache-2.0 weights 2.5; noncommercial 3.0 weights исключены.
   Наличие прогноза не устанавливает торговую ценность или заработок.
11. **Комплектность релиза.** Committed AGENTS отстаёт от dirty рабочего AGENTS.
    Нельзя коммитить чужую правку целиком; интегратор должен сверить и принять её
    отдельно. Требуются точный accepted source, лицензии, archive verifier, чистая
    установка/миграция/откат и актуальные реальные сценарии.
