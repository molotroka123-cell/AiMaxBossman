# Рабочий промпт: Bossman 2.2 без повторной консолидации

Перед этим промптом прочитай UPDATE_20261013_1350_RU.md: появился Qwen L1 Lab,
пульт уже автоматически ставит разрешённые генерации в очередь, v2 gate добавлен
в код, но его действительность зависит от принятой и закреплённой конституции.
Не добавляй лишний шаг подтверждения в генерацию; существующие owner permissions
для внешних эффектов сохраняются. Старое описание кнопки запуска — baseline ea7.

Продолжай существующий Bossman. Сначала прочитай применимый AGENTS.md, затем
docs/v2.2-20261013/README.md, AUDIT_RU.md, REQUIREMENTS_RU.md и ACCEPTANCE_RUNBOOK_RU.md.
Пакет основан на ea7c9a3d; проверь текущие local/remote refs и дельту. Эта версия
спецификации не объявляет готовность 2.1/2.2. Не начинай проект и слияние заново.

Работай в существующем согласованном checkout и общей ветке, сохраняй чужой dirty
diff. Один интегратор меняет общие файлы; до трёх аудиторов независимо читают код/
результаты. Не создавай новые ядра, модельные реестры, память и очереди вместо existing.
Приватный отчёт ключей лежит локально вне Git: проверь актуальность metadata перед
выбором провайдера; не выводи и не публикуй credentials/балансы.

Первый приоритет: MC22-01..04 и A22-02/05 — один owner Telegram сценарий. Установи
identity единственного poller/backend. Проследи последний owner update по ID/типу/
времени без чтения фото и промпта для диагностики. Занятая chat-линия не доказательство
фильтра. Обычная caption с refs сейчас может идти в edit, минуя Qwen GenRefine.
Устрани маршрутизацию и блокировку длинным job, сохрани idempotency, approval, STOP
и приватность. Не запускай второго poller; неизвестную операцию не повторяй вслепую.
Реализуй durable queue/recovery в существующем storage, если этот путь их не имеет.

Докажи один synthetic фото→локальная Qwen→черновик→подтверждение→job→файл→доставка,
а затем отмену и restart без дубля. Запиши точную модель, веса/revision, cold/warm,
queue/generation/postprocess/delivery time. gen_s существующего кода содержит download/
polling: не называй его чистым inference. Четыре refs — conditioning, не LoRA;
обычный Qwen Image Edit/Wan 5B не выдавай за другой backend. Неподключённые веса явно
NOT_RUN. Личные материалы не отправляй в облако, guards/owner permissions не обходи.

После законченной вертикали выбирай следующий доступный requirement по риску и
пользе: готовый Reports/Operations/Jeff pilot, затем реальные Windows/STOP/restart,
медиа/музыка/Apps, независимое обучение/transfer. Следуй зависимостям в трёх specs.
Paper Trading/Pump.fun сохраняй; TimesFM не объявляй торговой прибылью. Для Poker
разделяй запись, разметку, калибровку, holdout, LoRA и solver. Собственный sandbox
для coaching проверяй отдельно от правил сторонних площадок.

Экономь лимиты: короткая разведка локальными инструментами, reuse существующих
receipts и targeted tests; облачные read-only задачи только в разрешённом бюджете.
Самостоятельный fix/lesson/transfer доказывай через Bossman worker, без скрытых
teacher patches. Не снижать gate и размер корпуса после результата. Непройденное
сохраняй NOT_RUN/BLOCKED/OWNER_REQUIRED и переходи к независимой доступной работе.

Каждый ID свяжи с capability ID, source, entrypoint, test и evidence на exact SHA.
Исправляй stale/orphan связи через существующие tree tools, не рисуй зелёные листья.
Один узкий commit за проверенную вертикаль, stage только собственные paths, обычный
fast-forward push в согласованную общую ветку. При неожиданном изменении remote
сохрани работу и согласуй дельту; без reset/force/global add. AGENTS dirty правку
другого исполнителя не присваивать. Отменённые часовые аудиты не возобновлять.

Freeze: все обязательные gates выбранного владельцем объёма на одном source SHA;
идентифицированная installed сборка, проверенный архив/hash/manifest, реальные
применимые GUI/model/payment checks, clean install/migration/rollback, AGPL и
third-party licenses. Опциональное откладывать только явно; deadline/CI/docs не
сертификат. В конце дай владельцу факты: что стало возможно, реальные artifact/hash/
время/стоимость, что блокирует, один следующий шаг. Не обещай завершение без доказательств.
