# Интерфейс 2.6.1 — понятный запуск и обратная связь

Дата: 2026-09-05. Это версия интерфейса Command Center поверх существующего
семейства V2.6. Версия Python-пакета остаётся 0.1.0; метка не означает
аттестацию всех возможностей ядра, автономного режима или финансовых операций.

- В операторском канале исполнитель выбирается явно; рядом видно имя модели.
  Без выбора команда сохраняется черновиком. Выбранный agent_id попадает в задачу.
- Блокировка показывает причину, а не сообщение об успешном запуске.
  В задачах появился фильтр «Заблокированы».
- Долгие действия помечаются aria-busy и защищены от повторного нажатия.
- Детектор кликов учитывает текст, скрытие панели, состояние кнопки и перевод
  фокуса. Значения полей ввода в телеметрию не записываются.
- Из пульта можно открыть карточку конкретной задачи. Блокировка не всегда
  означает запрос одобрения: её причина показана отдельно.
- Пульт различает полученный нулевой расход и отсутствующее значение.
  Если сервер уже заменил отсутствие данных нулём, интерфейс восстановить это
  различие не может; полнота серверной телеметрии проверяется отдельно.

Проверки: живой локальный сервер и Windows Chromium — mission_console,
testing_period и owner_control_ui; анализ экспортированного журнала — отдельные
детерминированные тесты. Прогоны моделей/платежей для обновления не нужны.

Исторический журнал не переписывается: ошибки и неизвестные результаты сохранены
в `docs/testing/*_a14515d.*` с указанием границ корреляции.

Фактический результат проверки этой правки: 9 passed, 30 deselected, Windows
Chromium, Python 3.12. В выборку входят переход пульт → GET карточки задачи,
явный выбор исполнителя → сохранённая задача, одиночный запуск занятой кнопки
и восстановление после обработанного отказа, проверка ложных/настоящих dead-click.
Это целевой регрессионный прогон; итоговая проверка общего интеграционного SHA
выполняется ведущим интегратором отдельно.
# Integration acceptance

Lead reran the combined UI, executor-admission and Windows verification selection:
54 passed, 1 skipped (96.52 seconds); the skip is not acceptance evidence.
Additional owner-state regressions and real Chromium: 12 passed (15.83 seconds).
The owner view now filters effects/finalizer events to the current run, shows
UNVERIFIED when completed lacks proof, preserves unknown cost, and displays the
executor-admission blocked reason. These are product-state corrections, not a new
execution authority.
