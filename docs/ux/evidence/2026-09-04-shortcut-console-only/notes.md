## Вывод

«Только командная строка» = на порту сидел чужой headless-сервер (остаток моего
убитного вызова), а видимая консоль — либо его невидимое окно, либо повторный
даблклик, упёршийся в занятый порт. Окно Chrome при этом либо не запускалось
(single-instance guard / занятый профиль), либо его процесс умирал вместе с
закрытием консоли. После зачистки порт свободен — следующий даблклик пойдёт по
чистому пути «поднять сервер → открыть окно».

## Что смотреть владельцу при повторе

1. `command-center\data\desktop-run.log` — должна появиться пара
   `start ...` / `browser-exit code=... lifetime=...`.
2. Есть только `start` без `browser-exit` — процесс убит снаружи (закрыта консоль).
3. `browser-exit ... lifetime<10s` — Chrome умер сам, дальше смотреть
   `command-center\data\desktop-profile\chrome_debug.log` (в этом окне файл
   отсутствовал — Chrome до стабильной работы не дошёл).
