# BOSSMAN Command Center — UX 2.0: настольное окно, панель «Процесс работы», переподключение

## 1. Запуск как приложение

### Команда запуска
```
bcc-desktop
```

Или через Python — работает и без `pip install -e command-center`:
```
python -m bcc.desktop      # окно приложения
python -m bcc              # только сервер, без окна
python -m bcc --help       # справка; сервер при этом не поднимается
python -m bcc --version
```

### Опции командной строки

| Опция | Описание | По умолчанию |
|-------|---------|--------------|
| `--host` | Адрес сервера | из переменной BCC_HOST или 127.0.0.1 |
| `--port` | Порт сервера | из переменной BCC_PORT или 8800 |
| `--browser` | Путь к Chromium/Chrome/Edge | автопоиск |
| `--profile` | Каталог профиля окна | `<data_dir>/desktop-profile` |
| `--window-size` | Размер окна | 1440,900 |
| `--no-server` | Только окно, без запуска сервера | не задано |
| `--browser-arg` | Дополнительный флаг браузеру | можно несколько раз |

### Поведение

- **Если сервер уже работает** на этом адресе и порту: новый сервер не запускается, окно подключается к существующему.
- **Секрет (токен) в URL не передаётся**: вход происходит через форму в окне. Cookie сессии сохраняется в отдельном профиле окна (`desktop-profile`) и переживает перезапуски.
- **Окно** открывается в режиме `--app` Chromium/Chrome/Edge (без адресной строки и вкладок).

### Коды выхода

| Код | Значение |
|-----|----------|
| 0 | Успешно |
| 2 | Chromium/Chrome/Edge не найдены |
| 3 | Сервер не поднялся на заданном адресе и порту |

## 2. Панель «Процесс работы»

### Как открыть

- Нажать кнопку в верхней строке (иконка системы)
- Или нажать **Ctrl+.** (контрол и точка)
- Состояние запомнится (localStorage ключ `bx.think.open`)

### Что показывает

Текущие задачи и события из жизни системы:

**Для каждой задачи:**
- **Состояние**: в очереди, запущена, пауза, остановлена, ждёт решения
- **Прошедшее время**: таймер, обновляется каждую секунду
- **Шаг**: текущий шаг из N (если известно)
- **Модель**: какой LLM сейчас работает
- **Инструмент**: последний вызванный инструмент и его длительность
- **Ожидание**: что система ждёт от владельца (инструмент, решение по гейту и т. д.)
- **Повторы**: сколько раз произошло переключение на резервную модель
- **Ошибки**: количество ошибок инструментов и логирования

**Лента событий** (последние 80):
- Все типизированные факты исполнения: задачи, инструменты, гейты, кэш, логи ошибок, проверки результатов и т. д.
- Время каждого события
- Пояснения (результат проверки, название инструмента, статус гейта)

### Что НЕ показывает

- **Никакого скрытого «хода мыслей» модели**: события очищены сервером и содержат только типизированные факты, структурированные для владельца.

## 3. Потеря соединения и перезапуск сервера

Если сервер упал или потерялась сеть:

1. **Индикатор соединения** внизу боковой панели станет красным: «нет соединения»
2. **Обратный отсчёт**: «нет соединения · повтор через N с» (обновляется каждые 500 мс)
3. **Баннер под верхней строкой** (появляется сразу при потере связи):
   - Текст: «Нет связи с сервером с HH:MM:SS (прошедшее время). Данные на экране могли устареть.»
   - Кнопка: **«Переподключить сейчас»** или «Повтор через N с»
4. **После восстановления сервера**:
   - Окно автоматически переподключится
   - Индикатор станет зелёным: «live-обновления»
   - Тост (уведомление): «Соединение восстановлено. Данные обновлены после [время] без связи.»
   - Активная страница перезагружается

Если хотите переподключиться раньше — нажмите кнопку «Переподключить сейчас» в баннере.

## 4. Как это проверено

В репозитории четыре теста UX 2.0 (реальный Chromium, реальный сервер, без сетевого шума):

- **test_ux2_desktop.py**: Реальный предустановленный Chromium в режиме `--app` против живого сервера; переиспользование уже запущенного сервера; секрет не попадает в URL.
- **test_ux2_thinking_pane.py**: Владелец видит факты исполнения из живого потока событий; панель открывается кнопкой/Ctrl+. и запомнит состояние; консоль браузера без ошибок.
- **test_ux2_reconnect.py**: При остановке и перезапуске сервера видно: обратный отсчёт до повтора, баннер с временем потери связи и кнопка «Переподключить сейчас», после восстановления — тост и обновление страницы.
- **test_ux2_pages_sweep.py**: Все 29 страниц рендерятся; каждая видимая кнопка имеет имя (текст, aria-label или title); нет двойной UTF-8-кодировки; кнопки-открывашки открывают модали, закрываемые по Esc.
