# Мастер-план внедрения идей из восьми репозиториев

Составлен по итогам исследовательской волны. Правило одно: **берём идеи,
не берём зависимости** — к этому независимо пришли семь агентов из восьми.

- Ветка: `claude/bossman-control-v03-43igbk`
- ТЗ: `docs/research/*.md` (~3900 строк)
- База тестов на старте волны внедрения: 273 passed, 1 skipped

## Итог исследования

| Репозиторий | Вердикт | Что берём |
|---|---|---|
| memsearch | ВЗЯТЬ ИДЕЮ | RRF k=60, отбрасывание пустых секций, очистка перед индексацией, инкрементальность по чанкам, модель в `chunk_hash` |
| mem0 | ВЗЯТЬ ИДЕЮ | форма факта, additive без разрушающего UPDATE, подмена id для модели, entity boost, экстракция раз на run |
| graphiti | ВЗЯТЬ ИДЕЮ | две оси времени, перекрытие вместо удаления, `invalid_at` старого = `valid_at` нового, временные фильтры в поиске |
| claude-context | ВЗЯТЬ ИДЕЮ | чанк = синтаксическая единица, заголовок `путь :: имя`, разбиение идентификаторов, дедуп перекрытий, фоновая индексация |
| RAGFlow | ВЗЯТЬ ИДЕЮ | не резать атом, границы fence/таблиц, веса реранка параметрами, пост-атрибуция цитат, контекст вокруг таблицы, реестр парсеров |
| LanceDB | ВНЕДРЯТЬ ПОЗЖЕ | этап 0: чанки в SQLite вместо одного JSON |
| Qdrant | ВНЕДРЯТЬ ПОЗЖЕ | этап 0: вынести чанкинг, расширить протокол, `Encoder` отдельно, снапшот `derived_stores` |
| browser-use, OpenClaw | исследуются | — |

**Ни одного «ВНЕДРЯТЬ»** — и это результат, а не отписка. Почти везде ценна
идея, а не библиотека: mem0 стоит ~8400 токенов на сохранение, graphiti —
15–40k на эпизод, memsearch ищет 2.15 с против наших 0.025 мс, claude-context
по их же бенчмарку даёт F1 0.40 против 0.40 у голого grep.

## Дефекты в нашем коде, найденные исследованием

Каждый — реальный, ни один не был известен до волны.

| Дефект | Нашёл | Статус |
|---|---|---|
| `tool_expand` ловит `KeyError`, а мост бросает `RuntimeError` → падал handler | memsearch | **исправлен** (приведён контракт моста) |
| Мост не передавал `--exclude` → исключения хранилища молча не работали | memsearch | **исправлен** |
| `stats` отдавал строку там, где контракт требует dict | memsearch | **исправлен** |
| Абсолютные пути с `$HOME` уходили в контекст модели | memsearch | **исправлен** |
| Ответ MCP-сервера не обрезался вовсе — один вызов мог залить десятки КБ в контекст | claude-context | **исправлен** |
| Узкое место BM25 — не поиск, а **запись**: 9.2 с на одну заметку при 24k чанков | Qdrant | лейн «Ядро памяти» |
| Холодный старт: JSON целиком в память, 20 с на 100k чанков | LanceDB | лейн «Ядро памяти» |
| Снапшот знает только SQLite — индекс памяти в него не попадает | Qdrant | лид |
| `_split_long` режет code-fence и таблицы пополам | RAGFlow | лейн «Ядро памяти» |

## Что осознанно НЕ делаем

- Milvus, Neo4j, Elasticsearch, MySQL, MinIO — ни одного нового сервиса.
- Ни одной новой зависимости в первой волне.
- Никаких вызовов LLM на каждом шаге агента ради памяти.
- Платформу RAGFlow — никогда: это второй control plane, а не библиотека.
- Локальный режим `qdrant-client` — никогда: brute-force на numpy, хуже нашего BM25.

## Условия возврата к отложенному

| Решение | Триггер |
|---|---|
| LanceDB / qdrant-edge | > 30 000 чанков, либо `memory.write` дольше 5 с, либо появился доступный эмбеддер |
| DeepDoc из RAGFlow | ≥ 20 PDF или ≥ 200 страниц в месяц два месяца подряд И `pdfplumber` негоден на ≥ 30% из них |
| Milvus + claude-context | корпус > ~50 МБ исходников, либо Milvus появился ради другой задачи |
