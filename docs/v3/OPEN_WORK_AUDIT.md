## 2. Незакрытое в коде (приоритет сверху вниз)

1. **SLO по маршрутам** — `/api/control-plane` честно отдаёт `slo.status = NOT_IMPLEMENTED`.
   Гистограммы задержек уже есть (`latency.execution_ms/verification_ms/task_completion_s`),
   не хватает целей и бюджета ошибок на маршрут.
2. **Покрытие Command Center 76%** против 89% у ядра. Порог в CI (72%) держит от
   регресса, но не закрывает слабые места: наименее покрыты UI-фичи. Поднимать
   порог только вместе с тестами, см. `docs/testing/COVERAGE_BASELINE.md`.
3. **Память: иерархия областей и TTL** (TRUTH-003 §19) — не начата. Существующее
   (журнал, FailureMemory, ScopedKnowledge с владением по хранилищу) работает;
   `ScopeToken` и вытеснение по TTL не делались. Ничего из состояния задач,
   эффектов, политик, одобрений, чеков, проверок и памяти отказов удалять нельзя.
4. **Детектор отсутствия прогресса** — существует в губернаторе
   (`_step_fingerprint` + пауза, тест `test_governor_no_progress_pause`), отдельная
   работа по §18 не требовалась; расширение на V3-цепочки не делалось.
5. **Удалённый транспорт флота** — сознательно НЕ реализован
   (`REMOTE_TRANSPORT_PRODUCTION_READY=NO`, `NODE_AUTH_PRODUCTION_READY=NO`).
   Это запрет из задания, а не недоделка.
6. **Autonomous Operations** — не начаты, отдельная миссия.

## 3. Замечания, найденные попутно (не мой участок, владельцу решать)

- `solana_volume_suite/setup_mainnet.py` использует пароль хранилища по умолчанию
  (`SuperSecretMasterPass123!`), если владелец нажал Enter. Для локального
  прототипа это осознанное удобство, для реального кошелька — слабое место.
  Live-исполнение Solana выключено, поэтому это не эксплуатируемо сейчас.
- В ветку одновременно пишут несколько сессий. Из-за этого прогоны CI регулярно
  отменяются, и «зелёный по точному SHA» получить трудно. Это организационная,
  а не техническая проблема.

## Дополнение при закрытии сессии (производительность и незавершённые проверки)

### Сделано и измерено

Открытие панели: 31 вызов `/api` → 17. Причины были две — запись `last_seen`
в БД на каждый запрос (на SQLite сериализует всё остальное) и независимые
одинаковые запросы оболочки и страницы обзора (`/api/system` трижды за
загрузку). Обе устранены, коммит `d5d38aa`, есть регрессионный тест.
