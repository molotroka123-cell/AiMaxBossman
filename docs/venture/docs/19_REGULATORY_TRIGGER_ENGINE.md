# Regulatory trigger engine

## Purpose

Regulation can create:
- forced spend;
- new admin;
- deadlines;
- new APIs/data;
- exemptions;
- compliance risk.

## Signal object

Capture:
- authority;
- legal instrument/proposal;
- status;
- current stage;
- technical docs status;
- affected segment;
- effective date;
- uncertainty;
- economic burden/opportunity;
- next legislative event.

## EET calibration

As of 2026-08-28:
- technical Playground exists;
- project schedule exists;
- final legislation remains in process.

Correct classification:
TECHNICAL_PREPARATION_ACTIVE
LEGISLATION_NOT_FINAL

An agent that confuses these creates product and legal risk.

## Decision question

For every change:
“Who now has a recurring, mandatory or expensive workflow that software can
compress?”
