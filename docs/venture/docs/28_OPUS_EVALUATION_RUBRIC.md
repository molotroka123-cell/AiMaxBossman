# Opus evaluation rubric

Opus should independently score each Business Decision Packet.

## Mandatory questions

1. Is pain economic or merely annoying?
2. Is the payer explicit?
3. Why now?
4. Is there direct evidence?
5. What does current workaround cost?
6. Can the customer be reached legally?
7. What is the first payment event?
8. What if CAC doubles?
9. What if price must fall 30%?
10. What if model cost triples?
11. What if regulation disappears/delays?
12. What if SAM is half the estimate?
13. What incumbent can copy it?
14. What moat can form?
15. What can be delivered manually first?
16. What is the cheapest falsification?
17. What result kills it?
18. What would change the recommendation?

## Verdicts

GO TO VALIDATION
GO TO PAID PILOT
GO TO LIMITED BUILD
HOLD
KILL

Opus should not have “GO TO FULL BUILD” before acquisition/retention proof.

## Bias checks

- novelty bias;
- confirmation bias;
- sunk-cost bias;
- founder-preference bias;
- regulatory hype;
- AI-solutionism;
- TAM inflation.
