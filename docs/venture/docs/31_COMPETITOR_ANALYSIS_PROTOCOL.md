# Competitor analysis protocol

For each competitor capture:
- exact product;
- target segment;
- public price;
- free tier;
- onboarding;
- integrations;
- core workflow;
- reviews/complaints;
- switching cost;
- distribution;
- recent changes.

## Questions

What do customers pay for?
What is bundled free?
Where is support expensive?
What feature is table stakes?
What is not solved end-to-end?
What can they copy in 90 days?
What requires proprietary process/data/distribution?

## Warning

Competitor absence may mean:
- opportunity;
or
- no market.

Need direct payment evidence.
