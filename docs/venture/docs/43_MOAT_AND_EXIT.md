# Moat and exit logic

## Moat hierarchy

Weak:
- prompt;
- UI;
- public model.

Moderate:
- deep workflow;
- integrations;
- domain calibration;
- support/process know-how;
- local compliance.

Strong:
- proprietary longitudinal operational data;
- distribution partnership;
- high switching cost;
- network effects;
- embedded workflow;
- trusted brand in narrow vertical.

## Exit readiness

A venture becomes saleable when:
- IP ownership clear;
- revenue independently tracked;
- customer contracts transferable;
- dependency inventory clean;
- churn/cohorts documented;
- source/licences clean;
- legal entity structure understandable.

Track “transferability” as a portfolio metric at higher MRR.

Do not optimize for exit before product-market proof.
