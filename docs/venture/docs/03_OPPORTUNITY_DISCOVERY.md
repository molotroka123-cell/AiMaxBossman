# Opportunity discovery system

## Signal classes

### Regulatory
A new obligation, deadline, exemption, API or reporting burden.

Question:
who has just acquired an expensive workflow?

### Fragmentation
Repeated retyping among e-mail, PDF, Excel, calendar, accounting, CRM and
government portals.

Question:
can one product own the entire economic workflow?

### Labor cost
High-value worker doing low-value admin.

Question:
what does one saved hour cost the customer?

### Technology
New model/API/local hardware makes previously expensive automation feasible.

Question:
did cost/quality cross a commercial threshold?

### Pricing
Incumbent raises price, removes feature or changes packaging.

Question:
is there an underserved price/value wedge?

### Demand
Repeated support issue, job posting, RFQ, forum complaint or search intent.

Question:
is there a payer and repeat frequency?

## Discovery record

Every signal creates:
- source;
- timestamp;
- affected segment;
- expected economic consequence;
- hypothesis;
- confidence;
- next evidence action.

It does not create a build task.

## Opportunity backlog states

NEW
→ TRIAGE
→ RESEARCHING
→ VALIDATION_CANDIDATE
→ VALIDATING
→ BUILD_CANDIDATE
→ BUILDING
→ PILOT
→ SCALE
→ HOLD
→ KILLED

A killed opportunity may return only if a new dated trigger changes the thesis.
