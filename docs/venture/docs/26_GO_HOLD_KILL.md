# GO / HOLD / KILL protocol

## GO

Only if next spend has evidence-backed expected value.

Specify:
- next gate;
- max spend;
- deadline;
- expected result;
- failure result.

## HOLD

Use when:
- evidence insufficient;
- timing wrong;
- dependency not ready;
- regulatory outcome pending.

Hold requires:
- revisit trigger;
- no active development.

## KILL

Examples:
- payer remains unidentified;
- no paid pilot after sufficient qualified selling;
- structural margin failure;
- data/API unavailable;
- legal acquisition impossible;
- retention failure;
- bespoke-service trap;
- incumbent free product removes wedge.

## Root cause

Before kill classify:
- problem;
- segment;
- offer;
- price;
- channel;
- implementation;
- timing.

Killed thesis remains in history.
