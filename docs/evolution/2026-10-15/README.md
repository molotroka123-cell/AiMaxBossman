# Эволюция Bossman · 15 октября 2026

Две версии одной 79,5-секундной кодовой анимации: [русская](bossman_evolution_ru.mp4),
[английская](bossman_evolution_en.mp4), [постер](poster_ru.png). Без облачных
видеомоделей и личных медиа. Это история проекта, а не свидетельство завершения
продакшен-приёмки 2.2.

## Пересборка

Из корня репозитория, с Python 3.12, `playwright`, Chromium, `tzdata` и `ffmpeg` в
`PATH`:

```powershell
python docs/evolution/2026-10-15/src/rebuild.py
```

Скрипт использует зафиксированные хеши веток из `src/refs.lock.json`. Для новой
сводки сначала обновите refs намеренно командой
`python docs/evolution/2026-10-15/src/build_data.py --fetch --refresh-refs`;
затем запустите `rebuild.py`. Если `origin/main` сдвинулся, старый снимок отвергается.
Видео рисует `src/bossman_evolution.html` через Chromium, а `src/render.py` передаёт
`data.json` и `i18n.json` в страницу при открытии. Временные `_render_chunks/` и
`still_*.png` используются только для проверки/сборки.

Точное значение каждого поля и источники дат вех находятся в `src/data.json`.
`per_day` считает уникальные коммиты по дате автора в Europe/Prague, включая
неслитые локальные ветки. Первый коммит `1e6c8c5` был 27 августа 23:10 UTC,
то есть **28 августа в Праге**. Сцена «27 августа» следует UTC-дате первого
коммита и исходному рассказу; ось графика использует Прагу. Это объясняет
расхождение с историческим эталоном, где ось начиналась 27 августа.

Эталонный архив указывал 3 737 коммитов на 14 октября. На новом снимке их
на 152 больше (+4,1%): в расчёт вошли все достижимые коммиты зафиксированных
локальных и remote веток, в том числе новая работа 15 октября. Файлы и тестовые
файлы совпадают с эталоном; максимум слитого PR остаётся 97. Число 97 **не**
означает, что открытых или иных PR всего 97.

Полоса авторов группирует только имя автора Git. `molotroka123-cell` =
«аккаунт владельца» (1 892), `Claude*` и `Bossman Repair Engineer*` = Claude

как **локальные имена без проверки личности**; мы не приписываем их владельцу.
Прочие (29) включают Qwen, ботов и других авторов. Сумма групп — 3 889.

Апрельские JARVIS, июньский ATLAS и 22 августа представлены по переданному

не о сертификации GUI, долгой стабильности или завершении этапа 2.2.
