Запуск тестов: `python -m pytest apps/compute_mesh apps/identity_fill apps/newsletter -q` -> 70 passed.

## Как перенести на второй компьютер (флешка)

1. Главный ПК: `python -m apps.compute_mesh.make_drive E:/ --coordinator http://<IP главного ПК>:8850 --token-file mesh.token`
2. Главный ПК: `python -m apps.compute_mesh.coordinator --token-file mesh.token`
3. Второй ПК (нужны Python и Ollama с моделями): запустить `bossman-worker/START_WORKER.cmd` с флешки, набрать YES.
4. Состояние: `http://<IP главного ПК>:8850/dashboard?token=<содержимое mesh.token>`
