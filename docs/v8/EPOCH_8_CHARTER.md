# Epoch 8 Charter — Bossman Studio

## Миссия

Дать владельцу одну студию генерации изображений, видео и звука внутри уже
существующего Command Center: одна строка промпта, настройки ровно те, что
объявляет выбранная модель, каждый законченный прогон — в одной галерее с
полным происхождением. Провайдеров несколько (локальные и облачные, включая
Higgsfield), но байты результата, деньги и улики остаются на машине
владельца, а каждая возможность доказана тестом на установленном
Windows-архиве — тем же контрактом приёмки v2, что и всё остальное.

«Свой Higgsfield» здесь означает **свою студию и свой контроль**, а не свои
модели: веса Seedance, Kling, Veo, Soul принадлежат их владельцам и доступны
только по API. Это записано прямо, чтобы ни один отчёт не выдавал доступ по
ключу за «собственную модель».

## In scope

- каталог моделей генерации как источник истины: схема параметров и ролей
  медиа на модель, пять ответов на провайдера (BUNDLED / CONFIGURED /
  MODEL_REQUIRED / EXTERNAL_SERVICE_REQUIRED / VERIFIED), проверенные
  возможности из проб (`model_router`: «проба важнее рекламы каталога»);
- протокол провайдера генерации с именованными состояниями и адаптеры:
  локальный ComfyUI (существует, text-to-image), OpenRouter `/api/v1/images` и
  `/api/v1/videos` (уже вызываются `tools/hailuo_rescue.py` и
  `tools/seedance_shorts.py`, но вне продукта), платформенный API Higgsfield
  (`POST /{model}`, `GET /requests/{id}/status`, `Authorization: Key id:secret`),
  MCP-сервер Higgsfield — только через полосу `tools/mcp_acceptance.py`;
- одна очередь прогонов с кооперативной отменой (урок BL-066), дедлайнами,
  бюджетом и без слепых повторов;
- единая кросс-медиа галерея с provenance на каждый результат, reuse
  (модель + настройки + промпт восстанавливаются), избранное, коллекции,
  корзина с отменой удаления;
- связка с движками: результат → медиа Video Studio (`media.import`), картинка
  Web Designer, вложение задачи агента; инструмент `studio.generate` под
  `gate_completion` («наблюдение ≠ улика»);
- раскадровка из `bcc/video_studio/storyboard.py` как план пакетной генерации
  (hook / reveal / detail / benefit / cta / proof → по кадру на рецепт);
- локальная пост-обработка (апскейл, удаление фона, рефрейм) — только
  кандидатами через матрицу пяти ответов `docs/oss/README.md`; рефрейм по
  FFmpeg доступен уже сейчас;
- приёмка на установленном архиве, строки вердиктов, вход в заморозку.

## Out of scope

- обучение или хостинг собственных генеративных весов (кроме уже
  существующего локального LoRA Video Studio, который остаётся как есть);
- копирование кода `open-higgsfield` (у репозитория нет файла LICENSE) и
  копирование интерфейса Higgsfield; заимствуются идеи с указанием источника;
- публикация в TikTok/соцсети, маркетплейс приложений, сайт-билдер, 3D-сцены,
  «предсказатель виральности» — не относятся к студии генерации и не
  обещаются;
- новые агенты, новые реестры/шлюзы/политики/менеджеры сайдкаров (правило §2
  `MASTER_PROMPT_NEXT_RUN.md`: «не писать второй раз»);
- новая страница-двойник: страница `images` («Изображения») становится
  «Студией», Video Studio и Web Designer остаются редакторами-потребителями;
- автоматическое включение тяжёлых моделей на старте, постоянные демоны,
  фоновые опросы провайдеров без задачи;
- платный fallback: если бесплатный маршрут недоступен — честный
  `OWNER_REQUIRED`, а не «дорого, но зато прошло».

## Неизменяемые принципы

1. **Каталог — источник истины, проба — судья.** Интерфейс рисует только то,
   что объявила модель; объявленное, но опровергнутое пробой, не предлагается.
2. **Байты — у владельца.** Результат скачивается при завершении, хэшируется и
   хранится локально; ссылка на CDN провайдера — вспомогательная и временная.
3. **Пять разных результатов.** Отсутствующий ключ, 429/квота, недоступная
   модель, отказ по контенту (nsfw/policy) и неверный ответ — разные состояния
   с разными действиями; ни одно не превращается в другое (словарь
   `bcc/model_health.py`, лестница `bcc/reality/recovery.py`).
4. **Деньги под гейтом.** Бюджет на прогон и на день; цена и локальность
   проверяются на каждом вызове, включая fallback (`provider_governance.py`);
   неизвестная цена облачной модели дисквалифицирует её (`model_router.py`).
5. **Ключи только через Vault или окружение.** В коде, аргументах, журналах,
   уликах и учебном корпусе ключей нет; в API и логах — только `…last4`.
6. **Медиа владельца не уходит без вопроса.** Отправка референса или клипа
   провайдеру — эгресс, показанный до кнопки; open-higgsfield кладёт загрузки в
   публичный Vercel Blob — Bossman так не делает.
7. **Наблюдение ≠ улика.** «completed» от провайдера — наблюдение; завершение
   — после независимой проверки байтов (декодирование, размеры, длительность,
   как в `read_verification.py` и `verify_windows_bundle.py`).
8. **Ничего по умолчанию не включено.** Каждый облачный провайдер —
   `ADOPT_AS_OPTIONAL_BACKEND`, выключен, включается владельцем; ленивый
   старт, остановка по бездействию, числа покоя приложены (§7 правил).
9. **Приёмка на архиве, не на клоне.** Каждая возможность студии — сценарий в
   `tools/acceptance_registry.json`, вердикт с привязкой к `archive_sha256`.
10. **Не обещать то, что не измерено.** Строки этого пакета — план; в отчётах
    появляются только числа, полученные прогоном.

## Входной гейт

Реализация Epoch 8 начинается, когда одновременно:

- на ветке есть принятый кандидат по контракту v2 и замку входов
  (сейчас `e39610de`, `WINDOWS_RC_READY_OWNER_REQUIRED`, блокеров нет);
- `REPOSITORY-FIXABLE P0 = 0`, `P1 = 0` по этому кандидату (выполнено, см.
  `docs/final/CURRENT_STATE.md`);
- владелец решил три вещи: (а) какие провайдеры разрешены и в каком порядке
  (локальный / OpenRouter / Higgsfield API / Higgsfield MCP), (б) бюджет в
  долларах или кредитах на день и на прогон, (в) где хранится ключ каждого
  провайдера (Vault приложения или Actions Secrets для CI);
- измерен и записан baseline движков: время импорта, RSS и CPU покоя
  `bcc.app` с Images-очередью, время первого ответа `/api/images/models` —
  до первого изменения (§7: «числа до/после, иначе интеграция не принимается»).

Без ключей провайдеров работа всё равно идёт: каталог, протокол, очередь,
галерея, интеграция с движками и вся приёмка на заглушках — репозиторная
часть; живые проверки остаются `OWNER_REQUIRED` и не маскируются.
