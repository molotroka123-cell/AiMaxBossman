# Визуальные материалы README V8

Эти файлы обслуживают документацию. Они не подключаются к runtime Bossman и не являются доказательством его готовности.

| Файл | Тип и источник |
|---|---|
| `hero.svg` | Новый типографический banner: V8 in progress, local-first, live pending |
| `workspace-concept.webp` | Crop AI-иллюстрации рабочего места; не фотография целевого компьютера |
| `interface-concept.webp` | Crop нарисованного интерфейса; не реальный screenshot |
| `usecases-concept.webp` | Crop художественных сценариев для раздела FUTURE |
| `architecture.svg` | Упрощённая объясняющая схема, не снимок работающих процессов |
| `event-loop.svg` | Числа из `../evidence/metrics-async-summary.json`, контролируемый Linux I/O-тест |
| `windows-acceptance.svg` | Исторические 40/42/44/46 сценариев разных кандидатов; не процент готовности |
| `timeline.svg` | События 10–18 сентября; точные SHA и UTC timestamps в аудите |
| `art-provenance.json` | Crop-координаты, тип изображения, размеры и контрольные суммы |

Полная исходная AI-инфографика не опубликована: она содержит неподтверждённые показатели и будущие даты. На crop нанесён текст `AI CONCEPT / NOT A PRODUCT SCREENSHOT`; соответствующая подпись есть и в README.
