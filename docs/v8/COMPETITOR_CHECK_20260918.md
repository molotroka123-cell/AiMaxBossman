# Сравнение направления Studio — 18 сентября 2026

Проверены публичные страницы. Это сравнение заявленных возможностей, не
измерение качества генерации, скорости, цены или надёжности чужих продуктов.

| Продукт | Что подтверждает официальный источник | Следствие для Bossman |
|---|---|---|
| [Higgsfield](https://higgsfield.ai/) | Несколько моделей генерации и управление камерой/движением | Одна строка промпта и выбор модели сами по себе не преимущество |
| [Runway](https://runway.com/product/ai-video-generator) | Генерация, редактирование, продление видео; старт из текста, картинки или клипа | Сохранять существующий монтаж; объединить его с генерацией |
| [Adobe Firefly Boards](https://www.adobe.com/products/firefly/features/boards.html) | Изображения, видео, несколько моделей, общая доска, работа с ассетами | Нужны удобная галерея, reuse и последовательность сцен |
| [Adobe Firefly video editor](https://helpx.adobe.com/firefly/web/firefly-video-editor/about-firefly-video-editor/about-firefly-video-editor.html) | Монтаж в браузере, текст, звук, генерация и история внутри редактора | Связка «генерация → монтаж» уже есть у аналога; нельзя объявлять её уникальной |
| [open-higgsfield](https://github.com/wide-trace/open-higgsfield) | README описывает prompt bar, настройки моделей, галерею | Только предмет изучения; код не копировался, зависимость не добавлялась |

Владелец хочет сделать генеративную студию главным способом создавать контент.
В фазе 0 поведение продукта не меняется, поэтому страницы Images и Video Studio
сейчас сохранены. Следующий интерфейсный этап должен вести от промпта к результату,
а существующий монтаж остаётся потребителем результата согласно уставу.

Измеряемая цель Bossman: локальные проверенные байты, история без ограничения
60 записей, полный provenance, явные расходы и эгресс, отказ вместо ложного
«готово». Эти свойства нужно доказать тестами следующих фаз; фаза 0 их целиком
не реализует. Звание «лучший в мире» не установлено сравнительным экспериментом.

Официальный REST Higgsfield этим обзором не подтверждён. Ни ссылки со скриншота,
ни README стороннего клиента не используются как API-контракт. Баланс владельца
здесь не запрашивался: credits=0/free — историческое наблюдение из точки входа.
