## 2. Почему он не может заменить Video Studio

Разные инструменты. Один делает клип из промпта, другой собирает фильм из
ваших файлов.

| Возможность | open-higgsfield | Video Studio Боссмана |
|---|---|---|
| Сгенерировать клип по тексту | да, через платформу | нет |
| Импортировать свои съёмки | нет | да |
| Многодорожечный монтаж, подрезка, undo/redo | нет | да |
| Экспорт с проверкой потоков и подписанной квитанцией | нет | да (`export_receipt.py`, `read_verification.py`) |
| Субтитры, расшифровка, перевод | нет | да |
| Ревизии, аренды, оптимистичная блокировка | нет | да (`store.py`) |
| Инструменты для агентов | нет | 24 штуки `video.*` |

Замена одного на другое отдаёт весь монтаж и не приносит ничего, чего не даёт
добавление провайдера генерации.

## 3. Четыре причины, по которым его код нельзя вписать буквально

1. **Лицензии нет.** Правило проекта (`docs/final/CONNECTOR_INTEGRATION_REPORT.md`):
   кандидат без проверенного файла лицензии на закреплённом SHA получает
   `REJECT` или `REFERENCE_ONLY`. Чужой код без лицензии в репозитории закрывает
   дорогу к публикации архива.
2. **Чужой стек.** Интерфейс Боссмана — ванильные ES-модули без npm-сборки
   (см. `docs/IMAGES_FEATURE_REPORT.md`: «без React, TypeScript, Tailwind, npm и
   без единой новой зависимости»). Next.js + React + сборщик внутри
   Windows-архива с Python-рантаймом и Chromium — это второе ядро интерфейса.
3. **Эгресс байтов владельца.** Загрузки идут в публичный Vercel Blob. Устав V8,
   принцип 6: медиа владельца не уходит наружу без подтверждения, публичных
   хранилищ нет.
4. **Ноль тестов.** Всю приёмку пришлось бы писать с нуля, а без неё архив не
   замораживается.

## 4. Что из него действительно стоит взять — и уже взято

Идеи, переписанные своими словами в `ARCHITECTURE_AND_WORKSTREAMS.md`:

* каталог моделей как источник истины, интерфейс рисует только объявленное (W1);
* настройки строго по схеме модели, без параллельного захардкоженного списка (W3);
* роли медиа (`start / end / reference / video / audio`) с лимитом на роль (W1);
* одна строка промпта для картинки и видео, модель решает поверхность (W3);
* повтор прогона восстанавливает модель, настройки и промпт, а не только текст (W5);
* галерея со скоупами и просмотрщиком (W5).

Заимствуются идеи с указанием источника. Код — свой.

## 5. Решение по кандидату

**`REFERENCE_ONLY`** — по тому же словарю вердиктов, что markitdown, playwright-mcp
и остальные: `docs/final/CONNECTOR_INTEGRATION_REPORT.md`. Причины: нет лицензии,
нет тестов, чужой стек, публичный эгресс, и ни одной возможности сверх той, что
даёт собственный провайдер генерации.

**Что делать вместо замены.** Video Studio остаётся. Генерация приходит страницей
«Студия» из V8 (фазы 0–2), а результат сразу становится медиа на таймлайне
(`media.import`, фаза 4). Тогда получается то, чего нет ни у Higgsfield, ни у его
клона: сгенерировал → смонтировал со своими съёмками → экспортировал с квитанцией.
