# Web Designer: творческий бриф в рабочем пути

Дата: 21.09.2026. Ветка поставки: `release/bossman-owner`.

## Как проверить владельцу

1. В реестре моделей подключите уже запущенную локальную модель и проверьте её доступность. Модель должна уметь отвечать структурированным JSON. Этот сценарий не скачивает веса и не выбирает облако вместо недоступной локальной модели.
2. Откройте «Веб-дизайн» → новый проект → карточка **«ИИ: творческий бриф (локально)»**. Введите название и описание на тестовых данных, нажмите «Открыть проект». Для существующего проекта тот же режим доступен в списке шаблонов строки генерации.
3. Проверьте полученный сайт в превью, измените текст, сохраните, перезапустите Bossman и откройте проект снова. В истории версий верните прежний вариант и проверьте содержимое. Не публикуйте сайт автоматически.

Обычные шаблоны остались отдельным детерминированным режимом. Успешный шаблон не называется результатом ИИ. Если нет допустимой локальной модели, появляется NOT CONFIGURED; существующий сайт не заменяется, пустой AI-проект не создаётся. Повторное нажатие создания во время запроса не отправляет второй запрос из формы.

## Что делает реализация

Существующий `web_designer_creative_brief.py` используется одним вызовом: семь стадий не означают семь запросов. Модель возвращает конечный HTML и короткие структурированные сведения о направлении, секциях, замечаниях и уточнениях. Программа проверяет форму ответа, сохраняет точный HTML через прежнюю систему версий и не принимает опоздавшую генерацию поверх чужой правки.

Короткая критика модели — её заявление, не независимое доказательство качества. В метаданных `browser_quality_gates=NOT_RUN`, пока соответствующие проверки не выполнены отдельно. Наличие `model_calls=1` фиксирует путь обработчика и не делает контрактный HTTP-stub настоящей моделью.

## Инженерная приёмка

`test_web_designer_creative_execution.py`: production router + реальные файлы и новый процесс, но явные модельные двойники. `web_designer_create.test.mjs`: настоящий обработчик формы с тестовыми DOM/API. `test_web_designer_ai_create_ui.py`: реальный браузер и production registry/provider/storage с явно указанным локальным HTTP-stub вместо генеративной модели; включён в windows-installed.

Ни один из этих уровней не доказывает скорость/качество модели на Ryzen владельца. Новому SHA требуется новый application ZIP и свои завершённые проверки. Прежний архив не изменять и не перемаркировывать.
