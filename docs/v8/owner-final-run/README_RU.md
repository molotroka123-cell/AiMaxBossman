# V8: подготовка и один GUI-прогон владельца

Это пакет инструкций и пустых шаблонов, НЕ сборка Bossman и НЕ доказательство freeze. Он должен попасть в окончательный application ZIP до его проверки. В репозитории путь: `docs/v8/owner-final-run/`; в готовой поставке: `app-support/owner-final-run/`.

Порядок: `PREPARATION_MEMORY_RU.md` → `OPENCODE_LOCAL_SETUP_RU.md` → `OPENCODE_OWNER_RUN_RU.md`. Для запуска OpenCode — `START_PROMPT_RU.md`. Исполнителям подготовки — `FABLE_ASTER_HANDOFF_RU.md`. В рабочую локальную папку скопировать `RUN_CHECKPOINT.template.json`; баги записывать по `BUG_REPORT_TEMPLATE_RU.md`.

Важное: документы не дают OpenCode зрение и мышь сами по себе. Калибровка driver обязательна. GUI-оператор не делает работу за агента Bossman. Терминал/код допустимы для отдельной диагностики и ремонта, не вместо пользовательского сценария. Пока нет всех обязательных результатов — ни один шаблон не является готовностью продукта.

Текущая задача — сохранить рабочую базу, устранить конкретные блокеры и закончить поставку. Новые функции, новые форки, отключение защит и старые автоматические мониторинги не включать.
