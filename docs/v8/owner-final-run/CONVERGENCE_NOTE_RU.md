## Один основной способ пройти приложение

Основной вход владельца — `docs/v8/OWNER_GUI_START_HERE_RU.md`, затем `OPENCODE_OWNER_RUN_RU.md` в этом пакете. Это видимый GUI-прогон G00–G19. Установленный OpenCode и независимый GUI-driver должны быть заранее готовы.

`docs/v8/OWNER_LOCAL_RUN_RU.md` Claude полезен как ТЕХНИЧЕСКИЙ спутник для диагностики, воспроизведения CI и работы интегратора. Его clone/Python/pytest не становятся обязательными для обычного запуска и GUI-приёмки владельца. Успешная команда из него не заменяет реальное нажатие, ввод и проверку эффекта от лица пользователя.

Нельзя автоматически передавать `--job-status success` только потому, что такой пример написан в инструкции. Статусы берутся из реально завершённых проверок. Нельзя смешивать старый bundle-acceptance из CI с новыми локальными уликами разных run_id/архивов и затем объявлять всё единым прогоном. Идентичность и источник каждого доказательства сохраняются; при несовместимости binding — BLOCKED, не ручная правка JSON.
