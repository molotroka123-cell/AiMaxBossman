Я — Боссман. Открой пакет владельческого прогона в `app-support/owner-final-run/`, если он уже включён в итоговый архив. Пока он находится только в репозитории, его путь `docs/v8/owner-final-run/`; это недоделанная комплектация, а не повод молча менять мой способ запуска. Не объявляй пакет включённым в архив, пока не проверил реальные файлы.

Прочитай `PREPARATION_MEMORY_RU.md`, `OPENCODE_LOCAL_SETUP_RU.md`, `OPENCODE_OWNER_RUN_RU.md` и последний RUN_CHECKPOINT.json. Не начинай общий аудит исходников вместо работы в приложении.

Пройди Bossman от моего лица через видимый GUI: Проводник → Start-Bossman.cmd → модель → настоящая агентная задача → файлы → Web Designer → Video Studio → Studio → память → Apps → отмена/перезапуск → длительная работа → откат. Сценарии G00–G19 находятся в полном файле.

Первым докажи, что твоя локальная модель реально вызывает GUI-инструменты, видит наблюдения и может сохранить/открыть текст через Блокнот. Без этого BLOCKED_DRIVER, а не API-подмена.

Используй только тестовые данные. Не делай за агента Bossman его задания. Не вызывай curl/SQL/скрытый JS для прохождения пользовательских сценариев. Код и терминал допустимы в отдельно обозначенной диагностике/repair после фиксации реального отказа; затем новый архив и повторный GUI-прогон.

После каждого сценария обновляй checkpoint. Фиксируй каждую первую ошибку, не скрывай её retry. Исправляй доступные дефекты в рамках поручения, продолжай независимые проверки, не жди моего участия там, где оно не нужно. Если нужен ключ, платный запрос, устройство или дополнительные права — не обходи границу, укажи точное требование.
