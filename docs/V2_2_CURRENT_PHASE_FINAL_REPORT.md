## Что честно НЕ сделано

1. **Мост OpenClaw** — прямой запрет пака для этой фазы. Не начинался.
2. **Закрытие browser-use и OpenClaw** — оба исследователя оборвались на лимите
   сессии. Закрывать их шаблонами из пака без реальных замеров означало бы
   выдать незавершённое за готовое. Отмечено NOT RUN.
   Единственная находка, которую агент успел зафиксировать до обрыва:
   у OpenClaw есть `openclaw mcp serve` — то есть наш существующий stdio
   MCP-клиент может подключиться к нему **без нового кода**. Это меняет оценку
   стоимости моста и должно быть проверено первым в следующей фазе.
3. **Интеграция `sqlite_index` в путь записи** (`patches/MEMORY_INTEGRATION.md`)
   и **derived stores в снапшот** (`patches/SNAPSHOT_INTEGRATION.md`) —
   модули готовы и покрыты тестами, проводка не сделана.
4. **Реальные hardware smoke** — GPU-модель, `opencode serve`, живой
   OpenRouter, замер VRAM: ничего из этого в контейнере невозможно.

## Решения при слиянии, которые стоит знать

Пак — merge kit, поэтому три кандидата были **не приняты вслепую**:

- `facts.py` оставлен наш (623 строки против ~230): в нём приёмы mem0, которых
  в паке нет. Совместимость дана адаптером `FactStore`, а не переписыванием.
- Строгость формы факта стала параметром: 15–80 слов нужны для фактов **из
  диалога**, структурные пишутся мягко. Запрет местоимений и неразрешённых
  относительных дат действует всегда.
- Два теста пака были неточны и исправлены с объяснением: проверка
  `.gitignore` через поиск по общему токену и срабатывание сканера на тестовых
  «канарейках».

## Готовность к следующей фазе

Репозиторий в рабочем состоянии: дерево чистое, тесты зелёные, CI-файлы на
месте. Порядок следующей фазы:

1. **Провести две готовые проводки** — `sqlite_index` в путь записи и
   `derived_stores` в снапшот. Оба модуля уже покрыты тестами; это снимет два
   PARTIAL и закроет найденный дефект «запись перестраивает весь индекс».
2. **Запустить Actions** и записать реальный статус — до этого CI остаётся PARTIAL.
3. **Закрыть browser-use и OpenClaw** с настоящими замерами. Первым проверить
   `openclaw mcp serve`.
4. Только после этого — мост OpenClaw, с обязательным дефолтом **ASK на
   отправку в канал**: он впервые даёт BOSSMAN возможность писать реальным людям.
