# STAGE 10 — Autonomous Development Factory: статус

## Что построено
`bossman/dev_factory/` — минимальное production-ядро петли:

`Task → план → изолированная копия → код → тесты в песочнице → состязательное
ревью → правка → доказательства → ПАТЧ → ОЖИДАНИЕ ВЛАДЕЛЬЦА`

| Модуль | Роль |
|---|---|
| `models.py` | автомат задания (11 состояний, единственный граф переходов), `DevStep`, `Evidence`, `RetryBudget`, `Patch`, `CONSEQUENTIAL_KINDS` |
| `store.py` | атомарное состояние (tmp+fsync+replace), журнал `performed` |
| `planner.py` | контракт планировщика + `FakePlanner`; обрамление недоверенного контента, детектор инъекций |
| `workspace.py` | одноразовая копия репозитория (без `.env`/ключей/`.git`), diff как патч |
| `executor.py` | тесты ТОЛЬКО через песочницу Этапа 8; недоверенный репозиторий → DEVELOPER-изоляция |
| `evidence.py` | вердикт по выводу тестов, вычистка секретов; UNKNOWN ≠ успех |
| `reviewer.py` | независимое состязательное ревью: секреты, инъекции, границы безопасности, отсутствие доказательств |
| `factory.py` | оркестратор петли, бюджет, отмена, восстановление |
| `subsystem.py`, `routes.py` | регистрация в реестре, read-only статус и патч |

## Границы, закодированные в коде (не в документации)
- **Нет пути публикации.** Терминал петли — `AWAITING_APPROVAL`. Тест разбирает
  AST модулей и требует, чтобы ни один вызов подпроцесса не нёс `push/merge/pr/release/tag`.
- **Успех невозможен без доказательств.** `Evidence.proves_success` требует
  `verdict=PASS` и `failed=0`; нераспознанный вывод даёт `UNKNOWN` и не считается успехом.
- **Сбой песочницы = FAIL**, а не тихий успех (fail closed).
- **Бюджет попыток конечен** и сам не восстанавливается.
- **Рестарт не повторяет консеквентные шаги** — журнал `performed` переживает перезапуск.
- **Контент репозитория — данные.** Инъекции не исполняются, а фиксируются в истории задания и в событии.
- **Секреты** не копируются в рабочую область, вычищаются в доказательствах, и патч с секретом ревью не проходит.

## Переиспользовано (без дублей)
Песочница (Этап 8), Resource Brain (Этап 4, через песочницу), events, errors/lifecycle/obs.
Второго рантайма, второй памяти и второго gateway не заведено.

## Тесты
`tests/test_dev_factory.py` — 21 состязательный тест: патч без авто-мержа, отсутствие
пути публикации, только владелец доводит до DONE, провалившиеся тесты не становятся
готовыми, сбой песочницы fail-closed, бюджет, отмена и её идемпотентность, рестарт
без повтора консеквентного шага, повторный прогон готового задания, инъекция из
README не меняет план и политику, секреты не копируются/не проходят ревью,
границы безопасности отклоняются, атомарность состояния.

## Не сделано (осознанно, вне scope Stage 10)
- Реальный планировщик на модели (есть контракт `Planner` + `FakePlanner`); подключение
  идёт через существующий Gateway, второго не заводить.
- `executor.edit()` — шов под модель/агента: сам по себе ничего не пишет, чтобы пустой
  прогон не выдавал себя за работу.
- Публикация патча (PR) — сознательно ВНЕ фабрики: это действие владельца.
- Stage 11 (обучение) и Stage 12 (remote client) не трогались.
