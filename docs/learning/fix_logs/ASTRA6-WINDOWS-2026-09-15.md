## Причины и воспроизводимые уроки

1. LGPL-вариант FFmpeg не содержал нужный приложению libx264. Проверять следует
   реальное кодирование H.264/AAC, ffprobe и полное декодирование результата,
   а не только наличие исполняемого файла. Используется upstream GPL-сборка
   с сохранением лицензионных текстов.
2. Новая версия FFmpeg убрала `-filter_complex_script`. Драйвер проверяет
   поддерживаемые опции конкретного бинарника и использует файловую форму
   `-/filter_complex`, когда требуется. Не заменять эту проверку увеличением
   тайм-аута UI-теста.
3. Идентификатор файла NTFS может превышать точный диапазон JavaScript Number.
   Передавать device/inode строками и сохранять проверку идентичности перед
   применением операции. Не обходить подтверждение владельца ради зелёного теста.
4. Терминальную сессию нельзя удалять из памяти до успешного commit её финального
   статуса в БД. Сбои открытия, записи и commit должны сохранять возможность повтора.
5. Ответ процесса на HTTP после рестарта ещё не означает готовность фоновых
   подсистем. Ограниченное ожидание должно требовать фактические healthy-состояния;
   постоянно starting/error не считается успешным результатом.
6. Видимые кнопки избранного и коллекций имели пустые либо неполные обработчики;
   поле поиска тоже не отправляло запрос. Использованы уже существующие параметры
   серверного API, чтобы фильтрация и подсчёт работали до ограничения страницы.
7. Скрытая оболочка диалога не доказывает открытие окна. Запрос без ответа не
   доказывает эффект. Повторный выбор активной вкладки и отменённый native prompt
   требуют отдельных наблюдений, а не автоматической маркировки «сломано».

## Границы вывода

Обход видимых групп кнопок не доказывает все вложенные состояния и внешние аккаунты.
Облачные модельные сценарии требуют секрета `BOSSMAN_OPENROUTER_API_KEY` в Actions;
при его отсутствии отчёт обязан оставаться OWNER_REQUIRED. Проверка Radeon,
камеры, калибровки и сохранения интеллекта локальной модели выполняется отдельно.
Название «Астра 6» — метка кандидата, не криптографическая подпись и не объявление
полного FROZEN. Источник окончательного статуса — `ASTRA6-FREEZE.json` конкретного
прогона с совпадающим SHA.
