# Поправка v3: постоянное разрешение на торговлю криптой

Что меняется: в конституцию добавлен раздел «Standing owner permissions» с одним пунктом — торговля криптой
средствами, которые уже лежат в кошельках Боссмана, без запроса перед каждой сделкой. Остальной текст не тронут.

Лимиты в черновике предложены Claude, а не владельцем: сделка не больше 5% баланса кошелька, стоп на день при
убытке 10%. Поменяй числа в файле до принятия, если нужны другие.

Принять (только владелец, в своём окне PowerShell, не из сессии агента):

    powershell -ExecutionPolicy Bypass -File tools/adopt_constitution_v2.ps1 -Draft docs/constitution/proposals/BOSSMAN_CONSTITUTION_v3_TRADING_DRAFT.md

Скрипт покажет разницу и закрепит новый хеш. Агент этот шаг выполнить не может — так задумано.
