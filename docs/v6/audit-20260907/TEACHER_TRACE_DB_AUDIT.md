## 3. Правила фильтра (предлагаемая политика, требует подтверждения владельца)

1. Источники «документы, чаты, расписки, фото» → `contains_private_data=True` по умолчанию; такие записи хранятся локально, не экспортируются и не покидают машину.
2. Обучающим (`reusable=true`) может стать только запись с внешне проверенным исходом.
3. Секреты и PII редактируются до записи; обнаруженный секрет — отдельное событие безопасности, а не молчаливая замена.
4. Экспорт валидирует схему и хэш-цепочку; любая ошибка — отказ экспорта целиком (fail-closed).
5. Размер/ротация ограничены, чтобы журнал всегда был сканируем CI.

## 4. Что НЕ утверждается

- Не измерялось качество обучения ни на каких данных.
- Не утверждается, что журнал даёт какой-либо процент прироста «ума» — см. `MODEL_SELF_ROUTING_AND_TANDEM_LEARNING.md` §6.
