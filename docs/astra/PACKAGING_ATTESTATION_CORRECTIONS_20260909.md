# Packaging acceptance corrections

These corrections strengthen candidate evidence; they do not turn historical
or diagnostic wheels into accepted artifacts. A fresh exact-SHA build is required.

* The Windows manifest-display CI command now reads UTF-8 and writes escaped
  ASCII JSON. The prior command repeated the cp1252 failure after the verifier
  had been repaired. The regression executes the actual workflow command in a
  strict cp1252 subprocess and checks decoded JSON equality.
* `git status` alone misses assume-unchanged/skip-worktree edits. Build identity
  now compares actual bytes and symlinks against HEAD blob objects, and scans
  packaged source/resource inputs for ignored additions. Negative controls use
  same-size, restored-mtime replacements hidden from normal Git status and an
  ignored injected Python module. Generated bytecode does not alter identity.
* Clean bundle builds use fresh detached Git worktrees. A negative control
  proves hidden local edits and stale `build/lib` files do not enter the snapshot,
  while the original workspace remains intact.
  Snapshot creation and the bundle CI checkout explicitly disable Git's
  autocrlf conversion. A real autocrlf=true negative control proves converted
  checkout bytes are detected; the clean snapshot restores exact text bytes
  while retaining binary CRLF bytes unchanged. No binary normalization is used.
* Wheels now carry `source_dirty`; installed verification and browser acceptance
  require strict Boolean false and a matching full SHA. True, null, missing,
  numeric zero/one, and string `false` are refused. Diagnostic dirty bundles
  cannot run/publish exact-SHA acceptance. The owner's independent model harness
  applies the same gate in its separately integrated change.
* The old root packaging test isolated only its final import process. When
  PYTHONPATH exposed source egg-info, target pip exited zero claiming the wheels
  were already installed while the target venv was empty. This was reproduced
  using the same 83c1a02 wheels: contaminated install/import failed; external cwd
  plus cleared PYTHONPATH installed those unchanged wheels and imports succeeded.
  The test now isolates installation too; all original import assertions remain.

The bundle contains the Python Playwright package through Core's declared
dependency. Chromium, FFmpeg/ffprobe and real model credentials/runtime are
explicit prerequisites. The generated README supplies installed-only commands
and distinguishes boot acceptance from live model, browser and Intelligence
Preservation evidence. Linux results never certify Windows.
