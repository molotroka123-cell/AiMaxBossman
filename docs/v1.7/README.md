# Bossman 1.7 — Consent-Based Personalization Lab\n\nExperimental branch for a Telegram assistant with local-first model routing and opt-in per-user personalization.\n\nCore rules:\n- Each participant explicitly opts in before durable personalization is enabled.\n- Each participant has an isolated local profile and can inspect, export, pause, correct, or delete it.\n- Telegram users never receive desktop-control, shell, owner-admin, payment, trading, or secret-management tools.\n- Jev selects the model/tool path with a local-first preference; web search is used when fresh information is needed.\n- Cloud routing is minimized and controlled by privacy/cost policy; there is no silent paid fallback.\n- Long-term memory is limited to user-provided preferences, goals, interests, and interaction style. Secrets are never stored.\n- Sensitive traits are not inferred for profiling.\n- Cross-user memory leakage is a P0 failure.\n\nPlanned stages:\n1. architecture and tests on this branch;\n2. owner-only Telegram shadow run;\n3. privacy/adversarial tests;\n4. one invited participant;\n5. up to 3–4 invited participants;\n6. later convergence only after Bossman 1.6 is green.\n\nThis branch is intentionally isolated from Bossman 1.5/1.6 release work.
