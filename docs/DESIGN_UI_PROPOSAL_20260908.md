# Предложение по дизайну и интерфейсу Command Center — 2026-09-08
По итогам вечернего прогона (Twitch + BTC + cloud QA + apps toggle). Только то, что observed.

## 1. Развязать жизнь сервера и окна (критично, баг B1)
Сейчас `bcc.desktop` гасит сервер, когда закрывается Chrome-окно. Владелец теряет фоновые миссии,
не понимая почему. Предложение:
- сервер (`bcc.app`) — отдельный долгоживущий процесс/служба с трей-иконкой «BOSSMAN запущен»;
- окно дашборда — обычный клиент, открывается/закрывается свободно;
- в UI — индикатор «сервер: uptime, порт, pid» + кнопка «Перезапустить сервер».

## 2. Вход без боли с токеном
Токен живёт в консоли, которую прячут/закрывают. Предложение:
- первый вход: кнопка «Открыть дашборд» в лаунчере сама пробрасывает сессию (desktop-profile уже помнит cookie);
- в UI — страница «Доступ»: показать/сменить токен, список активных сессий, кнопка «Выйти везде».

## 3. Apps: честное состояние вместо 409
Все 9 приложений отвечают 409, потому что флаг `BOSSMAN_APPS_CONTROL_ENABLED` выключен, а UI этого
заранее не говорит. Предложение:
- карточка каждого app всегда показывает живое состояние (process) — оно и сейчас читается без флага;
- кнопки Start/Stop при выключенном флаге — disabled с подсказкой «включите управление + рестарт»,
  а не кликабельные с ошибкой после нажатия;
- мастер «Включить управление приложениями» в один клик (проставить флаг, рестартнуть сервер самому).

## 4. OpenRouter: бесплатные модели — отдельный фильтр
Каталог 428 моделей, бесплатных ~24, искать их листанием тяжело. Предложение:
- чип-фильтр FREE рядом с ALL/CODING/VISION/TOOLS (бэкенд уже отдаёт цены);
- бейдж «probe fail» на модели, если последняя проба красная (как у `cohere/north-mini-code:free`);
- предупреждение перед назначением модели с красной пробой на агента.

## 5. Cloud-агенты и локальный UI
Облачный агент не достаёт loopback (политика браузера) — задачи 29/30 упали с «нужен публичный URL».
Предложение:
- при создании задачи с browser-инструментами и локальным URL — варнинг сразу, а не после прогона;
- шаблон «Локальный UI-тест»: автоматически выбирать локального исполнителя вместо облака;
- в карточке агента — строка «куда дотягивается»: internet / local (честно, из политики).

## 6. Мелочи
- Миссии: кнопка «Остановить всё» (гасить зависшие running пачкой, сейчас — по одной).
- Пробы модели: streaming=false показывать как «не проверено», а не как красный провал, пока нет эталона.
- Run-лог ночи: одна страница «Ночной прогон» со списком что сделано/упало и кнопкой «Скачать отчёт».
