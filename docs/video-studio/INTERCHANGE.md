# Обмен с открытыми редакторами

В Video Studio подключены OpenTimelineIO и экспорт редактируемого Shotcut/MLT.
Это совместимость конкретного набора операций, без заявления паритета с VEGAS Pro или Shotcut.

## Shotcut

Portable Shotcut **26.8.1** установлен локально в `.audit-work/shotcut/portable/Shotcut`.
Архив `shotcut-win64-26.8.1.zip`, 225002077 bytes, SHA-256
`b0148856de01b39add4bf4d6a813bfbc554b4663b65e3ca25cb2589f47555a6a`
совпадает с `sha256sums.txt` официального выпуска. Входящие бинарные файлы/архивы не добавлены в Git.

Экспорт `.mlt` создаёт настоящие источники, дорожки, source in/out, промежутки,
mute/solo, статическую громкость и многодорожечное смешивание. Ссылки на исходники
локальные и абсолютные: для другого компьютера сначала перенесите пакет проекта
с исходниками и перепривяжите их. Доли кадра округляются к ближайшему кадру
последовательности с явным предупреждением. XML экранируется стандартной библиотекой.

Эффекты, keyframes, retiming, вложенность, сложные перекрытия внутри одной дорожки
и титры не теряются молча: такой editable export отклоняется с объяснением.
Для сохранения этих эффектов откройте в Shotcut проверенный отрендеренный master;
он сохраняет вид/звук, но уже не предоставляет отдельные исходные клипы.
Произвольный чужой MLT не исполняется и не получает доступ к локальным файлам через Bossman.

Проверка: `test_video_studio_shotcut.py`, **4 passed** с реальным `melt.exe 7.41.0`.
MLT → настоящий MP4 → полный decode/размеры/длительность/звук; красный и синий кадры
проверены на своих временных позициях; отдельный тест подтверждает верхний синий
слой поверх красного. Проверена ошибка при подмене исходника и отказ терять reverse.

## OpenTimelineIO

Зависимость: `pip install -e 'command-center[video-interchange]'` либо
`pip install 'opentimelineio>=0.18,<0.19'`. В проверенном окружении — **0.18.1**.

Нативный `.otio` сохраняет точное время, перекрытия, идентификаторы, все
последовательности и медиатеку. Bossman-specific эффекты и retiming сохраняются
как metadata: другой редактор может их игнорировать. Изменения обычной обрезки
во внешнем OTIO корректно возвращаются через import и новую revision.
Немаппированные чужие ссылки отвергаются. Перед применением host проверяет
каждый исходник, путь внутри своего хранилища и SHA-256. Сам OTIO ничего не рендерит.

Проверка: `test_video_studio_interchange.py`, **6 passed** на настоящей библиотеке:
roundtrip, перекрытия, пустые дорожки, внешняя обрезка, ретайминг metadata,
неактивные последовательности/неиспользуемые исходники и ограничение размера.

Первичные источники: [Shotcut download](https://www.shotcut.org/download/),
[официальный выпуск](https://github.com/mltframework/shotcut/releases/tag/v26.8.1),
[MLT XML](https://www.mltframework.org/docs/mltxml/),
[OpenTimelineIO](https://github.com/AcademySoftwareFoundation/OpenTimelineIO).
