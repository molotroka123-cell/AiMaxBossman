# Обучение локального монтажного специалиста

Выполнено настоящее обучение весов отдельного LoRA-адаптера. Существующие модели владельца не перезаписаны.

- База: `Qwen/Qwen2.5-0.5B-Instruct`, фиксированная ревизия `7ae557604adf67be50417f59c2c2f167def9a775`, Apache-2.0.
- PEFT LoRA: rank 16, alpha 32, q/k/v/o projections, dropout 0.05.
- 160 шагов AdamW, learning rate 0.0002, seed 43; BF16, RTX 4060 Laptop, Torch 2.8.0+cu128.
- 48 синтетических монтажных примеров; отдельные 24 теста с другими формулировками и ID клипов. Приватные видео/переписка в обучение не включены и никуда не отправлялись.
- Семейства: trim, move, speed, reverse, audio volume, opacity.
- Точное совпадение команды на неизменном holdout: **0/24 до → 13/24 после**.
- Время обучения вместе с двумя прогонами оценки: 272.44 с; максимальная выделенная GPU-память: 1513 MiB.
- SHA-256 файла обученных весов `adapter_model.safetensors`: `9574e020469a6f78ece8dfd6aa2b4de1d58a02cd3f2bcb2e1b6b6912872226e8`.

Падение training loss не принимается за качество. Итог 13/24 недостаточен для безусловного исполнения команд. Адаптер подключается как источник предложений: результат должен пройти проверку выбранного clip ID, схемы команды, допустимости состояния и текущей revision. Существующие разрешения и execution gates сохраняются. Показатель относится только к этим шести семействам; он ничего не доказывает об общем интеллекте, VFX-оценке или просмотре видео.

Рецепт: `tools/video_studio/train_adapter.py --output <новый-каталог> --steps 160`. Скрипт фиксирует commit базовой модели, seed, hashes корпуса/holdout, baseline/candidate и отдельный `adapter/`. Каталог существующего эксперимента не перезаписывается. Весовые файлы остаются локально в `.audit-work/video-adapter-run01/adapter`; в Git находятся код, измерения и контрольные суммы.

Шестисемейный holdout уже использован для оценки этого эксперимента. Если менять датасет/параметры по его ошибкам, нужен новый внешний holdout; нельзя выдавать повторную подгонку под эти 24 случая за независимое улучшение.

Основные источники: [Qwen model card](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct), [PEFT LoRA](https://huggingface.co/docs/peft/package_reference/lora), [PyTorch Windows/CUDA](https://pytorch.org/get-started/locally/). OpenTimelineIO подключается отдельно как формат обмена монтажом, а не как генеративная модель: [официальный репозиторий](https://github.com/AcademySoftwareFoundation/OpenTimelineIO).
