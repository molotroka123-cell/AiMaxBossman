## Оценка полного клипа (на основе замеров)
Формула: `T = N_шотов × t_шота × (1 + запас)`.
- Конвейер `pipeline\concert.py`: 45 шотов на 168.829 с (31 певица + 14 вставок; вставки тоже через S2V, так как TI2V-5B непрактичен).
- Lightning: t_шота ≈ 16 мин (основной рендер) … 34 мин (замер под нагрузкой) → **12 ч … 25.5 ч**; с запасом 25 % → **15 ч … 32 ч**.
- 20 шагов: блоков S2V = ceil(168.829 / 4.8125) = 36; 36 × 2.9 ч ≈ **104 ч** (+25 % ≈ 130 ч).
- 70/30 S2V/I2V с TI2V-5B: вставки ≈ 4.7 ч на 5 с → хуже, чем всё через S2V.
- Не входит: загрузка моделей (уже скачаны), апскейл, ручной монтаж/отбор дублей.
