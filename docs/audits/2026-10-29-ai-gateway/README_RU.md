# Bossman AI Gateway — Единый шлюз безопасности для всех запросов к моделям (2026-10-29)

## Главное правило
Приватные данные остаются локально на ПК владельца; наружу к внешним провайдерам уходит только минимальный, локально очищенный запрос, и только через единый шлюз `AIGateway` (`command-center/bcc/security/ai_gateway.py`), встроенный в `GovernedAdapter.chat` (`command-center/bcc/provider_governance.py`).

## Схема маршрутизации

```text
Запрос → локальная классификация (public | internal | confidential)
       → минимальный пакет контекста (ContextMinifier)
       → локальная очистка и псевдонимизация (LocalScrubber + RedactionSession)
       → политика провайдера (ProviderPolicyRegistry: local | trusted | experimental | unknown)
          ├─ разрешено → AI Gateway → внешний/локальный адаптер (→ локальное восстановление меток [КЛИЕНТ_1])
          └─ запрещено → локальная модель (local_fallback_adapter) / жёсткий отказ (GatewayBlockedError)
       → метаданные в локальный журнал (GatewayAuditLogger, без текста запроса/ответа)
```

## Что реализовано

1. **Определение чувствительности запроса (`DataSensitivity`)**:
   - **`public` (Публичный)**: нейтральные и синтетические запросы без внутренних маркеров — разрешены любому одобренному провайдеру (`local`, `trusted`, `experimental`).
   - **`internal` (Внутренний)**: содержит названия клиентов, проектов, внутренние адреса или рабочие реквизиты — отправляется **только** доверенным провайдерам (`trusted`) или локальной модели, строго после локальной очистки и упаковки минимального контекста. Для экспериментальных (`experimental`) и неизвестных (`unknown`) провайдеров блокируется.
   - **`confidential` (Конфиденциальный)**: личная память (`personal_memory`), личные документы (`personal_docs`), бизнес (`business`), финансы (`finance`), API-ключи/пароли/seed-фразы (`keys`) и код из приватных репозиториев (`private_repo`) — обрабатывается **только локальной моделью**; внешний запрос запрещён.

2. **Локальная очистка текста и обратимая псевдонимизация (`LocalScrubber` + `RedactionSession`)**:
   - Необратимо вырезает и блокирует выход наружу при обнаружении API-ключей (`sk-...`, `AIza...`, `ghp_...`, `hf_...`, `nvapi-...`, `gsk_...`, `xoxb-...`), приватных ключей (`BEGIN PRIVATE KEY`), паролей и 12/24-словных BIP-39 seed-фраз.
   - Обратимо заменяет названия компаний/ФИО на `[КЛИЕНТ_1]`, банковские счета и ИНН на `[СЧЕТ_1]`, карты на `[КАРТА_1]`, email на `[EMAIL_1]`, телефоны на `[ТЕЛЕФОН_1]`, внутренние IP/хосты на `[ВНУТР_АДРЕС_1]`, локальные пути на `[ПУТЬ_1]`, названия проектов на `[ПРОЕКТ_1]`.
   - Оригинальные значения хранятся только в оперативной памяти `RedactionSession` внутри процесса и автоматически подставляются обратно (`session.rehydrate()`) в ответ модели локально.

3. **Передача минимума контекста (`ContextMinifier.pack_minimal_context`)**:
   - Автоматически исключает блоки памяти Bossman (`[MEMORY CONTEXT...]`), сообщения с флагом `_local_only`, ограничивает/удаляет сырые дампы инструментов (`role="tool"`), обрезает системные промпты и оставляет только последние `8` реплик (`max_context_chars=24000`).

4. **Запрет прямых вызовов и политика провайдеров (`ProviderPolicyRegistry`)**:
   - Все вызовы через `GovernedAdapter` проходят через `AIGateway.execute_chat`.
   - Неизвестные провайдеры (`unknown`) блокируются по умолчанию до явного разрешения владельцем (`POST /api/ai-gateway/policy/allow`).
   - Сомнительные/экспериментальные сервисы и `:cloud`-оффлоады (`experimental`) допускают только `public` / синтетические запросы.

5. **Локальное логирование только метаданных (`GatewayAuditLogger`)**:
   - Записывает: `provider`, `provider_host`, `provider_trust_tier`, `model`, `ts`, `tokens_in`, `tokens_out`, `latency_ms`, `sensitivity`, `data_categories`, `triggered_rules`, `decision`, `reason`, `prompt_sha256`.
   - Полный текст запроса и ответа в логи по умолчанию **не записывается** (`raw_text_logged: false`).
