**Побочная находка этого прохода — настоящая гонка в звонках** (секция «Звонки», соседний сбор по Jeff): `test_scenario_passes_offline[echo]` падал ~1 раз из 15 на тихой машине.
Первопричина: `EchoGuard` принимал первую оценку пути эха по 16 слотам (512 мс); случайная корреляция 0,5–0,6 давала задержку 1–2 слота вместо 8, прогноз эха был неверен, и звонок
перебивал собственный голос. Исправлено (`6d9c1f56`): первая оценка — после ≥1 с нашего аудио; 0 из 30 падений против 2 из 30; тест на снятых огибающих падает на старом коде.
