# Матрица 12 пунктов

PASS означает только названный уровень проверки, не общую приёмку. PARTIAL = выполнена ограниченная часть, остальное не проверено.

| Пункт | Статус | Факты и остаток |
|---|---|---|
| 1. Windows Job Object для запусков | NOT_RUN | Найдены пути, где привязка не гарантирована; нужна проверка каждого процесса и Windows live STOP. |
| 2. PowerShell-шлюз | PARTIAL | AST отсутствует в реальном пути argv; обычный PowerShell требует подтверждения. Интеграция и отрицательные тесты не выполнены. |
| 3. SpendFirewall по умолчанию | PARTIAL | Economy path закрыт без флага; 80 целевых тестов в совокупности. Прочие пути, реальная цена и выпуск разрешений не доказаны. |
| 4. Негативные тесты pc_agent_policy | NOT_RUN | Требуется воспроизвести на точном SHA и зафиксировать результат. |
| 5. Самоправка D-036 | NOT_RUN | Новый live цикл и перенос результата не выполнялись. |
| 6. Video Studio 2.0 | NOT_RUN | Свежий рендер не выполнялся; исторический синтетический PASS не считать live результатом. |
| 7. Character-lock | NOT_RUN | Нужна визуальная проверка последовательности и воспроизводимые метрики. |
| 8. QLoRA Gemma 3 без аренды | PARTIAL | Устранена выдача синтетического турнира за PASS; обучение Gemma 3, реальные ответы base/adapter и удержанный турнир не запускались. |
| 9. Пульт и голос | NOT_RUN | Живая приёмка этой ветки не проводилась. |
| 10. Причина рассылки Джеффа | NOT_RUN | Не расследовалась; не включать рассылку. |
| 11. Суточный прогон | NOT_RUN | Не запускался, исходные критические ограничения и live приёмка не закрыты. |
| 12. Граф роя | NOT_RUN | Реальная оркестрация Bossman и передача результатов не проверялись. |
