# Независимому проверяющему и интегратору

1. Сверить `origin/main`, исходную базу, exact HEAD ветки и незакоммиченные изменения. Переснять CI и runtime; не переносить старые статусы.
2. Повторить тесты из README и изучить diff двух кодовых коммитов. Атаковать классификацию бесплатного тарифа: подтверждать происхождение стоимости и покрытие отдельных транспортов; выработать атомарный межпроцессный учёт, binding токена к модели/провайдеру и безопасный выпуск разрешения владельцем. Провайдер может выставить счёт выше оценки; без жёсткого провайдерского лимита не обещать потолок.
3. Проверить QLoRA revocation и оба неизменённых receipt по SHA; до реального изолированного турнира помечать результат NOT_MEASURED. Подключать обучение только при доступных ресурсах, без аренды и без смешивания train/holdout.
4. Для PowerShell обрабатывать реальный argv без потери границ, закрывать неопознанные и encoded формы, не ослаблять существующий T2/T3. Проверить trusted System32, ограниченный timeout/воркер и отсутствие действий после STOP; выполнить Windows-негативные тесты без запуска опасных команд. Факт отсутствия AST не считать доказательством обхода.
5. Проверить Job Object в каждом launcher, аварийный путь, дочерние процессы и отрицательный контроль на Windows. Сохранить чужие процессы и изменения.
6. Только после устранения критичных проблем и согласованных prerequisites запускать live приёмку и 24-часовую устойчивость. Для каждого пункта записывать SHA, команду, среду, логи, стоимость, ожидаемое и фактическое. Оставлять BLOCKED/NOT_RUN, если доказательств нет.

Не сливать в main при красном обязательном CI, расхождении runtime или непроверенном diff. Не запускать второй poller и платные запросы; не объявлять продажу, Tier 5 или freeze без необходимых фактов. Отдельная cross-family проверка не проведена.
