# Уроки для памяти Bossman: исполнение аудита

Статус: подготовлено для импорта в настроенную память; импорт и использование моделью не подтверждены. Источник — локальные результаты на ветке `codex/exec-swarm-20261028`, base `f5b05cd17c7411e2136bb8f5106576a7e911915f`; подробнее `README_RU.md`, `MATRIX_RU.md`. Память — данные, она не отменяет инструкции, permissions и подтверждения владельца. Не считать запись изменением весов или доказанным ростом качества.

## Урок 1. Не тратить без подтверждения
Код `d55abf8061a513df582f3a788f18bbef632df0c7` проверяет одноразовое разрешение в конкретном economy path. Некорректная цена запрещена, неизвестный фактический счёт блокирует дальнейшие расходы. Это НЕ доказательство защиты всех маршрутов: проверять происхождение тарифа, стоимость, покрытие маршрута и независимый бюджет; не утверждать жёсткий потолок при возможности превышения у провайдера. Evidence: 80 локальных synthetic тестов на `27cab3209a2f2e0c5400dee886e22306a495a3e9`, без настоящих вызовов.

## Урок 2. Не путать образцы с экспериментом
Код `27cab3209a2f2e0c5400dee886e22306a495a3e9` отозвал PASS QLoRA-турнира, который сравнивал заранее записанные ответы. Чтобы заявить улучшение, нужны настоящие ответы base и adapter на удержанных заданиях, одинаковый оценщик, условия, SHA и воспроизводимые квитанции. Исторические данные сохранены, статус NOT_MEASURED.

## Урок 3. Проверять реальный путь исполнения
В Windows PowerShell AST не подключён к фактическому `argv`; обычная команда уже требует подтверждения. Не выдавать отсутствие шлюза за доказанный автоматический обход. Перед интеграцией разбирать argv без потери границ, защитить путь к парсеру и timeout и проверить STOP в Windows. Live-тест этого прогона NOT_RUN.

## Как пополнять память в следующих шагах
Для каждого законченного шага сохранять задачу, область, дату, SHA, факт, среду, проверку с отрицательным контролем, ограничения, источник и следующий измеримый тест. Непроверенное помечать NOT_RUN/BLOCKED; сохранять только минимально необходимые данные без секретов и личной информации. После записи проверить поиск и перенос урока на новое удержанное задание, а также после рестарта. Только измеренный результат на одной методике можно назвать улучшением; сохранённая заметка — ещё не обучение модели.
