## Что это

Node.js (Express 5) + React-дашборд. Локальный OpenAI-совместимый шлюз `/v1/*` (по умолчанию порт 3001): собирает бесплатные
уровни облачных провайдеров, ротирует ключи, ведёт RPM/RPD на ключ, переключается на другого провайдера при 429/ошибке.
SQLite через `better-sqlite3`. Встроенный каталог: 15 платформ (cerebras, cloudflare, cohere, google, groq, huggingface, kilo,
llm7, mistral, nvidia, ollama, opencode, openrouter, pollinations, zhipu), 82 модели в `/v1/models` для нашего ключа.

исходящих TCP-соединений после старта).

## Привязка и аутентификация

* По умолчанию `HOST` = `::` (все интерфейсы, `lib/config.ts`) — это **риск по умолчанию**. Наш лаунчер жёстко ставит
  `HOST=127.0.0.1`; `netstat`: `127.0.0.1:3001 LISTENING`, на `0.0.0.0`/`::` порта нет. `TRUST_PROXY=false`.
  `tailscale serve` на этот порт НЕ делать.
* Дашборд и `/api/*`: сессионный токен (`requireAuth`), пароль хешируется scrypt, есть троттлинг входа.
  Первый вход: аккаунт создаёт первый, кто откроет `http://127.0.0.1:3001` (с loopback код не нужен). Владелец должен сделать это
  сам при первом открытии, пока на машине больше никто не знает порт.
* `/v1/*`: единый ключ `freellmapi-<48 hex>`; хранится в таблице `settings` SQLite открытым текстом (читается только процессом
  с доступом к файлу БД). Ключи провайдеров шифруются AES-256-GCM; ключ шифрования автогенерируется в
  `freellmapi-data\.encryption-key` рядом с БД. Это защищает от копирования одной БД, но не от процесса с доступом к папке:
  папку данных не копировать и не пушить.
* Платные провайдеры добавить МОЖНО: есть «custom endpoint» (любой OpenAI-совместимый URL). Сам шлюз не отличает бесплатную
  модель от платной на таком эндпоинте. Правило: в дашборд вносить только бесплатные тарифы; в Bossman модели из шлюза
  регистрируются как 0/0 только после проверки реальным вызовом.

## Решение по ценности для Bossman

Что Bossman уже умеет: реестр провайдеров с пресетами бесплатных уровней (NIM, Groq, Google AI Studio, OpenRouter,
Experiential Labs free plan, HowToFix), цены 0/0 + `caps.free_tier`, роут free-chat, один ключ на провайдера.
Что добавляет FreeLLMAPI: один адрес с автоматической ротацией НЕСКОЛЬКИХ ключей одного провайдера, учёт RPM/RPD на ключ,
каскад между провайдерами при 429. Для оркестра самоулучшения (много коротких вызовов, главный враг — 429) это реальный плюс,
но только если у владельца по провайдеру больше одного бесплатного ключа или оркестр упирается в лимит. С одним ключом на
провайдера выигрыш — только каскад и учёт лимитов. Минусы: ещё один процесс (~70 МБ RAM, BELOW_NORMAL, без GPU) и ещё одно
место, где лежат ключи (поэтому ключи из хранилища Bossman НЕ копировались: владелец вставляет их в дашборд сам).

Решение: **установлен и запущен только на 127.0.0.1:3001, зарегистрирован в Bossman как один провайдер «FreeLLMAPI (local
gateway)» БЕЗ моделей**. Моделей с ценой 0/0 пока нет: без ключей любой вызов даёт 503 `no_providers`, значит ни одна
модель реальным вызовом не проверена. Модели добавлять только после ключей и проверки (ответ без стоимости, провайдер из
бесплатного списка). Если за 2 недели не станет заметно меньше 429 в оркестре — остановить и убрать задачу автозапуска.

есть бесплатный план без карты.
