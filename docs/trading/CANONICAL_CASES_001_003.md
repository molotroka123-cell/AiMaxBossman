# Canonical owner trading CASE set for market-learning branch

These are owner-history evidence, not YouTube teacher claims.

- CASE-001: `case-001-first-btc-long-2026-09-03-to-09-08.json` — closed around breakeven; core lesson is regime change from deleveraging to bearish leverage expansion and the need for structural acceptance.
- CASE-002: `case-002-second-btc-long-2026-09-08-to-current.json` — continuous Sep 8-11 chain; failed repair vs accepted reclaim, CPI shock, CVD/OI recovery, squeeze payout and profit-protection lessons.
- CASE-003: `case-003-fomc-btc-long-2026-09-16.json` — FOMC long from 75,400; event-driven deleveraging, two-sided liquidity sweep and post-event acceptance logic.

## Training rule

Owner CASEs are high-value historical examples but still must preserve chronology.
At timestamp T, the learner may only see evidence available at or before T.
Later outcomes are labels, never input features for the earlier decision.

YouTube episodes may retrieve these CASEs for comparison, but a YouTube teacher
cannot overwrite or silently mutate an owner CASE.
