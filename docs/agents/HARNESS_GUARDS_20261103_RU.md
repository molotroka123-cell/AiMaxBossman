## Подключение

- `pc.studio` и `computer.act` — G1 работает сам, без настроек.
- `Engine._call_model` — G2 сам для агентов с `free_pool_first` (агент 80) или `permissions.empty_recovery: true`.
- Реестр инструментов: `guard.config_refs`, `guard.media_provenance`, `guard.content_policy` (чтение, AUTO),
  `guard.publish_gate` (`terminal.run`, ASK). Пути — только внутри `~/Bossman`, `D:/Bossman` (`BCC_GUARD_ROOTS`) или workspace.
- Агент 80 «Bossman Harness»: инструменты добавлены через живой API (`python tools/harness_guards.py profile 80 --apply`),
  права не менялись. Живой рантайм :8801 на старом SHA игнорирует неизвестные имена — guard.* заработают после
  перезапуска Bossman на этой ветке / после слияния.
