# SmythOS Studio — оценка кандидата (06.10.2026)

Same-product Terminal Run: пульт, CLI, дашборд и Telegram — одна поверхность одного Bossman. Это запись и решение, а не интеграция; лестница North Star не меняется.

## Что проверено (источник: страница https://github.com/SmythOS/smythos-studio, прочитана 06.10.2026)

* Лицензия **MIT**; основной язык TypeScript (монорепозиторий: React, Node.js, Prisma); 594 звезды; в истории 1 607 коммитов.
* Запуск: Docker (`docker compose up -d`, порт 6060) или `pnpm install && pnpm dev`.
* Нужны: **MySQL**, поддержка поддоменов для «embodiments». Платная часть на странице не упоминается; для «корпоративных запросов» указан e-mail.
* Не проверено: дата последнего релиза, какие LLM и ключи нужны, качество, безопасность, производительность. Код я не запускал.

## Решение: **отложить, не внедрять**

* **Дубль.** В Bossman уже есть конструктор агентов и оркестров (страница «Агенты», граф агентов, оркестры); второй визуальный конструктор — это второе ядро, а правило владельца — один продукт с общими ядром, данными и правами.
* **Второй стек.** MySQL, Docker, Node/pnpm, поддомены — всё это чужие хранилище и аутентификация рядом с нашими; отдельная модель прав и данных.
* **Польза не измерена.** Нет задачи, базового уровня и метрики, по которым Studio лучше того, что уже есть.

## Если вернуться к вопросу

Только как внешний сервис по HTTP (как `apps/ai-webcam-vision`), в песочнице, без доступа к ключам и данным Bossman, и только после измерения на конкретной задаче: чем он лучше текущего конструктора, при том же бюджете и бесплатных моделях.
