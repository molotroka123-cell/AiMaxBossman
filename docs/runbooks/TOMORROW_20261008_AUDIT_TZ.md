# ТЗ на 08.10.2026: аудит дерева возможностей через Bossman (без новых функций)

Владелец, 07.10: «не внедряем новые функции, а проводим аудит через Bossman с платным и бесплатным стеком по всем записям, что есть в дереве, и внедряем после доказательств полезности. Завтра дерево должно быть целое, а Bossman одной версии».

## 1. Цель дня
1. Дерево целое: каждый узел имеет честный статус и ссылку на доказательство; нет битых ссылок, дублей и узлов без источника.
2. Bossman одной версии: одна линия кода, один установленный build, один SHA на сайте, в отчётах и в установленной сборке.
3. Любая запись «idea / recorded / branch / code / prepared» либо получает доказательство пользы и внедряется, либо закрывается с причиной (RETIRE / отложено).

## 2. Чего НЕ делаем
- Не пишем новые функции и не добавляем новые листья-идеи (кроме закрытия найденных дефектов).
- Не внедряем ничего без аудита и без доказательства пользы.
- Не трогаем ключи и vault; vault никогда не пушится. Ключи: только имена в логах.
- Платёжные действия, регистрации, вход в аккаунты, капчи: только с подтверждением владельца.
- Не выключаем компьютер, не останавливаем Jeff, Пульт и backend без бэкапа.

## 4. Метод (на каждую запись)
1. Аудит стеком: бесплатные модели (OpenRouter :free, NVIDIA NIM, локальные) делают первый проход; платный аудитор (Haiku 5.5, GLM 5.3 Flash, только как аудиторы) проверяет вывод. Расхождения идут на ручной разбор.
2. Доказательство пользы = измеримая метрика до/после (время, процент прохождения, число ошибок, стоимость) либо воспроизводимый живой сценарий. «Выглядит полезным» не считается.
3. Решение: INTEGRATE (после аудита и тестов) / KEEP_RECORDED / RETIRE, причина одной строкой.
4. Код пишут только бесплатные или локальные модели; Claude следит, аудирует, чинит ошибки инструментов.
5. Каждый шаг даёт receipt (команда, код выхода, sha256 вывода). Нет receipt, нет зелёного листа.

- Все узлы дерева имеют статус и источник; отчёт аудита покрывает 100% записей (не выборка); число решений INTEGRATE / KEEP / RETIRE сходится с числом узлов.
