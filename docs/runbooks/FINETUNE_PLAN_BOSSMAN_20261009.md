## 1. Принципы
1. Для каждого аспекта **до обучения** фиксируются метрика, набор hold-out и порог «лучше»; сравнение на одних входах и seed; стоимость и время записываются.
2. Адаптеры версионируются (`adapters/<аспект>/vN`), база не меняется → откат = отключить адаптер.
3. Любой адаптер, меняющий поведение языковой модели (Jeff, агент), проходит retention-gate: ≥ 20 заданий на метрику, сохранение ≥ 98 %, режимы direct → system prompt → context → полностью через Bossman, на точном SHA, комментарий владельца.
4. Данные людей — только с согласием участников (Jeff-участники, голос и лицо владельца); сырые данные в git не попадают, в облако — только то, что владелец разрешил.
5. Всё запускается через Bossman: задание обучения = бюджет + сторож терминации + журнал + квитанция `tree_apply_evidence`; статус листа дерева повышается только по квитанции.

## 3. Порядок (дешёвые победы первыми, рискованное после gate)
1. **Данные (бесплатно, сейчас):** `tools/training_data_preflight.py` для фото/голоса; разметка голоса (Whisper CPU); список недостающего → владельцу.
2. **Быстрые, низкий риск (1, 2, 5, 7, 8, 9):** по одному запуску, каждый с заранее записанным hold-out и порогом.
3. **Видео (6):** после 1 (идентичность фиксирует персонажа).
4. **Текст/агент (3, 4):** только после замороженного SHA и retention-замера «до»; обучение → замер «после» → gate; без gate адаптер не включается.
5. Каждый шаг: квитанция → `tree_apply_evidence`; сравнение «до/после» в пульте (по разрешению владельца).

## 4. Что нужно от владельца (по аспектам)
- Фото: 100–250 новых фото (разный свет/ракурс/одежда), без чужих лиц; подписи генерируются и проверяются Haiku/локальной VLM.
- Голос: 45–90 мин чистой речи (тихая комната, один микрофон, чтение текстов + свободная речь; русский и английский).
- Музыка: треки, на которые у вас есть права (свои, лицензия, CC); теги/тексты; 3–5 примеров желаемого стиля. Чужие коммерческие треки не использовать.
- Jeff: список участников, давших согласие на память; правки ответов Jeff («так лучше»); что считать «приватным».
- Видео: 30–100 коротких клипов себя (лицо в кадре, речь/без).
- Лимиты: потолок суммы на аспект и дневной потолок; разрешение на платный GPU (на запуск или общий потолок).

## 5. Риски и лицензии
- XTTS-v2: CPML, только некоммерческое. SDXL: OpenRAIL++-M. epicrealism-xl: источник/лицензия UNKNOWN (отмечено в каталоге Bossman). Wan2.2: Apache-2.0 (проверять по карточке на дату). ACE-Step: проверить лицензию весов по карточке перед коммерческим использованием. Qwen: лицензия конкретной модели — проверить перед тиражированием адаптеров.
- Переобучение на один образ (селфи-ракурс, одежда); защита — регуляризация и разнообразие данных.
- Музыка: риск воспроизведения обучающих треков и прав на стиль; автопроверка на близость к обучающим данным, только свои/лицензированные треки.
- Retention: адаптер текстовой модели может ухудшить «нейтральное» поведение — поэтому gate обязателен.
- Приватность: фото/голос владельца уходят на стороннюю GPU-аренду; удалять данные с пода сразу после скачивания (под терминировать).
- Сеть и железо подов нестабильны: автоподбор хоста по скорости (на плохом хосте было 145 КБ/с), сторож терминации, проверка скачанных файлов по SHA256.
