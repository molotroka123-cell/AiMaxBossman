# 03. Автономный режим (сверено с `command-center/bcc/autonomy`, 11.10.2026)

Источник правды: код в `command-center/bcc/autonomy/` (27 модулей) и `docs/constitution/BOSSMAN_CONSTITUTION.md`.
Цель документа: что именно ограничивает автономный цикл и что НЕ доказано.

## 1. Что такое цикл

`bossman autonomy ...` (`autonomy/cli.py`) управляет конечным автоматом самоулучшения (`autonomy/cycle.py`):

`PROPOSED -> PLANNED -> BUILDING -> TESTING -> CLAUDE_REVIEW -> CODEX_REVIEW -> STAGING -> USER_APPROVAL ->
DEPLOYED -> MONITORING -> COMPLETE | ROLLED_BACK`, из любого состояния возможен `BLOCKED`. Шаг USER_APPROVAL
останавливает цикл: Apply / Reject / Revise нажимает владелец. Панель релиза ничего не сливает и не пушит: она
записывает решение и выдаёт точные команды fast-forward и отката (`autonomy/service.py`).

## 2. Жёсткие ограничения (из кода)

| Ограничение | Где | Поведение |
|---|---|---|
| Конституция закреплена владельцем | `autonomy/constitution.py` | хэш файла сверяется с pin `%LOCALAPPDATA%\Bossman\autonomy\constitution.sha256`; нет pin или несовпадение -> BLOCKED, цикл не идёт. `pin()` работает только из интерактивного TTY человека, вне репозитория, с вводом первых 12 hex SHA |
| STOP | `autonomy/stop.py` | два файла: `<data>/computer/STOP` (глобальный) и `<root>/STOP` (автономия); проверяются на каждом шаге, брокер рук отказывает, сессии писателя/ревьюера убиваются деревом процессов. `resume` снимает только STOP автономии |
| Один писатель | `autonomy/lease.py` | аренда `<root>/engineering.lease` под межпроцессным замком; устаревшая аренда перехватывается, осиротевшие процессы убиваются |
| Дневной бюджет | `autonomy/budget.py` | по умолчанию 3 цикла, 30 ходов агента и 0 USD за сутки UTC; лимиты правит только владелец, лежат вне репозитория |
| Ограниченный супервизор | `autonomy/supervisor.py` | не демон: `max_cycles` 1..25 (`HARD_MAX_CYCLES`), `max_hours` до 24 (`HARD_MAX_HOURS`), по умолчанию 1 цикл и 2 часа; запускается планировщиком `tools/autonomy_supervisor.ps1` |
| Единственные «руки» | `autonomy/hands.py` | `HandBroker`: запрос хэшируется и журналируется, проходит `Policy.check`, исполняется как argv-подпроцесс в worktree без секретов в env, с таймаутом; без ожидаемых доказательств `ok=false` |
| Матрица полномочий | `autonomy/policy.py` | порядок: конституция; формат/чужая цель; «всегда владелец» (деньги, внешние сообщения, учётные данные, прод-деплой, новый способ заработка, отключение защиты, разрушающие операции); неизвестное действие = отказ; уровень; область путей |
| Журнал | `autonomy/journal.py` | JSONL с хэш-цепочкой `prev/hash`, `journal.head` ловит обрезание, секреты вычищаются ДО хэширования |

## 3. Кто пишет код

Писатель — официальный `claude -p` или `codex exec` под подпиской владельца, в изолированном клоне и ветке
(`autonomy/workers.py`); лёгкие задачи может писать бесплатный маршрут Nemotron, возвращающий только unified diff,
который применяет Bossman. Рецензенты read-only и привязаны к тому же (sha, diff hash, тесты).

## 4. Что доказано и что нет

| Утверждение | Статус | Доказательство |
|---|---|---|
| Журнал, STOP, бюджет, аренда, политика ведут себя по контракту | works на тестах | `test_autonomy_journal.py` и соседние (входят в 98 passed, `MP21_A_CHECKS`) |
| Один цикл самоисправления | PASS по определению сайта, PARTIAL по строгому порогу документа | `docs/evidence/north-star-ladder-20261010.md` |
| Три цикла подряд | FAIL (1 из 3) | там же |
| Перенос навыка измерен | NOT RUN | там же |
| 24 часа без сбоев | не записано | `docs/autonomy/BOSSMAN_2_1_AUTONOMOUS_COMPUTER_OPERATOR.md` |
| Многосайтовая автономная миссия (браузер, загрузка, процесс) | только дизайн | то же |

## 5. Что делает владелец

Пинит конституцию в терминале, задаёт `budget.json`, нажимает Apply/Reject, при необходимости `bossman autonomy stop`.
Отдельного внешнего разрешения требуют: деньги, внешние сообщения, прод-деплой, новые способы заработка.
