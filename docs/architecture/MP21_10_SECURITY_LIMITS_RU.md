означает, что есть код и тест; «не гарантируется» означает, что защиты нет или она не проверена.

## 2. Исключения, принятые владельцем явно

* `BOSSMAN_JEFF_BROWSER_IGNORE_ROBOTS=1` (решение владельца 11.10, «robots.txt обходим»): выключает ТОЛЬКО проверку
  robots.txt. Лимиты страниц, публичные http(s), STOP и PII-фильтры остаются. По умолчанию выключено.

## 3. Что НЕ гарантируется

| Пробел | Подробности |
|---|---|
| Полный offline | веб-поиск, браузер, Gmail, Telegram, каталог OpenRouter и загрузка моделей идут мимо `assert_provider_egress` |
| Живой стоп-кран | нет глобального hotkey; STOP только панелью, API или файлом |
| Лицензии моделей | 8 из 11 моделей Ollama без лицензионного текста; веса вне Ollama без LICENSE |
| Контрольная плоскость suite | POST без токена (loopback); часть эндпоинтов отвечает BLOCKED |
| Токен-бот на mainnet | authority реальных токенов не проверялись; RPC не вызывался |
| SwapMe-bot | не исправлялся: небезопасный WAL-бэкап, нестойкие коды менеджеров, полная БД отправляется файлом в Telegram, молчаливая подстановка курса |
| Playwright MCP | устанавливает владелец; DNS rebinding и под-ресурсы страниц не фильтруются; prompt injection режется эвристикой |
| Отдельные сторонние компоненты | RobustVideoMatting GPL-3.0, SegFormer некоммерческая лицензия: для продукта нужна замена или проверка |
| Секреты | токен в открытом Блокноте мог попасть в лог агента (OPEN_PROBLEMS B10): владельцу сменить токен |

## 4. Правила обращения с секретами

Ключи, vault, DPAPI и содержимое секретных файлов не пушатся и не отправляются; перед каждым push запускается
`tools/ci_secret_scan.py`. Данные приложения живут в `BCC_DATA_DIR`/`%LOCALAPPDATA%\Bossman\CommandCenter` вне git.
Сырые экспорты Telegram, фото, видео и веса LoRA в git не добавляются (в этом коммите только счётчики и SHA входов).
