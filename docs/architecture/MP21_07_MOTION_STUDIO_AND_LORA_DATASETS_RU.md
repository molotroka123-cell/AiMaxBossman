## 4. Метод проверки

* Сходство лица: `arcface_w600k_r50` из моделей FaceFusion (нормированный косинус), детектор yolo_face 640, к среднему
  эмбеддингу реальных фото; скрипты проекта `lora_eval.py` / `score.py` / `scan.py`. Порог сохранения в наборе 0.45
  (0 отброшено), порог синтетики 0.70, порог гейта Gate 1 T7 >= 0.75. Сходство не доказывает ни личность, ни согласие.
* Резкость: дисперсия лапласиана кропа лица, приведённого к 192x192, порог 30 (проектная метрика `scan.py`).
* Дубли: SHA-256 по байтам (этот проход) и отбор вручную 5 почти-дублей (v3).
* Подписи: токен `gfgirl` первым в каждой подписи; 8 пустых подписей переписаны вручную после просмотра картинок.
