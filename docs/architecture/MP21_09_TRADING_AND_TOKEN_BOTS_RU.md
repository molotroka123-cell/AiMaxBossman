## 2. Есть ли доказанная прибыль

НЕТ. Реальных сделок нет, поэтому «реальная доходность» не определена. Paper-арена (по реальным котировкам, виртуальные $50):
лучший агент +0.68% на 1 сделке, `new_pair` -16.7% и -21.7%, кандидатов на реальные деньги нет. Когорта creator fee:
2261 токен увиден, замеров 0 на момент отчёта. Статистический барьер проекта (>=30 сделок, >=10 вне выборки, >=2 режима,
EV>0 после издержек; `metrics.py`) не прошла ни одна стратегия. Торговля и выпуск токенов безопасным способом заработка не являются.

## 4. Токен-бот: полномочия (что проверено и что нет)

Проверено по коду helper, IDL SDK 4.0.0 и публичной документации: программа pump `6EF8rrec...F6P`, создание `create_v2`
(Token-2022), потолок dev-buy 5 SOL (`launch.js`), комиссия кривой 95 bps протокол + 30 bps создатель (снимок 09.10).
**НЕ ПРОВЕРЕНО on-chain** (RPC не вызывался): mint authority, freeze authority, update authority метаданных реально
выпущенных токенов; актуальность `PUMP_FEE_RECIPIENT`; формат `priceImpactPct` Jupiter; список tip-аккаунтов Jito.
Блокировок ликвидности и vesting в helper нет.

## 5. Правила

* Торговый и токен-контур остаётся read-only/paper. Любое действие с реальными деньгами (подпись, отправка, ликвидность,
  перевод) только вручную владельцем, с отдельным подтверждением непосредственно перед действием
  (`bcc/autonomy/policy.py`: деньги = «всегда владелец»).
* Формулировки «безопасно», «проверено», «прибыльно» без измерений не используются.
* Юридическая оценка не дана: формулировки о манипулировании описывают дизайн, а не являются заключением.
