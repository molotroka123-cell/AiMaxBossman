# 08. Калькулятор объёма обменника и SwapMe-bot (сверено 11.10.2026)

Полный аудит, формулы и результаты: `docs/archive/2026-10/owner/MP21_C_EXCHANGE_CALCULATOR_20261011.md`. Код: `tools/exchange_volume/`
(`timeutil.py`, `parse.py`, `calc.py`, `reconcile.py`, `cli.py`), тесты `tests/exchange_volume` (25 passed, 1 skipped).
Только stdlib и `Decimal`, без сети.

## 1. Запуск

```powershell
cd <repo>\tools
python -m exchange_volume.cli run --export <messages.html> --out <папка> [--workbook book.xlsx] [--rates rates.csv] `
       [--exclusions refs.txt] [--baseline old.json] [--period business|calendar] [--dup-window-min 10] [--rate-max-age-h 24]
python -m exchange_volume.cli run --db <swapme.db> --out <папка>       # БД открывается read-only
python -m exchange_volume.cli anonymise --export <messages.html> --out <папка> --seed 20261011
```

Выходы: `volume_result.json` (периоды, объёмы, пары, валюты, сверка) и `deals.csv` (по строке на сообщение: статус, флаги,
курс/источник/время курса). Реальные экспорты и книга владельца в git НЕ кладутся.

## 2. Правила (из кода и документа)

* Время: `ts_utc = локальное время экспорта - смещение из каждого сообщения`; бизнес-время Europe/Prague по EU DST
  (подтверждено владельцем 11.10); бизнес-месяц 21-е..20-е.
* Валовый объём USDT = сумма USDT-ноги каждой учтённой сделки (одна нога, не in+out).
* Сделки без USDT-ноги остаются `unpriced`; перевод только по внешнему CSV курсов не старше `--rate-max-age-h`.
* Комиссия и чистый объём: `null`, а не 0, если данных нет. В режиме `--db` считаются только если у ВСЕХ сделок периода есть `fee` в USDT.
* Дубль: идентичные обе ноги и разрыв <= 10 мин. Одинаковые пары позже в тот же день не удаляются, а помечаются кандидатами.
* Внутренний оборот автоматически не удаляется; зеркальные пары только помечаются.
* Не угадываются: `complex` (>2 пар сумма+валюта), `incomplete` (нет валюты), `ambiguous_amount`, неподдерживаемые валюты.
* Правдоподобие: курс сделки, отличающийся от медианы пары более чем на 25%, помечается `implied_rate_outlier`, но остаётся в итогах.
