# Runbook на ПК владельца: один фиксированный кандидат → замер → первый доказанный цикл (06.10.2026)

Same-product Terminal Run: пульт, CLI, дашборд и Telegram — одна поверхность одного Bossman. Лестница North Star: достигнут только
`SELF_IMPROVEMENT_INFRASTRUCTURE_PRESENT`; этот runbook ничего не поднимает сам, он говорит, **что именно запустить и что принести обратно**.
Всё ниже выполняется на вашем ПК; облачная сессия не имеет ваших ключей, vault и железа и ничего из этого не запускала.

Правило прохода: **один фиксированный SHA, пока идёт проверка — никаких пушей в ветку цели.** Покерная линия уже включена (`96cec27e` — предок ветки цели).

## 0. Зафиксировать кандидата
```
git fetch origin
git checkout goal/bossman-self-improvement-tree-20261005
git pull --ff-only
git rev-parse HEAD            # это и есть <SHA> во всех командах ниже; запишите его
```

## 1. Пакет именно этого SHA
1. Windows-пакет собирает CI (workflow «One-download Windows application»; у облачной сессии нет права его запускать — нажмите Actions → Run workflow на ветке цели
   или на `night/bossman-windows-bundle-20261006`; см. журнал сессии). Для ранее собранного `90dd13fb` уже есть `BOSSMAN-Windows-x64-90dd13fb92c4.zip`
   с `archive_sha256 c1fc77b0178d99bef7ac8a0ee60c73989caf8db8b138ec387493dd2b65daa6c3` (это код `6d9c1f56`, не текущий кандидат).
2. Проверка скачанного архива: `certutil -hashfile BOSSMAN-Windows-x64-<sha12>.zip SHA256` — сравнить с `archive_sha256` из `bundle-acceptance.json`.
3. `python tools\verify_windows_bundle.py --archive <zip> --expected-sha <SHA> --out bundle-acceptance.json` (код 0 PASS, 1 FAIL, 2 OWNER_REQUIRED).
4. Вечерняя приёмка скачанного пакета: `Evening-Test.cmd` (внутри архива, `app-support/bundle_evening_test.py`; ключи `--full`, `--ui-sweep`, `--live` — см. `--help`).
5. Вручную: UX/CMD запускается; Jeff отвечает **весь прогон**; кнопка/команда STOP останавливает; перезапуск (restart) поднимает те же данные.
   Что вы увидели — запишите в `docs/owner/` одним файлом: SHA, дата, что нажимали, что получилось. Выдуманные пункты не пишутся.

## 2. Замер Intelligence Preservation (то, чего ждёт красный гейт)
Гейт сравнивает ОДНУ и ту же модель на одинаковых заданиях в четырёх режимах: напрямую → системный промпт → контекст → полностью через Bossman; нужно минимум 20 заданий
на каждую метрику, сохранение ≥ 98 % исходного качества, без ухудшения выбора инструментов и аргументов; вызовы реальные, на точном SHA.
```
python tools\intelligence_preservation_run.py --help
python tools\intelligence_preservation_run.py --model <локальная модель> --sha <SHA> [--endpoint ...] [--out ...] [--context-engine]
python tools\intelligence_evidence_transport.py prepare <файл измерения> --expect-sha <SHA> --out comment.txt
```
`prepare` создаёт обезличенный текст `BOSSMAN_INTELLIGENCE_EVIDENCE_V1 …`. Полные задания и ответы остаются у вас.
Дальше: опубликовать этот текст **комментарием к коммиту `<SHA>`** от аккаунта `molotroka123-cell` (не под PR) и перезапустить CI.
Если честного замера нет или он не прошёл — гейт остаётся красным, и это правильный результат; число заданий искусственно не увеличивать.
Замечание: эта проверка доказывает **сохранение качества**, а не самообучение.

## 3. Самообучение — отдельное доказательство
Нужен ключ бесплатного провайдера из vault (в облачной сессии его нет; стабы и подмену ответов не использовать). Один цикл:
```
python tools\tree_self_improve.py --help
python tools\tree_self_improve.py --worker openrouter-free
```
Засчитывается только если Bossman **сам** получил дефект, исправил его в изолированном кандидате, прошёл независимые проверки, **сохранил опыт** и **применил его на новой задаче**
(после перезапуска). Патч, написанный Claude, не считается. Принести: `VERIFIED_CANDIDATE` или честное `FAILED`/`BLOCKED`, id задач, хеши улик.

## 4. Лимиты и модели
* По умолчанию режим «только бесплатное» (`FREE_ONLY`): платный маршрут и неизвестная цена модели отказываются; исключение — маршрут Anthropic с потолком Fable $3 (задан владельцем).
* **GLM 5.3 Flash через OpenRouter**: облачная сессия не смогла проверить точный model ID и цену (openrouter.ai недоступен из песочницы), поэтому в код он **не вписан**.
  Проверка на ПК: открыть публичный список `https://openrouter.ai/api/v1/models`, найти id с `glm`, выписать `pricing.prompt`/`pricing.completion`.
  Пришлите id и цену — тогда добавляется узкий allow-list на одну модель с учётом расходов; глобальный переключатель `BOSSMAN_ALLOW_PAID_CLOUD` для этого не использовать (он открывает всё).
* Дорогие модели без вашего явного слова не включать; RunPod — только с вашего разрешения.
