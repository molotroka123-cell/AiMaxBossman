## 3. Задачи GLM 5.3 Flash — 0 из 5 отправлено

Не отправлял ни одной. Причина — жёсткий лимит «без GPU / без моделей ollama»:

- `POST /api/coding-tasks` (`command-center/bcc/features/coding_tasks.py`, `create_task`) **всегда**
  сначала вызывает `readiness()`, а она делает handshake с **локальным** sidecar
  (`bossman-fast-qwen36-35b-a3b-q5` в ollama, «одна настоящая tool call»), даже если в запросе
  `worker: "glm-flash"`. Кэш handshake — 60 секунд. То есть каждая задача GLM может поднять
  локальную модель на 27 ГБ в VRAM.
- **Инцидент, честно:** перед тем как это понять, я один раз вызвал `GET /api/coding-tasks/readiness`
  (~13:15 по местному времени). Сразу после этого `GET :11434/api/ps` показал загруженную
  `bossman-fast-qwen36-35b-a3b-q5` (size_vram 26.9 ГБ, expires_at 13:20:15, keep-alive 5 минут).
  Скорее всего, её загрузил или продлил именно мой вызов (другие агенты могли сделать то же самое,
  различить нельзя). Модель я не выгружал и процессы не трогал. Если в это время шёл рендер,
  стоит проверить, не задело ли его.
- Рекомендация (не моя зона, не правил): в `create_task` при заданном `worker` не вызывать
  локальный handshake (проверять только ключ облачного исполнителя). Пока этого нет, задачи GLM
  от агентов одновременно с GPU-рендером противоречат правилу «без GPU».

## 4. Что остаётся `code` и почему

- **app-ai-3d-maker** — 7 падений в `tests/test_slicer.py`: заглушки слайсеров — POSIX-скрипты
  `#!/bin/sh` (на Windows `shutil.which` их не находит → NOT_AVAILABLE). Попутно: адаптеры
  запускают `binary` по голому имени, а не путь, который вернул `shutil.which`; на Windows
  обёртка `.cmd`/`.bat` будет найдена, но не запустится. Нужно: переносимые заглушки
  (Python + `.cmd`) и запуск по найденному пути. Не делал — лимит ~5 исправлений.
- **app-ai-webcam-vision** — 6 падений, только Windows: 3 проверки прав `0600` (на NTFS права
  задаются через ACL, а не `chmod`); 2 — `zoneinfo` без `tzdata` (на Windows `AWV_TIMEZONE=Europe/Prague`
  даёт ConfigError — **реальный дефект продукта**: в `dependencies` нет `tzdata; sys_platform == "win32"`);
  1 — тест копирует ffmpeg в файл `ffmpeg` без `.exe`, и на Windows PATH-поиск его не находит
  (это дефект теста). В сообщении коммита `3fbb1748` это неточно названо «POSIX ffmpeg stub».
- **pv-act, pv-executor, pv-ui** — тесты на этом хосте не собираются без `cv2`; результата нет

- **bossman-accountant** — строка суммы, которую нельзя разобрать, в JSON-импорте
