# Пост Telegram → пайплайн «как сделать так же» (локально, без облака)

Задача владельца 27.10: Gemma (агент 41) разбирает пост, видео и канал по ссылке t.me/c/… и шлёт пайплайн в пульт.
Оператор (Claude/Боссман) содержимое НЕ смотрит: видит только статусы, счётчики и служебную строку.

Порядок (проверен вживую 27.10, задачи 591–607):
1. Предусловие: Telegram Desktop запущен ИМЕННО с сессией владельца, на переднем плане, развёрнут.
   Проверка: `python diag.py <screenshot.png>` → `TELEGRAM_СОСТОЯНИЕ` не `экран_входа`. Если экран входа — СТОП,
   нужен вход владельца (код с телефона); пайплайн без просмотра не писать.
2. Запись: ПК-агент `POST /api/pc-agent/tasks` с планом `[pc.record_screen{url, duration_s:60–75, send_to_pult:false}, pc.observe_screen]`.
3. Разбор: `python analyze.py` — 7 кадров (лимит вложений чата = 8) + снимок → Gemma; первая строка
   «ПОСТ_ОТКРЫТ: да|нет; ВИДЕО: N; ЭКРАН: …». В пульт уходит ТОЛЬКО при «да».

Ловушки (на доске D-036…D-039): чат-задача без инструментов отвечает «как будто видела»; слово FaceFusion включает T3-отказ;
launch Telegram.exe и клавиши в окно Telegram вне allowlist; вложений >8 → 422; обработчик tg:// запускает Telegram
с рабочей папкой `Roaming\Telegram\`, где нет сессии владельца (экран входа).
