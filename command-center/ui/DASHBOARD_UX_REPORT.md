# BOSSMAN — отчёт по UX и языку дашборда

Ветка: `claude/bossman-control-v03-43igbk`. Затронут только `command-center/ui/`.

Две цели: (1) чтобы владелец-непрограммист управлял сервером, не встречая
непонятных слов; (2) единый premium-вид на токенах `theme.css`, как на главной.

**Ошибок в консоли: 0** — на всех 22 страницах, на 1580px и 390px
(проверено настоящим Chromium с входом по токену).

---

## 1. Что сделано: новый общий слой

Чтобы не копировать разметку главной в каждый файл, добавлены переиспользуемые
кирпичи дизайн-системы:

- **`theme.css`** — новые классы `bx-*`: `bx-page`, `bx-pagehead`, `bx-cards`,
  `bx-tile` (универсальная премиум-карточка сущности), `bx-tags/bx-tag`,
  `bx-stats/bx-stat`, `bx-meter`, `bx-bignum`, `bx-code`, `bx-seg`
  (сегментированный переключатель), `bx-field/bx-input/bx-textarea`,
  `bx-blank` (крупное пустое состояние), `bx-list`. Всё на токенах, светлая тема
  не сломана, мобилка — одна колонка, тап-зоны ≥44px.
- **`pages/_ui.js`** — функции-обёртки над этими классами: `pageHead`, `panel`,
  `pill`, `statusPill`, **`statusText`** (переводит любой статус на человеческий:
  `running`→«выполняется», `LIVE`→«работает», `pending`→«ждёт решения»…),
  `tile`, `tag`, `meter`, `bar`, `stat`, `btn`, `blank`, `errorNote`, `codeBlock`,
  `segmented`, `field`, **`plural`** (русские формы: «3 шага», «5 шагов»).

Один общий словарь статусов означает, что нигде на экране не всплывёт голое
`STOPPED`, `queued` или `pending` — все проходят через `statusText`.

## 3. Убранный жаргон: было → стало (по страницам)

### Навигация (заголовки страниц в меню)
- `AI Governor` → **Присмотр**
- `Self-Healing` → **Восстановление**
- `Роутер моделей` → **Выбор модели**
- `Benchmark Lab` → **Замеры моделей**
- `Форки сессий` → **Развилки**
- `NL-оркестрация` → **Команды агентов**
- `Workflow Builder` → **Конструктор миссий**
- `Скиллы` → **Навыки**
- `Подтверждения` → **Ждут решения**

### Главная (home)
- Панель здоровья показывала сырые `db`, `queue_worker`, `metrics` и статусы
  `OK`/`STOPPED` → **База данных / Обработчик задач / Сбор показателей** +
  «в норме»/«остановлено».
- Лента событий показывала `agent.created`, `model.created`, `approval.created`
  → **Создан агент / Добавлена модель / Ждёт вашего решения** (сырой код — в
  подсказке).
- «Модели онлайн» → **Моделей на связи**; «Здоровье системы» → **Состояние системы**.

### Ждут решения (Approvals)
- `Approve` / `Reject` → **Разрешить** (зелёная) / **Отклонить**.
- «Очередь подтверждений» → **Ждут вашего решения** + «N действий нельзя
  выполнить без вашего „да“».

### Агенты
- `Edit`/`Delete` → **Изменить**/**Удалить**; добавлена **Поручить задачу**.
- В форме: `System prompt` → **Характер и правила**; `Fallback-модель` →
  **Запасная модель**; `Max steps` → **Шагов на задачу**;
  `Max retries` → **Повторов при ошибке**; `fallback:` на карточке → **запасная:**.

### Миссии
- `Start/Stop/Pause/Resume` → **Запустить/Остановить/Пауза/Продолжить**.
- «воркеров» → **помощников**; «KPI-цели» → **что считать успехом**;
  «Прогресс» → **Готово**; «План (N)» → **Шаги плана**.

### Состояние системы
- «Процессор» → **Загрузка процессора**; `GPU` → **Видеокарта (GPU)**;
  `VRAM занято` → **Память видеокарты занята**; «Компоненты» → **Из чего состоит
  система**; сырые имена компонентов → человеческие.

### Ресурсы
- `Resource Brain / RAM-бюджет` → **Нагрузка на память**.
- `Balanced/Performance/Low power` → **Поровну/На скорость/Экономно**.
- `Enforce` → **Не запускать задачи, если памяти не хватает**.
- `Total override, MB` → **Всего памяти считать (МБ)**; `Reserve floor, MB` →
  **Всегда держать свободным (МБ)**; `reserve floor` → **неприкосновенный запас**;
  «Активные резервации / resource_managed» → **Что сейчас держит память**.

### Технические страницы (подписи)
- Замеры: `TTFT/tok/s/latency/stability` → **Первый ответ / Скорость (сл/с) /
  Задержка / Стабильно** (+ подсказки, что это значит).
- Терминал: `Sandbox/Project host/System admin` → **Песочница/В проекте/С правами
  системы**; `AUTO/ASK/DENY` → «выполнится сразу / спросит подтверждение /
  запрещено»; `Preview/Run/Kill` → **Проверить/Запустить/Остановить**.
- Браузер: `Take Over/Resume/Stop` → **Взять управление/Вернуть агенту/Закрыть
  окно**; хинт о Playwright → «Агент работает в настоящем браузере…».
- Навыки: `Run/Clone/Export/Assign` → **Запустить/Копия/Скачать/Назначить**;
  `MCP Hub` → **Подключённые инструменты**; `auto/ask/deny` → **разрешать/
  спрашивать/запрещать**.
- Развилки: `Fork/checkpoint/run` → **Ответвить/сохранённая точка/запуск**.
- Команды агентов: `оркестр/manager/worker/reviewer` → **команда/главный/
  помощник/проверяющий**; `Proposed configuration` → **Что получилось**.
- OpenRouter: `Sync/Pin/Probe` → **Обновить список/Закрепить/Проверить**;
  `ctx/in/out/params/stale` → **контекст/вход/ответ/настроек/устарело**.
- Карта агентов: `Manager/Workers/Reviewer` → **Главные/Помощники/Проверяющие**.
- Конструктор: статусы узлов `Success/Running/Failed…` → **Готово/Идёт/Ошибка…**.
- Пульт (mobile): `Approve/Reject/Pause/Resume/Stop/Kill/Abort/Take Over` →
  русские эквиваленты.
- Модели: `Check/Test/Edit/Delete` → **Проверить/Проба/Изменить/Удалить**;
  «провайдеров» → «поставщиков».
- Задачи: `Pause/Stop/Resume/Retry/Run` → **Пауза/Остановить/Продолжить/
  Повторить/Запустить**.

Пустые состояния и ошибки везде переведены на человеческий: не «no data», а
«данных пока нет»; не «request failed», а «не удалось получить — попробуйте
обновить».

## 4. Что изменил в композиции и почему

- **Единый ритм страницы.** Каждая переработанная страница теперь начинается с
  `bx-pagehead` (крупный читаемый H1 + одна строка-объяснение обычными словами),
  дальше — панели `bx-panel`/карточки `bx-tile` на общей сетке. Раньше страницы
  использовали плоские `.panel`/`.card` и мелкий caption-заголовок — вид «сырой
  админки».
- **Статус — цветом И словом.** Пилюли `bx-pill` всегда несут слово («работает»,
  «ждёт решения», «остановлено»), а не только точку. Человек не угадывает, что
  значит зелёная точка.
- **Карточки-плитки** (`bx-tile`) с акцентом, иконкой, тегами, статами и крупными
  кнопками — вместо плоских строк. Миссии — фиолетовый акцент, Ждут решения —
  янтарный (тревожно-ожидающий), «Разрешить» — зелёная независимо от акцента
  карточки.
- **Пустые панели не растянуты** под высоту соседей (`align-items:start`), пустое
  состояние — крупное и с объяснением, что здесь появится.
- **Мобилка:** одна колонка; широкая пилюля статуса переносится под заголовок,
  чтобы не резать название посреди слова; кнопки во всю ширину; сегментированные
  переключатели растянуты; тап-зоны ≥44px.

## 5. Найденные баги

- **Главная, панель «Состояние системы»** показывала сырые технические имена
  подсистем (`queue_worker`, `db`, `metrics`) и английские статусы (`OK`,
  `STOPPED`) — то, что владелец видит каждый день. Починено: человеческие имена +
  `statusText`.
- **Главная, лента событий** выводила сырые коды событий (`agent.created` и т.п.)
  как заголовки. Починено: словарь человеческих фраз, сырой код ушёл в `title`.
- Отдельно подтверждаю ранее найденную в проекте проблему `Object.assign(el.style)`
  и CSS-переменных: новый `_ui.js`/`btn(accent)` задаёт `--bx-accent` только через
  `h(..., {style:{'--bx-accent':…}})`, который в `components.js` идёт через
  `setProperty` — то есть корректно.

## 6. Что осталось на потом

- **Модели** и **Задачи**: переведены подписи, но карточки ещё на старом
  плоском `.card` — стоит перевести на `bx-tile`, как Агенты/Миссии.
- **Навыки / Конструктор / Изображения**: тела на старой сетке; подписи и кнопки
  переведены, глубокий редизайн внутренностей — следующим заходом.
- Тексты самих навыков (SKILL.md) приходят из репозитория на английском — это
  контент, а не интерфейс; переводить в UI не стал.
- Мелочь: на «Состоянии системы» деталь БД показывает `sqlite+aiosqlite` (сырое
  значение от сервера) — можно спрятать/замапить, влияние минимальное.
- `CPU`/`RAM` на главной оставлены как есть (короткие, общеизвестные, страница —
  эталон); при желании → «Процессор»/«Память».
