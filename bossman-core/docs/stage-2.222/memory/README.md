# Memory folder — ЭТАП 2.222

Эта папка задаёт отдельную архитектуру памяти. Память не является просто векторной БД.

## Категории

- `identity/` — минимум стабильной идентичности агента.
- `projects/` — состояние конкретных проектов.
- `decisions/` — принятые решения с supersedes links.
- `facts/` — проверяемые факты.
- `constraints/` — обязательные ограничения.
- `procedures/` — проверенные workflows.
- `failures/` — отрицательная память: симптом → причина → fix → verification.
- `episodic/` — история отдельных задач/сессий с TTL.
- `unresolved/` — вопросы и противоречия.
- `distilled/` — компактные производные summaries, никогда не заменяющие raw source.

В runtime это логические namespaces; физически Stage 2.222 хранит их в `memories` таблице через `kind`, `project`, `status` и provenance. Если позже память будет разнесена по плагинам, интерфейс `MemoryPlugin` должен сохраняться.
