# External context ideas to evaluate

These are inspiration candidates supplied for research, not trusted dependencies and not accepted benchmark claims.

- claw-compactor: deterministic multi-stage compression, AST-aware handling, reversible transformations.
- gortex: graph-oriented code context and symbol relationships.
- context-chef: context compiler, dynamic state and tool pruning.
- Code-HUD: compact structural code views.
- infinite-conversation-architecture: sliding window + conversation graph + state/prefetch.
- session handoff/compact tools: structured continuation documents.
- mcp field projection concepts: request only necessary tool-result fields.

Before vendoring or installing any third-party repo: inspect license, commits, dependencies, network behavior, install scripts, secrets access, and run in AI Sandbox. Benchmark against BOSSMAN golden tasks. Architecture can be recreated locally without accepting a dependency.
